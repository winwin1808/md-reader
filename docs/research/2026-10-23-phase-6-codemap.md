## 2. render pipeline (core/render/render.ts renderToHtml, lines 62-144; options.ts)
Input is an already-parsed mdast (parseMarkdown does remark-parse/gfm/frontmatter; render does NOT re-parse). `unified()` bare processor, in order:
1. remarkRehype {allowDangerousHtml: allowRawHtml}  (:70)
2. rehypeSlug (:71)
3. rehypeRaw — only if allowRawHtml (:73-75)
4. rehypeHighlight — if highlight !== false (:77-79)
5. rehypeSanitize with `schema` (:113): base = sanitizeSchema with code/span className overridden to ['className','hljs',/^hljs-/,/^language-/] (:88-101); if allowRawHtml adds '*': style, className, data-info (:103-111)
6. rehypeStringify {allowDangerousHtml: allowRawHtml} (:114)
Then `processor.runSync(tree)` + `processor.stringify(hast)` (:117-118). POST-SANITIZE string/regex transforms, in order (:120-137):
- applyGitHubAlerts(html, localizeAlerts) if githubAlerts===true — options.ts:143-167, regex `/<blockquote>\s*<p>\s*\[!(NOTE|TIP|IMPORTANT|WARNING|CAUTION)\]...<\/blockquote>/ig` -> `<div class="markdown-alert ..."><svg ...>` (title 'vi' only if locale==='vi', else en)
- applyExternalLinks(html) if externalLinks===true — options.ts:98-124 regex over `<a ...>...</a>`; adds class external-link, target=_blank rel=noopener noreferrer, appends inline <svg class="external-link-icon">
- applyTypographer(html) if typographer===true — options.ts:19-94 tag-aware scanner; skips pre/code/script/style/svg; replaceTypography :3-17 (regex: (c)(tm)(r) --- -- quotes)
- displayMetadata===true && parsed.frontmatter non-empty: prepend `<div class="markdown-metadata-card">` built from frontmatter entries with escapeHtml (:129-137)
try/catch: on error console.error + returns {html:'', toc}. stripFrontmatter has no effect inside renderToHtml (frontmatter is already stripped by parseMarkdown); processFrontmatter is unused in renderToHtml. Toc ids from Slugger (extractToc :16-50) run on tree independent of rehypeSlug.
Content-script build aliases rehype-highlight to a no-op (vite.content.config.ts) — but content script does not import core anyway.
