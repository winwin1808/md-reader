INVARIANTS
- Packages boundary: `packages/ui` is pure React & CSS (NO `chrome.*`), pure presentation.
- Formatting actions:
  - `bold`: wraps with `**...**`
  - `italic`: wraps with `*...*`
  - `strike`: wraps with `~~...~~`
  - `code`: wraps with `` `...` ``
  - `codeblock`: wraps with ```` ```\n...\n``` ````
  - `h1`..`h3`: prepends `# `, `## `, `### `
  - `bullet`: `- `
  - `number`: `1. `
  - `task`: `- [ ] `
  - `quote`: `> `
  - `math`: wraps with `$...$`
  - `link`: `[text](url)`
  - `table`: inserts standard 3x3 markdown table template
- `handleListContinuation`:
  - When Enter is pressed on an existing non-empty list item (e.g. `- item` or `1. item`), continues with `- ` or incremented number `2. `.
  - When Enter is pressed on an empty list item (e.g. `- ` alone), removes the bullet and exits the list.
- Toolbar layout in `packages/ui/src/theme/formatting-toolbar.css`:

  - Import `formatting-toolbar.css` in `packages/ui/src/viewer.css`.
- In `packages/ui/src/index.ts`:
  - Export `FormattingToolbar`, `FormattingToolbarProps`, `FormatAction`, `applyFormat`, `handleListContinuation`.
