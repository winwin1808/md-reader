### [x] 7l2.1 — tree semantics, keyboard navigation, pinch zoom
FILES       packages/ui/src/components/MindmapModal.tsx
            packages/ui/src/components/MindmapModal.test.tsx
            packages/ui/src/theme/mindmap.css
INTERFACES  The SVG node layer gets role="tree" aria-label "Sơ đồ tư duy"; each node <g> role="treeitem", aria-level (depth + 1),
              aria-expanded (only when it has children), aria-selected, aria-label = its text; roving tabindex (selected node 0,
              others −1). Initial selection = root.
            Keys while the tree has focus: ↓/↑ next/previous visible sibling (wrap off), → expand if collapsed else first child,
              ← collapse if expanded else parent, Home/End first/last visible node, Enter → onJump(node), Space → toggle collapse,
              "+"/"=" zoom in, "-" zoom out, "0" fit to view. The selected node is kept in view (pan just enough).
            Focus ring on the selected node: stroke var(--accent) 2px outline rect (SVG, not CSS outline) only when focus came from
              keyboard (:focus-visible equivalent via a keyboard-mode flag).
            Touch: two-pointer pinch (pointer events, track two active pointers, scale by distance ratio around the midpoint);
              one-pointer drag pans (existing); `touch-action: none` on the canvas.
INVARIANTS  - Mouse behaviour (click jump, drag pan, wheel zoom, collapse buttons) unchanged.
            - packages/ui: tokens only; no chrome.*.
TEST        MindmapModal.test: tree/treeitem roles + aria-level/expanded; ArrowDown moves aria-selected; ArrowRight on a collapsed node
            expands it, again moves to its first child; ArrowLeft returns to parent; Enter calls onJump with the selected node; Space
            toggles; "0" resets the transform; two-pointer pinch (synthetic pointer events) changes the scale. Then
            `pnpm --filter ui test`, `pnpm -r typecheck`; report.
COMMIT      feat(ui): mindmap navigable by keyboard (tree semantics) and pinch zoom
