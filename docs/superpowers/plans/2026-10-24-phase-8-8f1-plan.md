INTERFACES  export interface BlameRange { from: number; to: number; clientId: number; actor: string | null }
            export function computeBlame(doc: Y.Doc): BlameRange[]
            Use the existing source accessor in packages/core/src/doc (read doc.ts and checkpoint.ts to find it, e.g. getSource(doc)); otherwise use doc.getText('source').
            Read registerActor in checkpoint.ts to learn how meta.actors (a Y.Map) is keyed (clientID as a string or a number) and look names up the same way.
BEHAVIOR    - Walk `ytext._start` through `item.right`. This is the one private-API use, so keep it in a single small function with a comment.
            - Skip items that are `deleted`, or whose content is not countable (`item.countable === false`, i.e. formatting).
            - For each counted item, the length is `item.length` and the client is `item.id.client`.
            - Merge adjacent runs from the same client into one range.
            - Positions are UTF-16 offsets into `ytext.toString()`. The ranges cover [0, length) exactly, with no gaps or overlaps. Empty text returns [].
            - actor is `meta.actors.get(key)` or null.
            - Pure read: never write to the doc.
INVARIANTS  - packages/core is pure TS. It may use yjs, but no react, chrome.* or document, and it never knows a provider.
            - The schema is unchanged: Y.Text "source", Y.Map "meta" (actors already exists), Y.Array "history". formatVersion is not bumped.
            - Docs use gc:false. Deleted items still exist in the item list and must be skipped.
TEST        pnpm --filter @md-reader/core test src/doc/blame.test.ts. Cases:
            (1) A pin test on the private shape. After an insert, `text._start` has `id.client` (number), `length` (number), `deleted` (boolean) and `content`. If Yjs changes this shape, this test fails first.
            (2) Two docs A and B, created with the project's doc factory if one exists, otherwise `new Y.Doc({ gc: false })`:
                - A inserts "Xin chào " and registers actor "An". Sync to B.
                - B appends "thế giới" and registers "Bình". Sync back to A.
                - computeBlame(A) gives two ranges: [0,9) for A's client with actor "An", and [9,16) for B's client with actor "Bình".
                - Slicing the text by each range gives each client's text.
            (3) A deletes part of B's text. The deleted text is absent, and the ranges still tile the text.
            (4) A makes two separate inserts at adjacent positions. They are merged into one range.
            (5) A client with no registered actor gets actor null.
            (6) Empty doc → [].
            Then pnpm --filter @md-reader/core test (full count) and pnpm --filter @md-reader/core typecheck.
