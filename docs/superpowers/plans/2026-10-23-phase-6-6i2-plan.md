### [x] 6i2.1 — computeLineDiff: trim common ends, Myers on the middle, line numbers
FILES       packages/core/src/diff/diff.ts
            packages/core/src/diff/diff.test.ts
INTERFACES  `computeLineDiff(original: string, modified: string): DiffLine[]` — same signature, same
            ordering contract as today (document order; for a changed block, removed lines before
            added lines — check what the current tests expect and keep it). Algorithm: split on '\n'
            (empty string → []), strip common prefix and suffix lines (emitted as 'same'), Myers
            O((N+M)·D) greedy diff with backtracking on the middle. Every DiffLine gets `lineNumber`:
            1-based line in `modified` for 'same' and 'added', in `original` for 'removed'.
            detectConflict unchanged.
INVARIANTS  - packages/core is pure TS: no react, no chrome.*, no document.
            - No new dependency.
TEST        pnpm --filter core test src/diff
            All existing cases pass unchanged. Add: lineNumber values on a small mixed diff; 20 000-line
            text with 3 single-line edits spread out → finishes < 200 ms (performance.now) and output has
            exactly 3 removed + 3 added lines; identical inputs → all 'same'; one side empty.
            Then `pnpm --filter core test` and `pnpm --filter ui test` (ConflictModal uses it); report both.
COMMIT      perf(core): Myers line diff with common-affix trimming and line numbers

### [x] 6i2.2 — bound Myers memory
FILES       packages/core/src/diff/diff.ts
            packages/core/src/diff/diff.test.ts
INTERFACES  Myers search stops when D exceeds `MAX_EDIT_DISTANCE = 2000` (module constant, not exported
            unless tests need it — then export it). On overflow the trimmed middle is emitted as all its
            original lines 'removed' then all modified lines 'added' (with correct lineNumbers). Output stays a
            valid diff (applying it reproduces both sides); it just isn't minimal.
INVARIANTS  - Same signature/ordering contract; packages/core pure TS.
TEST        pnpm --filter core test src/diff
            two completely different 20 000-line texts → returns within 500 ms; every original line appears once
            as removed and every modified line once as added; existing cases unchanged. Then `pnpm --filter core test`.
COMMIT      perf(core): cap Myers edit distance to bound memory on unrelated texts
