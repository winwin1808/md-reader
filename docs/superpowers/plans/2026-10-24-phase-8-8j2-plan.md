### [x] 8j2.1 — core: registerActor must not race the owner's actors map
parallel-group: a
FILES       packages/core/src/doc/checkpoint.ts · packages/core/src/doc/actor.test.ts
INTERFACES  `export function registerActor(doc: Y.Doc, name: string): void` keeps its signature (checkpoint.ts:79).
BEHAVIOR    - Today, when `meta.actors` is not a Y.Map, registerActor creates `new Y.Map` and sets it on meta. In a joiner doc that has not synced yet (meta has no `formatVersion`), this races the owner's own `actors` map. Y.Map LWW on the key `actors` then drops one side's names.
            - New rule: if `meta.actors` is not a Y.Map AND meta has no `formatVersion`, do NOT create the map. Instead attach a one-shot `meta.observe` handler. When `actors` becomes a Y.Map, it sets `String(doc.clientID) → name` and unobserves itself.
              - If registerActor is called again before then, only the latest name is written. Keep one pending handler per doc, e.g. a WeakMap<Y.Doc, {name, handler}>.
            - Existing behavior is unchanged when the map exists, and when formatVersion exists. That includes the legacy plain-object migration branch.
INVARIANTS  - Y.Doc is the source of truth. Schema: Y.Text "source" · Y.Map "meta" · Y.Array "history". formatVersion is present from creation; a schema change needs a migration.
            - packages/core is pure TS. yjs is allowed; no react, chrome.*, document, and no provider.
            - Never overwrite shared structure a remote peer may own. Create the meta sub-maps only in a doc initialised locally (with formatVersion).
TEST        Add to packages/core/src/doc/actor.test.ts:
            - (a) Joiner doc B is empty. registerActor(B,'Bình') runs before sync. Owner doc A is initialised and calls registerActor(A,'An'). Exchange updates both ways (Y.encodeStateAsUpdate / applyUpdate). Both docs' actors must contain both clientIDs with the right names. RED on current code.
            - (b) registerActor twice before sync → only the last name is written.
            - (c) An initialised doc still registers synchronously.
            Run: pnpm --filter @md-reader/core test, then pnpm -r typecheck.
COMMIT      fix(core): registerActor chờ map actors của chủ khi doc chưa khởi tạo — không mất tên (8j2)
