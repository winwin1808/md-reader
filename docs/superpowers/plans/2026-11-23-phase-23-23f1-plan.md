- Mô tả tiếng Anh:
  - list_comments: "List reviewer comments on a document (open ones by default). Each has quote (text when commented), currentText and line (where that text is now; null if it was deleted), body and replies.   - reply_comment: "Reply to a comment thread without resolving it. Use to ask a question or explain why you did not change something."
  - resolve_comment: "Mark a comment thread resolved after you addressed it. Pass reply to leave a short note of what you changed (posted before resolving)."
