### [x] 21b2.1 — `unpairIdentity` + `runCli(['unpair'])`
FILES       packages/mcp/src/pairing.ts · packages/mcp/src/pairing.test.ts · packages/mcp/src/cli.ts · packages/mcp/src/cli.test.ts
INTERFACES  Sinh ra:
            ```ts
            // pairing.ts
            export async function unpairIdentity(path: string = defaultPairPath()): Promise<'unpaired' | 'not-paired' | 'missing'>
            // cli.ts
            export async function runCli(argv: readonly string[], deps?: { stderr?: NodeJS.WritableStream; pairPath?: string }): Promise<'serve' | 'done'>
            ```
            `unpairIdentity`: chạy trong `withLock(path, …)`; dùng `readState(path)`: `reason === 'missing'` → `'missing'`; file đọc được nhưng không hợp lệ (`file === null`, reason khác `'missing'`) → `throw new Error('pairing file unreadable')`; `file.extKey === undefined` → `'not-paired'`; có `extKey` → `writeAtomic(path, <file không còn thuộc tính extKey, giữ nguyên version/privateKey/publicKey>)` → `'unpaired'`.
            `runCli(argv)`: `argv[0] === 'unpair'` → gọi `unpairIdentity(deps.pairPath)`, ghi đúng MỘT dòng ra `deps.stderr ?? process.stderr` rồi trả `'done'` mà KHÔNG gọi `main()`: `'unpaired'` → `le-sach-mcp: đã bỏ ghép cặp — khởi động lại ứng dụng AI rồi bấm Kết nối trong MD Reader (Cài đặt → Kết nối AI)`; `'not-paired'`/`'missing'` → `le-sach-mcp: chưa ghép cặp với MD Reader nào`. `argv` khác → trả `'serve'` (không làm gì khác).
            Khối direct-run cuối `cli.ts` đổi thành: `runCli(process.argv.slice(2))` → nếu `'serve'` thì gọi `main()` như hiện nay (giữ nguyên xử lý lỗi hiện có); nếu `'done'` thì kết thúc; lỗi của `runCli` → in ra stderr và `process.exitCode = 1`.
INVARIANTS  Bỏ ghép KHÔNG được đổi khoá máy chủ (`privateKey`, `publicKey` giữ nguyên byte-for-byte) — extension đã duyệt khoá đó không phải duyệt lại.
            File ghép cặp luôn ghi nguyên tử và quyền 0600 (dùng `writeAtomic` sẵn có), dưới `withLock`.
            `unpair` không mở cổng, không khởi động máy chủ MCP, không ghi gì ra stdout (stdout dành cho giao thức MCP stdio).
            Không đổi `VERSION` (việc của 21e2). Không thêm dependency.
