## Phase con này làm gì

Package thứ ba và cuối của khối scaffold: `@md-reader/extension`. Nó dựng
**khung build đa entry** (app page / service worker / content script) mà
1g1/1g2/1g3/1h1 sẽ điền, cộng một test smoke thuần TS. Đây là lớp DUY NHẤT
được phép gọi `chrome.*`.

**Không** viết `manifest.json`, service worker thật, app page hay content
script — đó là 1g1 trở đi. Ba entry được khai sẵn trong `vite.config.ts` nhưng
để dạng comment cho tới khi file tồn tại; build phải xanh ở phase con này.

## Version đã pin (đo trên registry hôm nay)

`vite@8.2.2` · `@types/chrome@0.2.9` · `y-indexeddb@9.0.12` ·
`react@19.3.0` + `react-dom@19.3.0` (**bắt buộc khớp `packages/ui`**, xem
INVARIANTS) · `yjs@13.6.32` (khớp `packages/core`).

## Đã loại — `@crxjs/vite-plugin`

Nó tự sinh manifest và tự inject content script; tiện, nhưng che mất đúng ba
thứ phase 1 phải kiểm bằng mắt: manifest tối thiểu, ranh giới entry, và kích
thước bundle content script (cổng 60KB gz ở 1h2). Manifest viết tay + copy là
~10 dòng config. MV3 support của plugin đó cũng từng vỡ theo bản Chrome.

## BLOCKER — review 1b4 dừng ở đây (2026-09-10)

`reviewer` trả **4 CONFIRMED**, chứng minh bằng build thật (bỏ comment 3 entry,
cho `content.ts` import React, chạy `vite build`):

1. **`chunkFileNames` dùng chung cho mọi entry** → Rollup tách chunk vendor
   `react.js` mà `content.js` `import`. Đo được: `dist/content.js` =
   `import{t as e}from"./react.js"`, `react.js` ~8.4KB (3.23KB gz) **kéo React
   runtime vào content script**. Ngân sách 60KB gz ở 1h2 chết từ khung build.
2. **`format: 'es'` áp cho MỌI entry, gồm content script.** MV3 content script
   không nạp được ES module (`content_scripts` không có `type: "module"`).
   `dist/content.js` build ra có `import` ở đầu → Chrome báo
   `Cannot use import statement outside a module`. 1h1 vỡ ngay.
3. **`rollupOptions.output` là một khối chung cho cả 3 input** trong cùng một
   lệnh `vite build`; không có cách set format/chunking khác nhau theo entry.
   Nghĩa là 1g1/1g2/1h1 **không thể chỉ "bỏ comment" input** như plan này ngụ
   ý — phải tách build.
4. *(ghi chú, không phải lỗi)* entry HTML `app` sinh thêm
   `dist/src/app/index.html` giữ nguyên path nguồn, không phẳng như hai JS
   entry. 1g2 cần rewrite hoặc chuyển path `index.html` lên gốc `src/`.

Build hôm nay vẫn xanh **chỉ vì chưa có entry thật nào** — đó là lý do lỗi này
lọt qua TEST của 1b4.

**Hướng sửa đề xuất (chưa áp dụng):** tách content script thành build riêng —
`format: 'iife'`, `inlineDynamicImports: true`, không chia sẻ
`rollupOptions.output` với app page — và giữ app/worker ở build ESM hiện tại.
Cần thêm một task vào 1b4 hoặc chuyển thành ràng buộc cứng cho 1h1.
