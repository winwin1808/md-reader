### [ ] 23a2-2 — `FORMAT_VERSION = 3` + migration v2→v3
FILES       packages/core/src/doc/schema.ts, packages/core/src/doc/doc.ts, packages/core/src/doc/doc.test.ts, packages/core/src/doc/migrate.test.ts, packages/core/src/doc/compact.test.ts
INTERFACES
```ts
export const FORMAT_VERSION = 3                       // schema.ts
migrateDoc(doc: Y.Doc): { from: number; to: number }  // doc.ts — chữ ký không đổi
```
(consume) `COMMENTS_ROOT` = `'comments'` từ `../comments/comments.js` nếu cần tham chiếu tên root.
Hành vi:
- `schema.ts`: `FORMAT_VERSION = 3`. Ghi chú (comment) cạnh hằng: v3 thêm root `Y.Map "comments"` tạo lười. **Không** thêm `comments` vào danh sách khoá mà hàm khởi tạo doc tạo sẵn nếu danh sách đó (`DOC_KEYS`) đang quyết định số root được khởi tạo — `doc.test.ts:61` ("exactly 3 keys") phải vẫn đúng với 3 khoá; chỉ đổi phần "formatVersion === 2" → 3 trong tên/kỳ vọng.
- `migrateDoc`: v2 → v3 chỉ đặt `meta.formatVersion = 3`, không tạo/sửa root nào khác. v1 → v3 chạy migration v1→v2 hiện có rồi v2→v3, trả `{from:1,to:3}`. v3 → `{from:3,to:3}`, không ghi gì. Version > 3 giữ hành vi hiện có (lỗi / tolerateNewer như đang làm).
- Cập nhật test cứng số 2 → 3: `doc.test.ts` dòng 23, 61, 67, 82, 102, 257 và thông điệp ở dòng 37 nếu nó phụ thuộc max version; `compact.test.ts:24`; `migrate.test.ts:31` (v1 migrate giờ kết thúc ở 3).
- `migrate.test.ts`: mở rộng test fixture của 23a2-1: sau `migrateDoc` → `{from:2,to:3}`, `meta.formatVersion === 3`, `source`/`history`/`actors` nguyên vẹn, `listThreads(doc)` (từ `../comments/comments.js`) = `[]`; gọi `migrateDoc` lần hai → `{from:3,to:3}` và state vector không đổi (không ghi thêm).
INVARIANTS
- Y.Doc là nguồn sự thật. Đổi schema sau khi có dữ liệu bắt buộc kèm migration + test fixture cũ; `formatVersion` phải tăng khi thêm root mới.
- `packages/core` thuần TS: chỉ `yjs`; KHÔNG react, `chrome.*`, `document`/`window`, Yjs provider.
- Migration chỉ chạy ở extension (chủ tài liệu); peer web không migrate — nên migration v2→v3 phải là thao tác không phá dữ liệu, idempotent.
- Không đổi chữ ký hàm export nào. Không thêm dependency.
TEST        pnpm --filter core test && pnpm --filter core typecheck

### [ ] 23a2-3 — Làm gọn tài liệu giữ bình luận (neo lại trên Y.Text mới)
