### [ ] 10j.1 — `tools.ts`: đăng ký 7 tool trên bridge
FILES       packages/mcp/src/tools.ts · packages/mcp/src/tools.test.ts
INTERFACES  Tiêu thụ: `BridgeServer`, `BridgeCallError` (./bridge-server); từ `@md-reader/core/bridge`: `validateToolArgs`, `BRIDGE_MAX_TITLE`,
            `BRIDGE_MAX_MARKDOWN`, `BridgeTool`, các kiểu Args/Result.
            ```ts
            export type BridgeLike = Pick<BridgeServer, 'call'>
            export function registerTools(server: McpServer, bridge: BridgeLike): void
            ```
            7 tool, `inputSchema` là shape zod (zod 4) khớp giới hạn core:
            - `publish_doc` { title: string 1..200, markdown: string ≤2 000 000, open?: boolean } — "Create a new document in the MD Reader
              Chrome extension on this computer and open it in a tab. The document stays on this computer; nothing is uploaded. Returns docId."
            - `list_docs` {} — "List documents stored in MD Reader on this computer (id, title, last opened, whether shared)."
            - `get_doc` { docId } — "Read the current Markdown of a document, including edits made by collaborators. Returns markdown and a hash to pass to update_doc."
            - `update_doc` { docId, markdown, baseHash } — "Replace the document's Markdown. Pass baseHash from get_doc; if the document changed since,
              the call fails with CONFLICT — call get_doc again and retry. Only the changed parts are written."
            - `share_doc` { docId, role?: 'view'|'edit' (mặc định 'view'), expiresInDays?: 7|30|null (mặc định 7) } — "Ask the user to create a share
              link. MD Reader shows a confirmation dialog; nothing is shared unless the user clicks Allow. Returns the link URL."
            - `list_links` { docId } — "List share links of a document (prefix, role, expiry, revoked)."
            - `revoke_link` { docId, tokenPrefix: string length 6 } — "Ask the user to revoke a share link (confirmation dialog in MD Reader)."
            Handler chung: `v = validateToolArgs(tool, args)` → sai: kết quả lỗi `INVALID_ARGS: <message>`; đúng → `await bridge.call(tool, v.args)`
            → `{ content: [{ type: 'text', text: JSON.stringify(result, null, 2) }] }`. `BridgeCallError` → `{ isError: true, content: [{ type: 'text',
            text: \`${code}: ${message}\` }] }`; lỗi khác → `INTERNAL: <message>`. Không ném lỗi ra SDK.
            Test (viết trước; `McpServer` + `Client` nối bằng `InMemoryTransport.createLinkedPair()`, bridge giả ghi lại lời gọi):
            `listTools` có đúng 7 tên; `callTool('publish_doc', …)` → bridge nhận đúng tool + args đã validate (title trim), kết quả text là JSON;
            bridge ném `BridgeCallError('CONFLICT', 'x')` → `isError` + text `CONFLICT: x`; `share_doc` thiếu role/expiresInDays → bridge nhận
            `role:'view', expiresInDays:7`; `tokenPrefix` dài 5 → lỗi (SDK hoặc INVALID_ARGS), bridge không bị gọi.
INVARIANTS  `packages/mcp`: KHÔNG react / `chrome.*` / `document`; import core chỉ qua `@md-reader/core/bridge`.
            Không ghi stdout (stdout là kênh giao thức MCP). Không thêm dependency.
            Mô tả tool phải nói rõ: tài liệu nằm trên máy người dùng; share/revoke cần người dùng bấm đồng ý.
