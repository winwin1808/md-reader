Goal: in the editor and split modes, the owner can toggle "Người viết". Each line then gets a tone bar for the person who wrote most of it, with their name on hover. The toggle is off by default.

Decision (deviation from the spec's `BlameGutter` React component): the gutter is a CodeMirror `gutter()` extension inside `Editor`, driven by an `Editor` prop. A React column beside CodeMirror can't stay aligned with wrapped lines or scrolling. A CM gutter is aligned by construction, and `lineNumbers()` already uses the same mechanism. The tested pure part is `lineAuthors()`.

Facts (guard):
- Editor.tsx is 159 lines. It already has `lineNumbers()` and exposes `editorViewRef`/`onEditorReady`, and its wrapper takes a className.
- TopToolbar `actions: ToolbarAction[]`, where `ToolbarAction { id; label; icon: IconName; onSelect }`; in narrow mode they go to an overflow menu.
- IconName has no person/users icon.
- App.tsx: `viewMode` state ('reading'|'editor'|'split'); toolbarActions at ~466-470; Editor sites at ~675 and ~688; `doc` and `yText` are destructured from the session (~146).
- `--peer-1..6` are in every theme block.

FILES       packages/ui/src/components/blame.ts (new) · packages/ui/src/components/blame.test.ts (new) · packages/ui/src/components/Editor.tsx · packages/ui/src/index.ts · packages/ui/src/theme/tokens.css
INTERFACES  consumes: `BlameRange { from; to; clientId; actor: string | null }` from @md-reader/core (8f1); `peerColor(clientId)` from './PresenceBar'.
            produces (blame.ts, re-exported from index.ts):
            export interface LineAuthor { clientId: number; actor: string | null }
            export function lineAuthors(ranges: BlameRange[], text: string): Array<LineAuthor | null>
            export function blameGutter(lines: Array<LineAuthor | null>): Extension   // @codemirror/view gutter()
            Editor: `EditorProps` gains `blame?: Array<LineAuthor | null> | null`. It is held in a `Compartment`; when the prop changes, `view.dispatch({ effects: compartment.reconfigure(blame ? blameGutter(blame) : []) })`. Changing it must NOT rebuild the view, so do not add it to the main effect deps.
BEHAVIOR    - lineAuthors:
              - Split the text on '\n'. Line i covers [start, end), with the newline counted toward the line it ends.
              - Each line's author is the clientId with the most characters overlapping it. Ties go to the earliest range.
              - An empty line with no overlap gets the author of the range containing its start offset, or null if there is none.
              - The result length equals the line count.
            - blameGutter:
              - class "cm-blame-gutter"
              - for line n (1-based doc line), the marker is `lines[n-1]`
              - a null marker, or an n past the end, renders nothing
              - a GutterMarker renders `<span class="cm-blame-mark" style="--peer: var(--peer-N)" title="<actor ?? 'Không rõ'>">`, with the colour from peerColor and the title set as an attribute, never as innerHTML
              - Markers with the same author compare equal (`eq`), so they are reused
            - tokens.css: .cm-blame-gutter is 6px wide. .cm-blame-mark is a 3px bar of `var(--peer, var(--pencil))` at full line height with 1px radius.
            - The blame array can be stale relative to the doc for up to 300 ms while the caller recomputes. Lines beyond its length render nothing.
INVARIANTS  - packages/ui is React. It never uses chrome.* and never imports a Yjs provider.
            - Import @md-reader/core by its workspace name.
            - Names are user-supplied, so set them only as text or attributes.
            - When the blame prop is absent, the Editor behaves exactly as today. Existing Editor tests pass unchanged.
            - Do not add new dependencies (`@codemirror/view` and `@codemirror/state` are already deps).

              - ranges [] → all null

### [ ] 8f2.2 — extension: "Người viết" toggle

INTERFACES  consumes: `computeBlame(doc)` from @md-reader/core; `lineAuthors` and `LineAuthor` from @md-reader/ui; the Editor `blame` prop (8f2.1).
            Icon.tsx: add `'person'` to `IconName`, with a simple stroke SVG (head circle and shoulders arc) in the same style as the existing icons.
BEHAVIOR    - App state is `const [blameOn, setBlameOn] = useState(false)`.
            - When `viewMode !== 'reading'`, add a toolbar action `{ id: 'blame', label: blameOn ? 'Ẩn người viết' : 'Hiện người viết', icon: 'person', onSelect: () => setBlameOn(v => !v) }` to toolbarActions, before 'settings'.
            - While blameOn is true and the mode is editor or split:
              - compute `lineAuthors(computeBlame(doc), yText.toString())` once immediately

              - also recompute on `doc.getMap('meta')` deep changes, since actor names can arrive later
              - unsubscribe and clear the timer on cleanup or when toggled off
            - Pass `blame={blameOn ? lines : null}` to BOTH Editor sites.
            - Turning blame off sets lines to null.
            - Not persisted: it resets to off on reload.
INVARIANTS  - apps/extension is the only layer that uses chrome.*. Cross-package imports use workspace names.
            - The Y.Doc is read-only here. computeBlame never writes.
            - The Editor's awareness and other props stay stable, because changing blame must not rebuild the editor.
            - Existing App tests pass unchanged.
TEST        - Run pnpm --filter @md-reader/extension test src/app/App.test.tsx. Add:

              - In editor mode the action exists.
              - Clicking it renders at least one .cm-blame-mark, with fake timers advanced as needed.
