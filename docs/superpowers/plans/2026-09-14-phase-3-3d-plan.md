- In `apps/extension/src/app/App.tsx`:
  - Check query parameter on load: `const isSpeakerMode = new URLSearchParams(window.location.search).get('speaker') === 'true'`.
  - Parse slides with `useMemo(() => splitIntoSlides(content), [content])`.
  - State: `isPresenting: boolean` (default `false`), `currentSlideIndex: number` (default `0`).
  - BroadcastChannel synchronization:
    - Create `BroadcastChannel('md-reader-slides-sync')` on mount.
    - Post message on slide change: `channel.postMessage({ type: 'NAVIGATE', index })`.
    - Listen to messages: update `currentSlideIndex` when received.
  - If `isSpeakerMode`:
    - Render `<SpeakerView slides={slides} currentSlideIndex={currentSlideIndex} onSlideChange={(idx) => { setCurrentSlideIndex(idx); channel.postMessage({ type: 'NAVIGATE', index: idx }) }} />`.
  - Keyboard shortcut `p` or `P`:
    - If user presses `p` while not in input/textarea, and not already presenting, toggle `isPresenting(true)`.
  - When presenting in regular mode:
    - Render `<Deck slides={slides} initialSlide={currentSlideIndex} onClose={() => setIsPresenting(false)} onSlideChange={(idx) => { setCurrentSlideIndex(idx); channel.postMessage({ type: 'NAVIGATE', index: idx }) }} onOpenSpeakerView={() => window.open(window.location.pathname + '?speaker=true' + (fileUrlParam ? '&file=' + encodeURIComponent(fileUrlParam) : ''), 'md-speaker', 'width=1080,height=680')} colorTheme={colorTheme} mode={themeMode} />`.
  - Pass `onPresent={() => setIsPresenting(true)}` to `TopToolbar`.
