## Phase con này làm gì

Xây dựng module tự động định dạng Markdown (`formatMarkdown`) trong `@md-reader/core`:
1. Định nghĩa `FormatOptions` và hằng số `defaultFormatOptions` với cấu hình chuẩn hoá mặc định: `bullet: '-'`, `emphasis: '_'`, `strong: '*'`, `fences: true`, `listIndent: 'one'`, `printWidth: 0`.
2. `formatMarkdown(source, options)`: sử dụng pipeline `remark-parse` (qua `parseMarkdown`) + `remark-gfm` + `remark-stringify` để format lại AST markdown.
3. Bảo toàn nguyên văn phần YAML Frontmatter ở đầu file (không reformat qua parser YAML để tránh diff không mong muốn).
4. Đảm bảo tính chất **Idempotence** (định dạng 2 lần cho cùng kết quả: `format(format(x)) === format(x)`).
5. Error handling an toàn: không bao giờ throw lỗi; không bao giờ làm mất nội dung (nếu format sinh ra chuỗi rỗng khi input không rỗng, hoặc gặp lỗi không xác định, lập tức trả về `source` nguyên bản).

- `unified@11.0.5`

                     emphasis: opts.emphasis,
                     strong: opts.strong,
                     fences: opts.fences,
                     listItemIndent: opts.listIndent,
                     lineWidth: opts.printWidth > 0 ? opts.printWidth : Infinity,

              4. Ghép lại chuỗi output:

                   let result = rawFrontmatter.endsWith('\n') ? rawFrontmatter : rawFrontmatter + '\n'
                   if (formatted.length > 0) {

                   }
                 - Nếu không có rawFrontmatter:
                   let result = formatted.length > 0 ? formatted + '\n' : ''
              5. Error handling & Content safety:
