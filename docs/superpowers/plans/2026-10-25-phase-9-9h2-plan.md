            core: API_PATHS.assets(roomId) = `/api/rooms/${roomId}/assets`, API_PATHS.asset(id) = `/api/a/${id}`;
              `interface UploadAssetResponse { id: string; url: string; size: number; mime: string }`; `MAX_ASSET_BYTES = 2 * 1024 * 1024`;
              `ROOM_ASSET_QUOTA = 50 * 1024 * 1024`; `ASSET_MIME = ['image/png','image/jpeg','image/gif','image/webp'] as const`.
            AssetStore: put(roomId, mime, bytes: Uint8Array) → {id,size}; get(id) → {mime, bytes} | null; roomUsage(roomId) → number.
              id = 128-bit random b64url. D1 put: insert asset row + chunks (1 MiB each) in one db.batch().
            POST /api/rooms/:room/assets: auth via `Authorization: Bearer <token>` where token is the owner token (verifyOwner) or a link
              token resolving to {roomId === :room, role 'edit'}; else 403. Body = raw bytes, Content-Type must be in ASSET_MIME (415
              otherwise); sniff magic bytes match the declared type (png 89504E47, jpeg FFD8FF, gif 47494638, webp RIFF....WEBP) else 415;
              > MAX_ASSET_BYTES → 413 {error:'too_large'}; usage + size > ROOM_ASSET_QUOTA → 413 {error:'quota'}; 201 UploadAssetResponse
              with absolute url (origin of the request + API_PATHS.asset(id)).
            GET /api/a/:id: 200 bytes, Content-Type mime, `Cache-Control: public, max-age=31536000, immutable`,
              `X-Content-Type-Options: nosniff`, `Content-Security-Policy: default-src 'none'`; 404 unknown. CORS: allow GET from any origin
              (images in extension pages / web); POST CORS same as existing routes.
