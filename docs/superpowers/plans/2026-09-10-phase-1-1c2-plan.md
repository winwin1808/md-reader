## Phase con này làm gì

Xây dựng tầng render từ AST (`mdast`) ra HTML string và trích xuất cây mục lục (ToC) trong `@md-reader/core`:
1. `extractToc(tree: Root): TocEntry[]`: trích xuất cây ToC phân cấp từ các heading trong mdast, tính toán heading `id` khớp chính xác với thuật toán của `rehype-slug` (chuẩn github-slugger), hỗ trợ heading nhảy bậc (h1 -> h3 thành con trực tiếp của h1).
2. `HIGHLIGHT_LANGUAGES`: danh sách 14 ngôn ngữ highlight được đăng ký tường minh trong phase 1 (`ts, tsx, js, jsx, json, bash, css, html, md, yaml, python, go, sql, diff`).
3. `renderToHtml(parsed: ParseResult, options?: RenderOptions): RenderResult`: pipeline unified chuyển `mdast → remarkRehype → rehypeSlug → [rehypeHighlight] → rehypeSanitize(sanitizeSchema) → rehypeStringify`. `rehypeSanitize` luôn chạy trước khi ra chuỗi HTML để bảo mật.

            Chi tiết thực thi renderToHtml:
              - options.highlight mặc định true.
              - options.allowRawHtml mặc định false.
              - Gọi toc = extractToc(parsed.tree).
              - Khởi tạo unified processor:
                  processor.use(remarkRehype, { allowDangerousHtml: allowRawHtml })
                  processor.use(rehypeSlug)
              - Nếu highlight !== false:
                  processor.use(rehypeHighlight, {
                    // chỉ highlight nếu thuộc registry hoặc plainText fallback
                  })

                  const schema = allowRawHtml
                    ? {
                        ...sanitizeSchema,
                        attributes: {
                          ...sanitizeSchema.attributes,
                          '*': [...(sanitizeSchema.attributes?.['*'] ?? []), 'style', 'className'],
                        }
                      }
                    : sanitizeSchema

              - processor.use(rehypeStringify, { allowDangerousHtml: allowRawHtml })
              - const file = processor.processSync(parsed.tree)
              - const html = String(file)
              - return { html, toc }
              - Error handling: không throw với bất kỳ mdast hợp lệ nào. Code block lang lạ, link javascript: đều degrade im lặng.
