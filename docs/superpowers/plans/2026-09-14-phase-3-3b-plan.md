INVARIANTS
- `packages/ui` is pure React and CSS. NO `chrome.*` APIs, NO node modules.
- Responsive 16:9 slide container:
  - Fixed full viewport overlay: `position: fixed; inset: 0; z-index: 1000; background: var(--md-bg); color: var(--md-fg); display: flex; flex-direction: column; justify-content: center; align-items: center; overflow: hidden;`.
  - Slide canvas (`.deck-slide`): `aspect-ratio: 16/9; width: 90vw; max-width: 1400px; height: auto; max-height: 85vh; padding: 48px; box-sizing: border-box; display: flex; flex-direction: column; justify-content: center; overflow-y: auto;`.
  - Reuse `.md-viewer` class inside `.deck-slide` to inherit typography, syntax highlighting, and table styling.
- Keyboard navigation:
  - Next: ArrowRight, ArrowDown, PageDown, Space.
  - Prev: ArrowLeft, ArrowUp, PageUp, Backspace.
  - Home: first slide (`index = 0`).
  - End: last slide (`index = slides.length - 1`).
  - Esc: calls `props.onClose()`.
  - Do not trigger keyboard navigation if focus is inside an input, textarea, or button.
- Bottom floating bar (`.deck-controls`):
  - Slide counter `Slide ${currentIndex + 1} / ${totalSlides}`.
  - Prev button `←` (aria-label="Slide trước", disabled on first slide).
  - Next button `→` (aria-label="Slide kế tiếp", disabled on last slide).
  - Speaker View button `🎙` (aria-label="Giao diện diễn giả", title="Mở chế độ diễn giả", onClick calls `props.onOpenSpeakerView`).
  - Exit button `✕` (aria-label="Thoát trình chiếu", title="Thoát (Esc)", onClick calls `props.onClose`).
- Bottom progress bar (`.deck-progress-bar`):
  - Fixed at bottom: `position: absolute; bottom: 0; left: 0; height: 4px; background: var(--md-accent, #0969da); transition: width 0.2s ease;`.
  - Width: `((currentIndex + 1) / totalSlides) * 100%`.
- In `packages/ui/src/viewer.css`: Add `@import './theme/deck.css';`.
- Export `Deck`, `DeckProps` from `packages/ui/src/index.ts`.
