INVARIANTS
- Packages boundary: `packages/core` is pure TypeScript (NO React, NO `chrome.*`, NO DOM/`window`/`document`, NO Yjs provider).
- In `packages/core/src/render/types.ts`:
  - Export `RenderOptions` interface.
- In `packages/core/src/render/options.ts`:
  - `applyTypographer(html: string): string`:
    - Replaces `(c)`/`(C)` → `©`, `(tm)`/`(TM)` → `™`, `(r)`/`(R)` → `®`, `---` → `—`, `--` → `–`.
    - Handles smart quotes (`"` → `“` / `”`, `'` → `‘` / `’`) in text nodes while preserving `<pre>`, `<code>`, `<script>`, `<style>`, and SVG tags.
  - `applyExternalLinks(html: string): string`:
    - Finds external `<a href="https?://..."` that don't already have `class="external-link"`.
    - Adds `class="external-link" target="_blank" rel="noopener noreferrer"`.
    - Appends a subtle external link indicator SVG `<svg class="external-link-icon" ...>`.
  - `applyGitHubAlerts(html: string, locale?: string): string`:
    - Recognizes `<blockquote>\s*<p>\s*\[!(NOTE|TIP|IMPORTANT|WARNING|CAUTION)\]` (case-insensitive).
    - Replaces with `<div class="markdown-alert markdown-alert-{type}" role="region" aria-label="{title}"><p class="markdown-alert-title"><svg ...></svg><span>{title}</span></p>...</div>`.
    - Localizes titles if `locale === 'vi'`: NOTE → Ghi chú, TIP → Mẹo, IMPORTANT → Quan trọng, WARNING → Cảnh báo, CAUTION → Chú ý. Default English: Note, Tip, Important, Warning, Caution.
  - `processFrontmatter(source: string, options?: RenderOptions): { cleanMarkdown: string, metadataHtml?: string }`:
    - Detects leading `---` frontmatter block.
    - If `stripFrontmatter: true` (or `displayMetadata: true`), strips frontmatter from source so it is not rendered as raw hr/text.
    - If `displayMetadata: true`, formats key-values into `<div class="markdown-metadata-card">...</div>`.
- In `packages/core/src/render/render.ts`:
  - Accept `options?: RenderOptions` in `renderToHtml`.
  - Pipeline applies `processFrontmatter`, `applyGitHubAlerts`, `applyExternalLinks`, `applyTypographer` in order.
- In `packages/core/src/index.ts`:
  - Export `RenderOptions`, `applyTypographer`, `applyExternalLinks`, `applyGitHubAlerts`.
- In `packages/core/src/render/render-options.test.ts`:
  - Test typographer replacements and preserving code blocks.
  - Test GitHub alerts transformation and localization.
  - Test external link detection and icon attachment.
  - Test frontmatter stripping and metadata card generation.
