INTERFACES  `export type ImageSaver = (file: File) => Promise<{ src: string; note?: string }>` (exported via the editor subpath).
            `export function pasteImages(save: ImageSaver, opts?: { onError?(message: string): void; onNote?(message: string): void }): Extension`
              — EditorView.domEventHandlers for paste and drop: take File items with type in ASSET_MIME (ignore others → default
              behaviour); for each: insert a placeholder `![Đang tải ảnh…]()` at the drop/caret position (one change, userEvent
              'input.image'), call save(file); on success replace the placeholder range (tracked through changes with a StateField or
              mapPos) with `![<name without ext>](<src>)`; on failure remove the placeholder and call onError(message). Files >
              MAX_ASSET_BYTES are passed to save anyway (the saver decides: downscale or refuse).
            `export async function toDataUrl(file: File, maxBytes = 1_000_000): Promise<string>` — if file.size ≤ maxBytes → FileReader data
              URL; else downscale with createImageBitmap + OffscreenCanvas (fallback HTMLCanvasElement) to fit maxBytes (JPEG quality 0.85,
              halve dimensions until under, max 4 tries; gif keeps first frame) — throws Error('Ảnh quá lớn') if still over.
            Editor props += `saveImage?: ImageSaver`, `onImageMessage?(m: string): void`; when saveImage is set and variant is live, add
              pasteImages(saveImage, …). Default when absent: no paste handling (unchanged behaviour).
INVARIANTS  - Y.Text only state; placeholder + final insert are normal text changes (collab-safe). packages/ui no chrome.*.
