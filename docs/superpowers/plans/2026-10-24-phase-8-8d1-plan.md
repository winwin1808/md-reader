# Plan: Phase 8 — 8d1 Presence UI
Author: Hao Nguyen. Status: reviewed. Phase: 8. Sub-phase: 8d1

Branch: phase-8-8d1-presence-ui
BranchPoint: aba6bd7

Goal: `@md-reader/ui` can show who is in the room and draw remote cursors. That means:
- a `PresenceBar` of initials avatars, with the self avatar first
- a deterministic `peerColor` in six Lề sách ink tones
- an `awareness` prop on `Editor` that is passed through to yCollab
- a `presence` prop on `TopToolbar`

Wiring the real awareness into the apps belongs to 8d2. This sub-phase also closes the test gaps 8c2's review left in apps/web.

Decisions:
- `peerColor(clientId)` returns `var(--peer-N)` with N = (clientId mod 6) + 1. The tones live in tokens.css for every theme block, so the colours follow light, dark and high contrast. Inline styles accept var().
- The Editor's awareness prop is typed as `Parameters<typeof yCollab>[1]`, so ui needs no new y-protocols dependency.
