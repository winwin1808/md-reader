Goal: one real-browser test of the whole sharing loop, entirely local:
- the extension app turns sharing on for a doc and makes an edit link
- a second (plain) browser context opens the link and types
- the text appears in the extension, and presence shows 2

Facts (guard, phase-8 @ 71b4602):
- apps/extension/playwright.config.ts: `defineConfig({ testDir: 'e2e-pw', workers: 1, retries: 0, timeout: 30000, reporter: 'list' })`, no webServer.
- e2e-pw/fixtures.ts:
  - The `context` fixture is a launchPersistentContext with `--load-extension=dist`, headless new.
  - The `extensionId` fixture comes from the service worker URL.
  - The `server` fixture is a local http server on a random port serving .md files from a tmp dir.
  - smoke.spec.ts uses an `openViaContentScript` helper to open a doc in the app.
- apps/api:
  - scripts: `dev`: "wrangler dev --port 8787"; `build`: "wrangler deploy --dry-run --outdir dist"
  - wrangler 4.152.0 installed locally
  - wrangler.jsonc:
    - DO `DOC_ROOM`/DocRoom with a new_sqlite_classes migration
    - D1 binding `DB`, database_name "md-reader", migrations_dir "migrations" (0001_init.sql)
    - assets `{ directory: "../web/dist", binding: "ASSETS", not_found_handling: "single-page-application", run_worker_first: ["/api/*", "/parties/*"] }`
  - So the Worker on :8787 serves the web app too.
- Share URL: `buildShareUrl(serverUrl, token)` = `${serverUrl}/s/${token}`. serverUrl comes from Settings "Máy chủ đồng bộ" (input id settings-serverUrl; http:// is allowed only for localhost), default https://md-reader-api.qhao-work.workers.dev. The web EditPage uses location.origin.
- UI strings:
  - Settings "Cộng tác": "Tên hiển thị" (#settings-displayName), "Máy chủ đồng bộ" (#settings-serverUrl). There is no enable toggle.
  - ShareModal: button "Bật chia sẻ"; radios name="share-role" labelled "Xem" / "Sửa"; submit "Tạo link"; readonly input aria-label "Link chia sẻ".
  - The web EditPage asks for a display name (stored in localStorage 'mdr.displayName'). The presence bar is PresenceBar.

### [x] 8j.1 — collab e2e over local wrangler dev
FILES       apps/extension/e2e-pw/collab.spec.ts (new) · apps/extension/playwright.collab.config.ts (new) · apps/extension/package.json
INTERFACES  package.json script: `"e2e:collab": "pnpm build && pnpm --filter @md-reader/web build && playwright test -c playwright.collab.config.ts"`. Match how the existing `e2e` script builds; if it already builds, mirror it.
BEHAVIOR    playwright.collab.config.ts:
            - testDir 'e2e-pw', testMatch 'collab.spec.ts', workers 1, timeout 60000.
            - webServer:
              - command: `pnpm --filter @md-reader/api exec wrangler d1 migrations apply md-reader --local --persist-to .wrangler-e2e && pnpm --filter @md-reader/api exec wrangler dev --local --port 8787 --persist-to .wrangler-e2e`
              - The persist dir is relative to apps/api (wrangler's cwd under `--filter exec`); use a fresh dir per run, e.g. rm -rf it first in the command.
              - url 'http://localhost:8787/api/health', reuseExistingServer: false, timeout 120000.
              - env `{ WRANGLER_SEND_METRICS: 'false' }`.
            - The existing playwright.config.ts must ignore collab.spec.ts (testIgnore) so `pnpm e2e` stays wrangler-free. That is the only allowed change to it, and it then becomes a 4th file; list it in NOTES.
            collab.spec.ts uses the existing fixtures (context, extensionId, server):
            1. Open a doc "# Cộng tác\n\nĐoạn đầu." in the app the same way smoke.spec opens one.
            2. Open Settings, set "Tên hiển thị" = "Chủ" and "Máy chủ đồng bộ" = "http://localhost:8787", then close.
            3. Open the share UI (the toolbar action that opens ShareModal; find its label in the app), click "Bật chia sẻ", pick "Sửa", click "Tạo link", and read the "Link chia sẻ" input value. Expect it to start with 'http://localhost:8787/s/'.
            4. Second browser: `const b = await chromium.launch()`, a new context with no extension. Open the link, answer the name prompt with "Khách", wait for the editor, and type " Khách gõ." at the end of the doc.
            5. Back in the extension page, expect " Khách gõ." to appear in the document (Viewer or editor) within 15s, and expect the presence bar to show 2 people (both names, or a count of 2).
            6. Close b.
            - Never print tokens. The link is used only in memory; do not console.log it.
            - Clean up the .wrangler-e2e dir after the run (globalTeardown, or the webServer command's leading rm).
INVARIANTS  - Fully local: wrangler runs with --local and never deploys. Do NOT source ~/.config/md-reader/cloudflare.env and do not set CLOUDFLARE_* variables. If wrangler insists on login or a network call for local dev, report BLOCKED with its message (≤5 lines).
            - Share tokens are secrets: never log, print or write them to files.
            - The existing `pnpm --filter @md-reader/extension e2e` must stay 5/5 and must not start wrangler.
            - Test-only plus config. No product code changes; if a product bug blocks the flow, report BLOCKED with evidence.
TEST        pnpm --filter @md-reader/extension e2e:collab (report the pass count and duration; run it twice). Then pnpm --filter @md-reader/extension e2e (5/5). Then `git status --short` must show no stray .wrangler-e2e or other artifacts (add to .gitignore only if unavoidable and say so).
