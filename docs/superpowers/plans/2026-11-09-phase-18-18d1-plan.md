### [x] 18d1.1 — `feedback.ts`: kiểm tra đầu vào và hai store
FILES       apps/api/src/feedback.ts · apps/api/src/feedback.test.ts · apps/api/migrations/0005_feedback.sql
INTERFACES  ```ts
            export const FEEDBACK_KINDS = ['uninstall', 'bug', 'idea'] as const
            export const UNINSTALL_REASONS = ['not_needed', 'missing_feature', 'bugs', 'hard_to_use', 'privacy', 'switched', 'other'] as const
            export const MAX_FEEDBACK_MESSAGE = 2000
            export const MAX_FEEDBACK_BODY = 8192
            export const FEEDBACK_TTL_MS = 180 * 86_400_000
            export const FEEDBACK_PRUNE_BATCH = 500
            export interface FeedbackInput {
              kind: (typeof FEEDBACK_KINDS)[number]
              reason: (typeof UNINSTALL_REASONS)[number] | null
              message: string
              email: string | null
              version: string | null
              browser: string | null
              locale: 'vi' | 'en' | null
            }
            export interface FeedbackRow extends FeedbackInput { id: number; createdAt: number }
            export function parseFeedback(body: unknown): FeedbackInput | null
            export interface FeedbackStore {
              add(f: FeedbackInput): Promise<void>
              list(opts: { limit: number; before?: number }): Promise<FeedbackRow[]>
              prune(beforeMs: number): Promise<number>
            }
            export class MemoryFeedbackStore implements FeedbackStore { constructor(now?: () => number) }
            export class D1FeedbackStore implements FeedbackStore { constructor(db: D1Database, now?: () => number) }
            ```
            `parseFeedback` (body đã `JSON.parse`): không phải object → null. `kind` không thuộc `FEEDBACK_KINDS` → null. `reason`: với `kind === 'uninstall'` bắt buộc thuộc `UNINSTALL_REASONS`, thiếu/lạ → null; với kind khác: thiếu/null → `null`, có mà lạ → null (cả input). `message`: chuỗi (thiếu → `''`), `trim()`; dài > `MAX_FEEDBACK_MESSAGE` → null; rỗng khi `kind !== 'uninstall'` → null. `email`: thiếu/`''`/null → `null`; khác chuỗi → null (cả input); `trim()`; không có `@` hoặc dài > 254 → null (cả input). `version`, `browser`: chuỗi → cắt 64 ký tự (rỗng → null); khác chuỗi/thiếu → `null`. `locale`: `'vi' | 'en'` giữ, khác → `null`. Trường thừa bị bỏ (không lưu gì khác).
            `list`: sắp `id` giảm dần, `limit` hàng, `before` → chỉ hàng `id < before`. `prune(beforeMs)`: xoá tối đa `FEEDBACK_PRUNE_BATCH` hàng có `createdAt < beforeMs` (cũ nhất trước), trả số hàng đã xoá.
            D1: bảng `feedback(id INTEGER PRIMARY KEY AUTOINCREMENT, kind TEXT NOT NULL, reason TEXT, message TEXT NOT NULL, email TEXT, version TEXT, browser TEXT, locale TEXT, created_at INTEGER NOT NULL)` + `CREATE INDEX feedback_created_idx ON feedback(created_at)`. `prune`: `DELETE FROM feedback WHERE id IN (SELECT id FROM feedback WHERE created_at < ? ORDER BY created_at LIMIT ?)`, trả `meta.changes`. Migration theo đúng khuôn các file `apps/api/migrations/000*.sql` sẵn có.
INVARIANTS  Không thu telemetry: bảng không có cột IP, install hash hay định danh nào khác; chỉ lưu đúng các trường của `FeedbackInput` + `id` + `created_at`.
            Góp ý cũ hơn 180 ngày bị xoá; dọn theo lô để một lượt cron không chạy quá lâu.
            Đầu vào không hợp lệ bị bác cả gói, không lưu một phần.
