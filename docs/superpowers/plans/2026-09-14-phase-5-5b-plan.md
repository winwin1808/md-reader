INVARIANTS
- Packages boundary: `apps/extension` is the only layer allowed to interact with browser file APIs (`window.showOpenFilePicker`, `window.showSaveFilePicker`, `IndexedDB`).
- Native IndexedDB: Store `FileSystemFileHandle` in database `md_reader_fs`, object store `handles`, key `active_file`.
- Handle permission verification:
  - If `handle.queryPermission({ mode: 'readwrite' }) === 'granted'`, return true.
  - If not granted, call `handle.requestPermission({ mode: 'readwrite' }) === 'granted'`.
  - Handle exceptions gracefully, returning false if permission is denied or throws.
- Graceful cancellation: When user cancels file picker (`AbortError` or null), return null without throwing.
- Tests in `apps/extension/src/app/fs/file-system.test.ts`:
  - Test `isFileSystemAccessSupported` returns true when `showOpenFilePicker` exists on window, false otherwise.
  - Test `openLocalFile` opens picker with markdown filter, reads file text, and returns handle, file, and content.
  - Test `saveToHandle` creates writable stream, writes text, closes, and returns timestamp.
  - Test `saveFileAs` calls `showSaveFilePicker` with suggested name and writes content.
  - Test `storeFileHandle`, `getStoredFileHandle`, and `clearStoredFileHandle` persist and retrieve handle in IndexedDB.
  - Test `verifyHandlePermission` queries and requests permission correctly.
