### [x] 8i.1 — doc-registry: findOrCreateByOrigin under navigator.locks
FILES       apps/extension/src/app/doc-registry.ts · apps/extension/src/app/doc-registry.test.ts
INTERFACES  The exported `findOrCreateByOrigin` keeps its exact signature and return type (read the file). Add an optional last parameter, or a module-level injectable, for tests only: `locks?: Pick<LockManager, 'request'>`, defaulting to `globalThis.navigator?.locks`.
BEHAVIOR    - Wrap the whole find-then-create body in `locks.request('mdr:import:' + originKey, () => body())` and return its result. `originKey` is the same normalized key the function already uses to look up records.
            - When `navigator.locks` (or the injected locks) is undefined, call the body directly, exactly as today.
            - Errors propagate unchanged.
            - The lock is exclusive (default mode).
            - Do not hold the lock across anything but the find+create, so other registry functions are unaffected.
INVARIANTS  - apps/extension is the only chrome.* layer. Storage and IDB behavior is otherwise unchanged.
            - Each doc keeps its own IDB, and the registry maps origin → docId 1:1. This task enforces that under concurrency.
            - Existing registry tests stay green unchanged.
TEST        Add to doc-registry.test.ts:
            - (a) With a fake `locks` that serializes per name (a simple promise-chain map), two concurrent `findOrCreateByOrigin` calls for the same origin resolve to the same docId, and only one record exists.
            - (b) Without the lock (locks undefined), the function still works for a single call.
            - (c) The fake lock receives the name 'mdr:import:' + the origin key.
            RED first: (a) must fail on the current code. If the registry's own storage makes (a) pass without a lock (because the reads are synchronous), make the test's storage async enough to expose the race (await a tick between find and create through the existing seams), and say how.
            Then pnpm --filter @md-reader/extension test (full) and pnpm -r typecheck.
