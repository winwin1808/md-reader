              (not /^[a-z][a-z0-9+.-]*:/i and not starting with '//' or '#'), set src to the resolved value (await if promise); failure →

            image-resolver.ts: `export function createImageResolver(origin: { url?: string; dirHandle?: FileSystemDirectoryHandle }):
              ImageResolver`:
              - url http(s): new URL(src, url).href.
              - url file://: absolute = new URL(src, url); fetch(absolute) → blob → URL.createObjectURL (cache by absolute; revoke all on
                dispose()) — extension pages cannot <img src="file://…"> directly.
              - dirHandle: walk path segments (reject '..' escaping the dir) → getFileHandle → file → object URL (cached).
              - none of these → return src unchanged.
              `dispose()` exported on the returned function object (resolver.dispose()).
            App.tsx: build the resolver from the current doc record (origin URL, or dir handle if one was granted — granting the dir is
              9h3's job; here only use it if present), pass to Viewer and Editor, dispose on doc change.
