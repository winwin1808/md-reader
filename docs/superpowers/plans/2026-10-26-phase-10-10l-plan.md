# Plan: Phase 10 / 10l — Extension: thực thi `publish_doc` / `list_docs` / `get_doc`
Author: haonq (coordinator: Claude Opus). Status: built. Phase: 10. Sub-phase: 10l

BranchPoint: c85c8e2 (phase-10)

Quyết định (ghi vào spec): `publish_doc` chạy ngay trong service worker bằng đường kéo-thả có sẵn (`createRecord` +
`writeDocText(record, md, 'replace')` ở `apps/extension/src/app/doc-registry.ts`), rồi mở tab `app.html` + `docQuery(docId)`
(bỏ khi `open:false`). `list_docs` đọc registry (`listRecent`) trong SW. `get_doc` LUÔN chạy trong tab app page của tài liệu
(mở tab nền nếu chưa có, đóng lại sau khi đọc nếu chính SW mở) để tài liệu đang chia sẻ trả bản đã đồng bộ qua provider phòng.
Tài liệu tạo từ MCP dùng `originKind: 'drop'`, `originPath: null` (thêm kiểu 'mcp' → nợ).
Ở SW hiện `execute` là stub (10k.2). Message SW ↔ tab: `chrome.tabs.sendMessage`.

### [x] 10l.1 — SW: `executeInApp` + hằng message + nối vào worker
FILES       apps/extension/src/shared/bridge-msg.ts · apps/extension/src/worker/bridge-route.ts · apps/extension/src/worker/bridge-route.test.ts · apps/extension/src/worker/index.ts
INTERFACES  Tiêu thụ từ `@md-reader/core/bridge`: `BridgeRequest`, `BridgeResponse`, `validateToolArgs`, `BridgeResultMap`.
            Từ `../app/doc-registry`: `createRecord`, `writeDocText`, `listRecent`, `getRecord`, `docQuery`, `DocRecord` (import tương đối trong cùng package).
            ```ts
            // shared/bridge-msg.ts (không import gì nặng — app page và SW đều dùng)
            export const BRIDGE_EXEC_MSG = 'mdr-bridge-exec'     // SW → tab: { type, req: BridgeRequest } ; tab trả BridgeResponse qua sendResponse
            export const BRIDGE_READY_MSG = 'mdr-bridge-ready'   // tab → SW: { type, docId } khi session đã synced
            export interface ExecMsg { type: typeof BRIDGE_EXEC_MSG; req: BridgeRequest }
            export interface ReadyMsg { type: typeof BRIDGE_READY_MSG; docId: string }
            // worker/bridge-route.ts
            export interface RouteDeps {
              createRecord: typeof createRecord; writeDocText: typeof writeDocText; listRecent(limit: number): Promise<DocRecord[]>
              getRecord(docId: string): Promise<DocRecord | null>; docUrl(docId: string): Promise<string>   // chrome.runtime.getURL('app.html') + docQuery
              findTab(docId: string): Promise<number | null>          // tab app.html đang mở đúng tài liệu (khớp ?d=…-<shortKey> hoặc ?doc=<docId>)
              openTab(url: string, active: boolean): Promise<number>; closeTab(id: number): Promise<void>
              waitReady(docId: string, tabId: number, ms: number): Promise<boolean>   // chờ ReadyMsg đúng docId từ tab đó
              sendToTab(tabId: number, msg: ExecMsg): Promise<BridgeResponse>
            }
            export function createExecuteInApp(deps: RouteDeps): (req: BridgeRequest) => Promise<BridgeResponse>
            ```
            Hành vi: `validateToolArgs` sai → res lỗi `INVALID_ARGS`.
            - publish_doc: `rec = createRecord({ title, originKind: 'drop', originPath: null })`; `writeDocText(rec, markdown, 'replace')`; lỗi khi ghi →
              res `INTERNAL`; `open !== false` → `openTab(await docUrl(rec.docId), true)`. Kết quả `{ docId: rec.docId }`.
            - list_docs: `listRecent(200)` → `{ docs: [{ docId, title, lastOpenedAt, shared: !!rec.room }] }`.
            - get_doc (và mọi tool còn lại cần tài liệu: update_doc, share_doc, list_links, revoke_link): `getRecord` null → `NOT_FOUND`;
              `tab = findTab(docId)`; không có → `openTab(docUrl, false)`, nhớ `opened = true`; `waitReady(docId, tab, 10_000)` false → `TIMEOUT`
              'MD Reader tab did not load the document in time'; `res = sendToTab(tab, { type: BRIDGE_EXEC_MSG, req })`; nếu `opened` và tool là
              get_doc hoặc list_links → `closeTab(tab)` (lỗi đóng bỏ qua). Lỗi sendToTab → `INTERNAL`.
            worker/index.ts: thay stub `execute` bằng `createExecuteInApp` với deps thật (`chrome.tabs.query({ url: chrome.runtime.getURL('app.html') + '*' })`
            + so query của tab; `chrome.tabs.create`/`remove`/`sendMessage`); `waitReady` lắng nghe `chrome.runtime.onMessage` cho `ReadyMsg` từ
            `sender.tab.id === tabId` (kiểm sender.id + sender.url là app.html như các message khác), hết giờ → false. Tab đã mở sẵn: trước khi chờ,
            gửi thử luôn (tab đang mở và synced sẽ trả lời) — nếu `findTab` trả tab có sẵn thì bỏ qua waitReady.
            Test bridge-route.test.ts (viết trước, deps giả): publish ghi đúng record + text, mở tab active; open:false không mở; ghi lỗi → INTERNAL;
            list_docs map đúng (shared theo room); get_doc tài liệu không có → NOT_FOUND; có tab sẵn → không mở/đóng, chuyển tiếp res; không có tab → mở nền,
            chờ ready, gửi, đóng; ready hết giờ → TIMEOUT và vẫn đóng tab đã mở; args sai → INVALID_ARGS.
INVARIANTS  Chỉ `apps/extension` dùng `chrome.*`; bridge-route.ts KHÔNG gọi `chrome.*` trực tiếp (qua deps) để test thuần.
            Mọi ghi `Y.Text` đi qua đường sẵn có (`writeDocText` dùng `applyTextChange`) — cấm xoá toàn bộ rồi chèn lại.
            Không đổi schema Y.Doc, không đổi `DocRecord`. Content script không import các file này.
            Worker vẫn chỉ nhận message từ app.html của chính extension.

### [x] 10l.3 — SW: dọn record khi publish lỗi, gửi-có-thử-lại thay cho chờ READY, luôn đóng tab tự mở
FILES       apps/extension/src/worker/bridge-route.ts · apps/extension/src/worker/bridge-route.test.ts · apps/extension/src/worker/index.ts · apps/extension/src/worker/index.test.ts
INTERFACES  Đổi `RouteDeps` (bridge-route.ts):
            ```ts
            // thêm
            deleteRecord(docId: string): Promise<void>          // = deleteRecord của ../app/doc-registry
            sleep(ms: number): Promise<void>                     // index.ts: setTimeout; test: giả, không chờ thật
            now(): number                                        // index.ts: Date.now
            // bỏ
            waitReady(...)
            ```
            Hành vi mới:
            - publish_doc: `writeDocText` ném lỗi → `await deleteRecord(rec.docId)` (lỗi xoá bỏ qua) rồi trả `INTERNAL`. Không mở tab.
            - tool cần tài liệu: không còn chờ READY. Gửi bằng vòng thử lại: `deadline = now() + 10_000`; lặp `try { res = await sendToTab(tab, msg); break }
              catch { if (now() >= deadline) → TIMEOUT 'MD Reader tab did not load the document in time'; await sleep(250) }`. (sendMessage tới tab
              chưa có listener ném "Receiving end does not exist" — đó là tín hiệu thử lại.) Áp dụng cả khi tab có sẵn lẫn tab vừa mở.
            - Tab do SW mở (`opened`) LUÔN được `closeTab` sau khi có kết quả hoặc TIMEOUT, với mọi tool (bỏ danh sách get_doc/list_links); lỗi đóng bỏ qua.
            index.ts: bỏ hàng đợi waiter READY và nhánh xử lý `BRIDGE_READY_MSG` trong onMessage (không còn ai cần); truyền `deleteRecord`, `sleep`, `now` thật.
            Không xoá hằng `BRIDGE_READY_MSG` ở task này (10l.4 xoá cùng App.tsx).
            Test (sửa trước, đỏ): publish ghi lỗi → deleteRecord gọi đúng docId và kết quả INTERNAL; sendToTab ném 2 lần rồi trả res → res được chuyển tiếp,
            sleep(250) gọi 2 lần; sendToTab luôn ném + now() vượt deadline → TIMEOUT và tab tự mở bị đóng; tab có sẵn → không mở/không đóng;
            tool update_doc với tab tự mở → vẫn đóng tab. Cập nhật index.test.ts nếu có test về READY waiter (xoá test đó, không thêm test mới cho nó).
INVARIANTS  bridge-route.ts KHÔNG gọi `chrome.*` (qua deps). Chỉ `apps/extension` dùng `chrome.*`.
            Mọi ghi `Y.Text` qua `writeDocText` (dùng `applyTextChange`). Không đổi schema Y.Doc, không đổi `DocRecord`.
            Worker vẫn chỉ nhận message từ app.html của chính extension. Content script không import các file này.

INTERFACES  ```ts
            export interface ExecSession { docId: string; title: string; yText: Y.Text; shared: boolean; synced: boolean }
            export function createBridgeExecutor(
              get: () => ExecSession | null,
              opts?: { waitMs?: number; pollMs?: number; sleep?: (ms: number) => Promise<void> }   // mặc định 8000 / 100 / setTimeout

            App.tsx: `execSessionRef` có thêm `synced: session.synced`; XOÁ effect gửi `BRIDGE_READY_MSG`. shared/bridge-msg.ts: xoá `BRIDGE_READY_MSG` và `ReadyMsg`

            Test (sửa trước, đỏ): session synced:false rồi chuyển true sau 2 lần poll → trả markdown của Y.Text lúc đã synced; luôn false → TIMEOUT;
            đổi docId lúc chờ → NOT_FOUND; các test cũ cập nhật thêm `synced: true`.
INVARIANTS  Chỉ `apps/extension` dùng `chrome.*`. Executor chỉ đọc Y.Text, không ghi.
