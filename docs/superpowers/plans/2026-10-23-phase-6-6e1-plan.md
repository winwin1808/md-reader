Decision: a doc whose meta has no `formatVersion` is v1 — both `migrateDoc` and
`readMeta` treat a missing value as 1 (today readMeta defaults to FORMAT_VERSION,
which would make an unmigrated legacy doc look like v2).

INTERFACES  schema.ts: `FORMAT_VERSION = 2`; `HistoryEntry` gains `snapshot?: Uint8Array`
              (label stays `string`; documented values 'save' | 'auto' | 'import').
            doc.ts:
              - createDoc(init?) builds `new Y.Doc({ gc: false })`; its meta/source writes move
                into a private `initDoc(doc, init)` that both createDoc and ensureDoc use.
              - readMeta: missing/non-number formatVersion → 1.
              - migrateDoc(doc): { from: number; to: number }
                  v = number formatVersion or 1 when missing; v > FORMAT_VERSION → throw
                  UnsupportedFormatVersionError (unchanged); v === FORMAT_VERSION → return
                  {from: v, to: v} WITHOUT opening a transaction (no update emitted);
                  v === 1 → ONE doc.transact: if title missing and name is a string →
                  title = name; delete 'name'; delete 'size'; createdAt missing → Date.now();
                  actors missing → {}; originPath missing → null; formatVersion = 2.
              - export function ensureDoc(doc: Y.Doc, init?: Parameters<typeof createDoc>[0]): { migrated: boolean }
                  meta has no keys at all → initDoc(doc, init) (source inserted only if the
                  Y.Text is empty), return { migrated: false };
                  else r = migrateDoc(doc), return { migrated: r.from !== r.to }.
            index.ts: export ensureDoc (doc.ts is already re-exported — check, add if needed).
INVARIANTS  - Schema stays Y.Text "source" · Y.Map "meta" · Y.Array "history"; changing the
              schema requires migration + an old-format fixture test (this task is that).
            - packages/core is pure TS: yjs allowed; no react, no chrome.*, no document,
              and it never learns which provider runs (it only receives a Y.Doc).
            - Writes to Y.Text are minimal deltas; never delete(0, length) + insert.
