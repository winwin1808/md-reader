Bổ sung so với spec (đã ghi vào spec): **tombstone**. Sau purge, client giữ link sửa có thể nối lại trong cửa sổ cache xác
thực 60 s (`authCache` trong api.ts, theo isolate) và đẩy bản cục bộ lên phòng rỗng → dựng lại nội dung đã xoá. Vì vậy DO
ghi `tombstone` vào storage sau `deleteAll()` và từ chối mọi kết nối/yêu cầu sau đó; api xoá entry cache của phòng.
`DELETE /api/rooms/:roomId` trả 401 khi không phải chủ (kể cả phòng không tồn tại — `verifyOwner` không phân biệt được),
404 chỉ khi đã qua kiểm chủ mà `deleteRoom` trả false.

### [x] 10e.1 — `DocRoom.purge()` + tombstone
FILES       apps/api/src/room.ts · apps/api/src/room.test.ts
INTERFACES  ```ts
            class DocRoom {
              purge(): Promise<void>
              // 1) đặt cờ trong bộ nhớ `purged = true`; 2) đóng mọi kết nối `conn.close(4410, 'deleted')`;
              // 3) chờ hàng đợi persist hiện tại (`this.queue`) xong; 4) `ctx.storage.deleteAll()`; 5) `ctx.storage.put('tombstone', 1)`.
            }
            ```
            - `onLoad`: đọc `tombstone` trước; có → đặt `purged = true`, KHÔNG nạp state, KHÔNG gắn listener `update`.
            - `onConnect`: `purged` → `conn.close(4410, 'deleted')` và return trước `super.onConnect`.
            - `handleMessage`: `purged` → bỏ qua message (không gọi super).
            - `persistUpdate`/`compactIfEmpty`/`onSave`: `purged` → không ghi gì.
            - `onRequest`: `POST` + `x-mdr-internal: 1` + path kết thúc `/purge` → `await this.purge()`, trả 204.
              `GET …/snapshot` khi `purged` → 410.
            Test trong room.test.ts (theo cách file đang dựng DocRoom/stub): purge → mọi kết nối mở nhận close 4410; storage chỉ
            còn khoá `tombstone`; kết nối mới sau purge bị đóng 4410; message update đến sau purge không làm đổi storage;
            snapshot sau purge → 410; khởi tạo DocRoom mới trên storage có tombstone → `purged` (kết nối bị đóng 4410).
INVARIANTS  `apps/api` chạy trên Workers: KHÔNG `document`/`window` toàn cục (`this.document` là Y.Doc của YServer, hợp lệ), KHÔNG `chrome.*`.
            Không đổi hành vi phòng chưa purge — test cũ room.test.ts xanh nguyên.
            Route nội bộ chỉ nhận khi có header `x-mdr-internal: 1` (index.ts đã xoá header này khỏi request từ ngoài).
