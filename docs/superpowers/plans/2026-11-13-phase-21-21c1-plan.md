INTERFACES  Tiêu thụ từ `@md-reader/core/bridge`: `type BridgePinState = 'unknown' | 'none' | 'self' | 'other'`, `bridgePinState(pinnedExt: string | null | undefined, myKeyId: string): BridgePinState`, và `BridgeHello.pinnedExt?: string | null` (đã có sau 21a). `keyId` từ `@md-reader/core/bridge-auth`.
            Sinh ra trong `bridge.ts`:
            ```ts
            export interface BridgeConn { port: number; client: string; keyHash: string; state: 'pending' | 'authing' | 'paired'; pinned: BridgePinState }
            export interface UnpairedServer { port: number; client: string; keyHash: string; pinned: BridgePinState }
            export interface BridgeDeps {
              connect(url: string): WsLike
              approved(): Promise<ApprovedClient[]>
              extKey(): Promise<{ privateKey: CryptoKey; publicKey: string }>
              onUnpaired(s: UnpairedServer): Promise<boolean>   // true = đã mở hộp hỏi, giữ kết nối chờ quyết định
              execute(req: BridgeRequest, client: string): Promise<BridgeResponse>
              setTimer(fn: () => void, ms: number): unknown
              clearTimer(h: unknown): void
            }
            ```
            (`requestPairing` bị xoá khỏi `BridgeDeps`.) Entry mới khởi tạo `conn.pinned = 'unknown'`.
            `onHello` mới, theo thứ tự: tính `kid = await keyId(h.serverKey)`; `myKid = await keyId((await deps.extKey()).publicKey)`; `e.conn.pinned = bridgePinState(h.pinnedExt, myKid)`; đọc `deps.approved()`. Nếu có mục duyệt khớp `keyHash === kid && serverKey === h.serverKey` VÀ `pinned !== 'other'` → `authenticate(e)` như cũ. Ngược lại → `e.conn.state = 'pending'`; `keep = await deps.onUnpaired({ port, client, keyHash: kid, pinned })` (ném lỗi coi như `false`); nếu entry còn sống và `keep === false` → đóng socket + `drop` (KHÔNG gửi `reject`). Sau mỗi `await` vẫn kiểm `live()` như code hiện tại.
            `index.ts`: chỉ đổi dep `requestPairing` thành `onUnpaired` giữ NGUYÊN hành vi cũ: nếu `isExpiryActive(revokedUntil, keyHash)` → trả `false`; ngược lại mở tab `app.html?pair=…` như hiện nay và trả `true`. Không đổi gì khác trong `index.ts`.
INVARIANTS  `chrome.*` chỉ được dùng trong `apps/extension`; `bridge.ts` tự nó không gọi `chrome.*` (mọi thứ qua `deps`).
            Không đổi luồng xác thực v2: `auth` chỉ được gửi cho máy chủ đã có trong danh sách duyệt (khớp cả `keyHash` lẫn `serverKey`) hoặc sau `decide(allow=true)`; chữ ký, nonce, `onAuthOk` giữ nguyên.
            Máy chủ báo `pinned === 'other'` thì KHÔNG BAO GIỜ gửi `auth`, kể cả khi đã duyệt.
