            // moderation.ts
            export const MAX_REASON = 500
            export interface ModerationStore {
              addReport(r: { roomId: string; reason: string; ipHash: string }): Promise<void>
              addTakedown(roomId: string): Promise<void>        // idempotent: INSERT OR IGNORE
            }
            export class MemoryModerationStore implements ModerationStore {
              constructor(now?: () => number)
              readonly reports: Array<{ roomId: string; reason: string; ipHash: string; createdAt: number }>
              readonly takedowns: Map<string, number>
            }
            export class D1ModerationStore implements ModerationStore { constructor(db: D1Database, now?: () => number) }
            // SQL: INSERT INTO reports (room_id, reason, ip_hash, created_at) VALUES (?, ?, ?, ?)
            //      INSERT OR IGNORE INTO takedowns (room_id, created_at) VALUES (?, ?)
            export function adminAuthorized(req: Request, secret: string | undefined): Promise<boolean>
            // secret vắng hoặc rỗng → false. Lấy bearer từ `authorization: Bearer <x>`; so SHA-256(x) với SHA-256(secret)
            // bằng vòng lặp XOR tích luỹ trên từng byte (thời gian hằng, không thoát sớm).
            // env.ts: interface Env thêm `ADMIN_SECRET?: string`
            ```

### [x] 10f.2 — Route báo cáo + gỡ phòng + script takedown
FILES       apps/api/src/api.ts · apps/api/src/api.test.ts · apps/api/src/index.ts · apps/api/scripts/takedown.mjs
INTERFACES  Tiêu thụ: `ModerationStore`, `MAX_REASON`, `adminAuthorized` (10f.1); `deleteRoomEverywhere` (10e); `LimitStore`,
            `subjectFrom` (10c); `API_PATHS.report` — **thêm** vào `API_PATHS` ở core? KHÔNG: dùng chuỗi `'/api/report'` trong api.ts
            (core/share đổi ở 10g khi web cần).
            `ApiDeps` thêm `moderation?: ModerationStore; adminSecret?: string`.
            - `POST /api/report`: body JSON ≤ `MAX_BODY` (4096) `{ token: string; reason: string }`; reason trim dài 1..MAX_REASON, token
              string 1..200 → sai: 400 `{error:'invalid body'}`. `store.resolve(token)` null → 404 `{error:'not found'}`.
              `deps.limits`: `check('report', s)` → 429 như các route khác; `deps.moderation` vắng → 501.
              `addReport({ roomId, reason, ipHash: s.ipHash })`, `limits.record('report', s, { roomId })` → 202 `{ ok: true }`.
            - `POST /api/admin/rooms/:roomId/takedown`: mọi path bắt đầu `/api/admin/` khi `!deps.adminSecret` → 404 `{error:'not found'}`;
              `!(await adminAuthorized(req, deps.adminSecret))` → 401; `deleteRoomEverywhere(roomId, {store, assets, limits, purge})` false
              → 404; true → `moderation?.addTakedown(roomId)` → 204.
            index.ts: truyền `moderation: new D1ModerationStore(env.DB)`, `adminSecret: env.ADMIN_SECRET` vào deps của handleApi.
            scripts/takedown.mjs: `MDR_API_URL=<https://…> MDR_ADMIN_SECRET=<…> node scripts/takedown.mjs <roomId>`; thiếu biến → in usage ra
            stderr, exit 1; gọi `POST $MDR_API_URL/api/admin/rooms/<encodeURIComponent(roomId)>/takedown` với bearer; in `takedown <roomId>: <status>`;
            exit 0 khi 204, 1 khi khác. Không bao giờ in secret.
            Test api.test.ts: report hợp lệ bằng link XEM → 202 và Memory có 1 report đúng roomId; token hỏng → 404; reason rỗng/501 ký tự → 400;
            lần thứ 11 cùng IP → 429; admin không có secret cấu hình → 404; sai secret → 401; đúng → 204, sau đó `GET /api/s/<token>` → 410,
            takedown được ghi; gỡ phòng không có → 404 và không ghi takedown.
INVARIANTS  Không đổi status/body các route khác; test cũ xanh nguyên.
            Báo cáo không cần đăng nhập nhưng token phải resolve được (chặn báo cáo rác vào roomId đoán mò); chỉ lưu `ipHash`.
            Admin chỉ bật khi Worker có secret `ADMIN_SECRET` (wrangler secret) — không bao giờ có giá trị mặc định trong code/wrangler.jsonc.
            `apps/api`: KHÔNG `document`/`window`/`chrome.*`; import core bằng `@md-reader/core`.
