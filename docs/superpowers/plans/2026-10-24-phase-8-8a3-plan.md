### [x] 8a3.1 — hàm persistence thuần trên `KVLike`

```ts
export interface KVLike {
  get(key: string): Promise<Uint8Array | string | undefined>
  put(key: string, value: Uint8Array | string): Promise<void>
  delete(key: string): Promise<boolean>
  list(opts: { prefix: string }): Promise<Map<string, Uint8Array | string>>
}
export const CHUNK_BYTES = 1_048_576          // 1 MiB
export const COMPACT_UPDATES = 200
export const COMPACT_BYTES = 262_144           // 256 KiB
export interface LogStats { updates: number; bytes: number }
export async function loadState(kv: KVLike): Promise<Uint8Array | null>
  // đọc 'snap:meta' (JSON {chunks:number, bytes:number}) → ghép 'snap:0'..'snap:n-1'; rồi áp mọi 'u:*' theo thứ tự seq tăng;
  // trả về một update gộp (Y.mergeUpdates) hoặc null nếu không có gì
export async function appendUpdate(kv: KVLike, update: Uint8Array, stats: LogStats): Promise<LogStats>
  // key 'u:' + String(seq).padStart(12,'0'); seq = stats.updates (sau snapshot cuối); trả stats mới; update > CHUNK_BYTES → vẫn ghi nhưng stats.bytes vượt → caller compact ngay
export function shouldCompact(stats: LogStats, roomEmpty: boolean): boolean
  // stats.updates >= COMPACT_UPDATES || stats.bytes >= COMPACT_BYTES || (roomEmpty && stats.updates > 0)
export async function compact(kv: KVLike, doc: Y.Doc): Promise<LogStats>
  // state = Y.encodeStateAsUpdate(doc); ghi các khúc 'snap:i' rồi 'snap:meta' CUỐI CÙNG (meta sau khúc để load không thấy meta mới với khúc cũ); xoá mọi 'u:*'; xoá khúc 'snap:i' thừa nếu snapshot mới ít khúc hơn; trả {updates:0, bytes:0}
export async function readStats(kv: KVLike): Promise<LogStats>   // đếm lại từ 'u:*' khi DO thức dậy
```

### [x] 8a3.4 — snapshot theo thế hệ, seq theo max, compact khi đóng kết nối (từ review)
FILES       apps/api/src/persistence.ts · apps/api/src/persistence.test.ts · apps/api/src/room.ts · apps/api/src/api.test.ts
INTERFACES  Không đổi chữ ký public của persistence.ts; đổi bố cục key:
            (1) Snapshot theo thế hệ: khúc ghi vào `snap:<gen>:<i>`, meta `snap:meta` = JSON `{gen:number, chunks:number, bytes:number}`. `compact`: gen mới = gen cũ + 1 (hoặc 0 nếu chưa có meta); ghi hết khúc của gen mới → ghi meta → xoá `u:*` → xoá mọi khúc có gen ≠ gen mới (quét `list({prefix:'snap:'})`, bỏ qua key `snap:meta`). `loadState`: đọc meta → chỉ ghép khúc đúng gen; thiếu khúc → bỏ snapshot, vẫn áp `u:*`. Thế là crash ở bất kỳ điểm nào cũng chỉ còn hai trạng thái hợp lệ: meta cũ + khúc cũ nguyên vẹn, hoặc meta mới + khúc mới nguyên vẹn.
            (2) `readStats`: `updates` = (max seq trong `u:*`) + 1, không phải số key; `bytes` = tổng độ dài. `appendUpdate` giữ nguyên dùng `stats.updates` làm seq.
            (3) `room.ts`: override `onClose(conn, code, reason, wasClean)` (và `onError` nếu partyserver có) → gọi `super`, rồi nếu `[...this.getConnections()].length === 0` thì `enqueue(() => compact(...))` khi `this.stats.updates > 0`. Bỏ guard chết `origin !== this`. Giữ `onSave` như cũ.
INVARIANTS  Snapshot ghi khúc trước, meta sau — bất biến vì DO có thể bị thu hồi giữa chừng; từ task này thêm: không bao giờ ghi đè khúc của thế hệ đang được meta trỏ tới. `this.document` là nguồn sự thật trong DO; storage là bản bền. Mọi ghi storage đi qua `enqueue`. Không R2, không đổi schema SQL. apps/api KHÔNG DOM `document`/`window` (trường `this.document` của YServer là Y.Doc, hợp lệ).
