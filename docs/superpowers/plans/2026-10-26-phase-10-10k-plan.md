# Plan: Phase 10 / 10k — Extension: cầu nối trong service worker + ghép cặp + Cài đặt "Kết nối AI"

Số đo nền (DESIGN §5.7): SW MV3 nối `ws://127.0.0.1` không cần host permission; SW bị dừng 30 s sau message cuối → ping 20 s;
`chrome.alarms` 0.5 phút đánh thức SW đã dừng và nối lại (~30 s); cổng đóng sinh log `ERR_CONNECTION_REFUSED` → sau 10 lượt quét
trắng liên tiếp chỉ quét mỗi 5 phút. MCP server (10i/10j) gửi `hello{protocol:1, client, pairKey}` ngay khi nối, chỉ gửi `req` sau
`welcome{paired:true}`, bỏ qua `ping`, coi `reject` là đóng.

Lệch spec (đã sửa spec): `mdr.bridge.approved` là `Array<{ keyHash: string; client: string; at: number }>` (thay vì `string[]`) để
Cài đặt hiện tên client. Ở 10k, `execute` chỉ trả lỗi `INTERNAL 'not implemented yet'` — 10l thay bằng thực thi thật.

### [x] 10k.1 — Logic cầu nối (`worker/bridge.ts`), deps tiêm vào
FILES       apps/extension/src/worker/bridge.ts · apps/extension/src/worker/bridge.test.ts
INTERFACES  Tiêu thụ từ `@md-reader/core/bridge`: `BRIDGE_PORTS`, `BRIDGE_PROTOCOL`, `parseBridgeMessage`, `textHash`, kiểu `BridgeRequest`,
            `BridgeResponse`, `BridgeHello`.
            ```ts
            export const PING_MS = 20_000
            export const IDLE_SCANS_BEFORE_BACKOFF = 10
            export interface ApprovedClient { keyHash: string; client: string; at: number }
            export interface BridgeConn { port: number; client: string; keyHash: string; state: 'pending' | 'paired' }
            export interface WsLike { readyState: number; send(data: string): void; close(code?: number, reason?: string): void;
              onopen: (() => void) | null; onmessage: ((e: { data: unknown }) => void) | null; onclose: (() => void) | null; onerror: (() => void) | null }
            export interface BridgeDeps {
              connect(url: string): WsLike                                  // mặc định new WebSocket(url)
              approved(): Promise<ApprovedClient[]>
              requestPairing(c: { port: number; client: string; keyHash: string }): void   // mở UI duyệt (10k.2)
              execute(req: BridgeRequest): Promise<BridgeResponse>
              setTimer(fn: () => void, ms: number): unknown; clearTimer(h: unknown): void   // setInterval/clearInterval cho ping
            }
            export function createBridge(deps: BridgeDeps): {
              scan(ports?: readonly number[]): Promise<number>   // thử nối mọi cổng chưa có kết nối; trả số kết nối đang mở sau lượt quét
              decide(port: number, allow: boolean, add?: (c: ApprovedClient) => Promise<void>): Promise<void>
              revoke(keyHash: string): void                     // đóng kết nối có keyHash đó
              stopAll(): void
              conns(): BridgeConn[]
            }
            ```
            Hành vi: mỗi cổng tối đa 1 kết nối (`ws://127.0.0.1:<port>`). `scan` chờ mỗi kết nối mở hoặc lỗi (timeout 1 s/cổng, đóng nếu quá) rồi trả.
            Khi kết nối mở: bắt đầu ping `{type:'ping'}` mỗi PING_MS; dừng khi đóng. Nhận `hello` hợp lệ (`parseBridgeMessage`, protocol 1) →
            `keyHash = await textHash(pairKey)`; có trong `approved()` → gửi `welcome{paired:true}`, state 'paired'; không → gửi
            `welcome{paired:false}`, state 'pending', gọi `requestPairing`. `decide(port, true, add)` → `add({keyHash, client, at: Date.now()})`,
            gửi `welcome{paired:true}`; `decide(port, false)` → gửi `reject{code:'DENIED'}` rồi đóng. `req` chỉ xử lý khi 'paired' (ngược lại bỏ qua);
            gọi `execute` và gửi lại `res` (execute ném → `res{ok:false, error:{code:'INTERNAL', message}}`). Message không parse được → bỏ qua.
            KHÔNG bao giờ lưu hay log pairKey (chỉ keyHash).
            Test (viết trước; WsLike giả điều khiển bằng tay, timer giả): scan mở kết nối cho cổng có server giả, bỏ qua cổng lỗi; hello đã duyệt →
            welcome paired:true; chưa duyệt → welcome paired:false + requestPairing đúng client/keyHash; decide allow → add được gọi + welcome
            paired:true; deny → reject DENIED + close; req khi pending bị bỏ qua, khi paired → execute → res cùng id; ping gửi theo PING_MS và dừng khi
            đóng; revoke đóng đúng kết nối; scan lần hai không mở trùng kết nối cổng đang mở.
INVARIANTS  Chỉ `apps/extension` dùng `chrome.*` — file này KHÔNG gọi `chrome.*` trực tiếp (mọi thứ qua deps) để test thuần.
            Chỉ nối `127.0.0.1`. pairKey không lưu, không log. Không thêm dependency.
            Content script KHÔNG import file này (ngân sách ≤ 60 KB gz).

### [x] 10k.2 — Nối vào service worker: storage, alarms, quyết định ghép cặp
FILES       apps/extension/src/worker/bridge-storage.ts · apps/extension/src/worker/bridge-storage.test.ts · apps/extension/src/worker/index.ts · apps/extension/public/manifest.json
INTERFACES  ```ts
            // bridge-storage.ts
            export const BRIDGE_STORAGE_KEY = 'mdr.bridge'
            export interface BridgeSettings { enabled: boolean; approved: ApprovedClient[] }
            export interface StoreLike { get(k: string): Promise<Record<string, unknown>>; set(v: Record<string, unknown>): Promise<void> }
            export function parseBridgeSettings(v: unknown): BridgeSettings        // sai hình dạng → { enabled: false, approved: [] }
            export async function readBridgeSettings(store: StoreLike): Promise<BridgeSettings>
            export async function addApproved(store: StoreLike, c: ApprovedClient): Promise<void>   // thay entry cùng keyHash
            export async function removeApproved(store: StoreLike, keyHash: string): Promise<void>
            export function nextScanDelayMin(idleScans: number): number           // < 10 → 0.5 ; ≥ 10 → 5
            export const PAIR_DECISION_MSG = 'mdr-bridge-pair-decision'           // { type, port: number, allow: boolean }
            export const BRIDGE_SCAN_MSG = 'mdr-bridge-scan'                     // { type } — app page mở → quét ngay
            ```
            worker/index.ts: tạo một `createBridge` toàn cục với deps thật (`new WebSocket`, `readBridgeSettings(chrome.storage.local).approved`,
            `requestPairing` = `chrome.tabs.create({ url: chrome.runtime.getURL('app.html?pair=' + port + '&client=' + encodeURIComponent(client)) })`,
            `execute` = trả `{ type:'res', id, ok:false, error:{ code:'INTERNAL', message:'not implemented yet' } }`).
            `tick()`: đọc settings; tắt → `stopAll()`, `chrome.alarms.clear('mdr-bridge')`; bật → `n = await scan()`; cập nhật đếm lượt quét trắng
            trong `chrome.storage.session` (khoá `mdr.bridgeIdle`; n>0 → 0, n=0 → +1); `chrome.alarms.create('mdr-bridge', { periodInMinutes: nextScanDelayMin(idle) })`.
            Gọi `tick` ở: `onStartup`, `onInstalled`, `alarms.onAlarm` (name 'mdr-bridge'), `storage.onChanged` khi khoá `mdr.bridge` đổi (đồng thời
            `revoke` các keyHash vừa bị xoá khỏi approved), và runtime message `BRIDGE_SCAN_MSG` (đặt idle về 0 trước). Runtime message
            `PAIR_DECISION_MSG` từ app page → `decide(port, allow, c => addApproved(chrome.storage.local, c))` rồi đóng tab gửi (`sender.tab.id`).
            Message chỉ nhận khi `sender.id === chrome.runtime.id` và sender là trang `app.html` của extension.
            manifest.json: `permissions` thêm `"alarms"` (không thêm gì khác).
            Test bridge-storage.test.ts (viết trước, store giả): parse sai hình dạng → mặc định; add thay trùng keyHash; remove; nextScanDelayMin 0/9/10/50.

            Mặc định cầu nối TẮT (không có khoá storage → enabled false → không quét, không nối).
            Không đổi hành vi hiện có của worker (onClicked, mở file, purgeStaleCache) — test cũ worker/index.test.ts xanh nguyên.
