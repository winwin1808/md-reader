### [ ] 10i.2 — `bridge-server.ts`
FILES       packages/mcp/src/bridge-server.ts · packages/mcp/src/bridge-server.test.ts
INTERFACES  Tiêu thụ `@md-reader/core/bridge`: `BRIDGE_PORTS`, `BRIDGE_PROTOCOL`, `BridgeTool`, `BridgeArgsMap`, `BridgeResultMap`,
            `BridgeErrorCode`, `parseBridgeMessage`, các kiểu message. `ws` (`WebSocketServer`).
            ```ts
            export class BridgeCallError extends Error { constructor(readonly code: BridgeErrorCode, message: string) }
            export interface BridgeServer {
              readonly port: number
              setClient(name: string): void
              call<T extends BridgeTool>(tool: T, args: BridgeArgsMap[T], timeoutMs?: number): Promise<BridgeResultMap[T]>
              close(): Promise<void>
            }
            export function startBridgeServer(opts: { pairKey: string; client: string; ports?: readonly number[];
              connectWaitMs?: number; allowedOrigin?: (origin: string) => boolean }): Promise<BridgeServer>
            ```
            Hành vi:
            - Thử lần lượt `ports` (mặc định `BRIDGE_PORTS`), `host: '127.0.0.1'`; EADDRINUSE → cổng kế; hết cổng → reject Error('no free port').
            - Upgrade: `allowedOrigin` mặc định = origin bắt đầu `chrome-extension://` hoặc `moz-extension://`; nếu `process.env.MDR_EXTENSION_ID`
              có giá trị thì chỉ nhận đúng `chrome-extension://<id>`. Origin sai/thiếu → từ chối upgrade (HTTP 403, dùng `verifyClient` hoặc
              `handleUpgrade` thủ công).
            - Khi nối: gửi ngay `{type:'hello', protocol:1, client, pairKey}`. Kết nối chỉ "paired" sau khi nhận `{type:'welcome', paired:true}`;
              `welcome{paired:false}` = đang chờ người dùng duyệt (giữ kết nối). `reject` → đóng kết nối đó.
            - Chỉ giữ MỘT kết nối paired: kết nối paired mới thay kết nối cũ (đóng cũ, mọi call đang chờ trên cũ → `NOT_CONNECTED`).
            - `ping` từ extension: bỏ qua (chỉ để giữ SW sống). Message không parse được: bỏ qua.
            - `call`: chưa có kết nối paired → chờ tối đa `connectWaitMs` (mặc định 35 000) một kết nối paired; hết giờ → `BridgeCallError('NOT_CONNECTED',
              'Open Chrome with MD Reader and turn on Settings → AI connection')`. Có → gửi `{type:'req', id, tool, args}` (id duy nhất, ví dụ
              bộ đếm + random), chờ `res` cùng id tối đa `timeoutMs` (mặc định 30 000; `share_doc`/`revoke_link` mặc định 120 000) → `TIMEOUT`.
              `res.ok` → resolve `result`; ngược lại reject `BridgeCallError(error.code, error.message)`. Kết nối đóng giữa chừng → mọi call đang
              chờ reject `NOT_CONNECTED`.
            - `close()`: đóng mọi kết nối + server, reject mọi call đang chờ `NOT_CONNECTED`, dọn mọi timer.
            Test (viết trước; client `ws` thật đóng vai extension, dùng cổng cao ngẫu nhiên, `connectWaitMs` nhỏ):
            hello đúng trường khi nối; call trước welcome → chờ, sau welcome{paired:true} → req được gửi, res ok → resolve;
            res lỗi → BridgeCallError đúng code; không có extension → NOT_CONNECTED sau connectWaitMs; res không về → TIMEOUT;
            Origin `https://evil.example` bị từ chối; cổng đầu bận → dùng cổng kế; kết nối paired thứ hai thay thứ nhất, call đang chờ trên
            thứ nhất → NOT_CONNECTED; reject → đóng; close() reject call đang chờ.
INVARIANTS  Chỉ bind `127.0.0.1`, không bao giờ `0.0.0.0`/`::`.
            KHÔNG react / `chrome.*` / `document`; import core chỉ qua `@md-reader/core/bridge`.
            Không ghi gì ra stdout (stdout dành cho giao thức MCP stdio ở 10j); log nếu cần chỉ ra stderr và không bao giờ chứa pairKey.
            Không thêm dependency.
