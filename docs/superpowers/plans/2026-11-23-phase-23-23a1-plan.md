### [ ] 23a1-1 — Bình luận: thêm / trả lời / resolve / xoá / liệt kê với neo RelativePosition
FILES       packages/core/src/comments/comments.ts (mới), packages/core/src/comments/comments.test.ts (mới), packages/core/src/index.ts
INTERFACES  (produce, đúng tên, export từ `@md-reader/core` qua `export * from './comments/comments.js'` trong index.ts)
```ts
import * as Y from 'yjs'
export const COMMENTS_ROOT = 'comments'
export const COMMENT_BODY_MAX = 4000
export const COMMENT_QUOTE_MAX = 300
export const COMMENT_AUTHOR_MAX = 40
export interface CommentAnchor { start: string; end: string; quote: string } // base64 của Y.encodeRelativePosition
export interface CommentEntry {
  v: 1; thread: string | null; author: string; clientId: number; ts: number; body: string; anchor?: CommentAnchor
}
export interface CommentState { resolved: boolean; by: string; clientId: number; ts: number }
export interface CommentReply { id: string; author: string; clientId: number; ts: number; body: string }
export interface CommentThread {
  id: string; author: string; clientId: number; ts: number; body: string; quote: string
  range: { from: number; to: number } | null
  resolved: boolean; resolvedBy: string | null; deleted: boolean; replies: CommentReply[]
}
export function getComments(doc: Y.Doc): Y.Map<unknown>            // doc.getMap(COMMENTS_ROOT)
export function addComment(doc: Y.Doc, input: { author: string; body: string; from: number; to: number; now?: number }): string
export function replyComment(doc: Y.Doc, threadId: string, input: { author: string; body: string; now?: number }): string
export function setResolved(doc: Y.Doc, threadId: string, resolved: boolean, by: string, now?: number): void
export function deleteComment(doc: Y.Doc, id: string): void
export function listThreads(doc: Y.Doc): CommentThread[]
```
Hành vi:
- Khoá mục: `c:<doc.clientID>:<rand8>` (rand8 = 8 ký tự `[a-z0-9]`, dùng `Math.random`); trạng thái: `s:<threadId>`.
- Giá trị ghi là object JSON thuần (`map.set(key, plainObject)`), không lồng Y.Map. `clientId` = `doc.clientID`. `ts` = `now ?? Date.now()`.
- `addComment`: `source = doc.getText('source')`; yêu cầu `0 <= from < to <= source.length` và `body.trim() !== ''`, sai → `throw new RangeError('comment_range')` / `RangeError('comment_empty')`. Cắt body ≤ 4000, author ≤ 40, quote = `source.toString().slice(from,to)` cắt ≤ 300. Neo: `start` = `Y.createRelativePositionFromTypeIndex(source, from, 0)`, `end` = `Y.createRelativePositionFromTypeIndex(source, to, -1)`, mã hoá `Y.encodeRelativePosition` → base64 (dùng `btoa`/`atob` trên chuỗi byte, không dùng Buffer). `thread: null`. Trả id.
- `replyComment`: `threadId` phải là khoá `c:` tồn tại có `thread === null`, không → `RangeError('comment_thread')`; body rỗng → `comment_empty`. Không có `anchor`. Trả id.
- `setResolved`: thread phải tồn tại (gốc, kể cả gốc đã xoá nhưng còn trả lời) → không thì `comment_thread`; ghi `s:<threadId>` = `{resolved, by (cắt 40), clientId: doc.clientID, ts}`.
- `deleteComment(id)`: xoá khoá `id`; nếu là gốc và không còn trả lời trỏ tới nó thì xoá luôn `s:<id>`. Nếu là trả lời và gốc đã xoá và không còn trả lời nào khác → xoá luôn `s:<thread>`. Id không tồn tại → không làm gì.
- `listThreads`: gom mọi mục `c:` theo thread. Range: decode neo → `Y.createAbsolutePositionFromRelativePosition(rel, doc)`; nếu một trong hai null hoặc `from >= to` → `range: null`. Gốc đã xoá nhưng còn trả lời → thread `deleted: true`, `body: ''`, `author: ''`, `quote: ''`, `range: null`, `ts` = ts trả lời sớm nhất, id = threadId. Trả lời sắp theo `ts` tăng (hoà → theo id). Thread sắp: có range theo `range.from` rồi `ts`; `range: null` cuối, theo `ts`. `resolved`/`resolvedBy` từ `s:<id>` (không có → false/null). Mục có giá trị sai dạng (không phải object, thiếu trường) bỏ qua, không throw — kiểm tối thiểu bằng type guard nội bộ (task 23a1-2 sẽ thay bằng `validateCommentValue`).
- Mọi ghi trong `doc.transact(() => …)`.
INVARIANTS

- Y.Doc là nguồn sự thật; schema hiện có: `Y.Text "source"` · `Y.Map "meta"` · `Y.Array "history"`. Task này chỉ THÊM root `Y.Map "comments"` — không đổi `FORMAT_VERSION`, không sửa `src/doc/schema.ts` (đó là 23a2).
- Import chéo package luôn bằng tên workspace; trong core dùng đường dẫn tương đối có đuôi `.js` như các file khác.

### [ ] 23a1-2 — `validateCommentValue` + `commentKeyClient`
FILES       packages/core/src/comments/comments.ts, packages/core/src/comments/comments.test.ts
INTERFACES  (produce, consume mọi thứ của 23a1-1)
```ts
export function commentKeyClient(key: string): number | null
export function validateCommentValue(key: string, value: unknown): string | null   // null = hợp lệ
```
Hành vi:
- `commentKeyClient`: `'c:<n>:<rand8>'` → n (số nguyên ≥ 0, không số 0 đứng đầu trừ "0"); `'s:c:<n>:<rand8>'` → n; mọi dạng khác → null. Regex khoá `c:` chặt: `^c:(0|[1-9]\d{0,15}):[a-z0-9]{8}$`.
- `validateCommentValue` trả mã lỗi đầu tiên gặp:
  - khoá không phải `c:`/`s:` hợp lệ → `'comment_key'`
  - khoá `c:`: value phải là plain object (không null, không mảng) → không thì `'comment_shape'`; `v === 1`; `thread` là null hoặc chuỗi khoá `c:` hợp lệ; `author` chuỗi ≤ 40; `body` chuỗi, `trim()` không rỗng, ≤ 4000 → quá dài `'comment_body'`; `ts` số hữu hạn ≥ 0; `clientId` số nguyên === `commentKeyClient(key)` → lệch `'comment_client'`; `anchor` có khi và chỉ khi `thread === null` → sai `'comment_anchor'`; anchor: `start`/`end` chuỗi base64 (`^[A-Za-z0-9+/]+={0,2}$`) ≤ 128 ký tự, `quote` chuỗi ≤ 300 → sai `'comment_anchor'`; trường lạ ngoài danh sách → `'comment_shape'`. Sai kiểu trường khác → `'comment_shape'`.
  - khoá `s:`: phần sau `s:` phải là khoá `c:` hợp lệ (không thì `'comment_key'`); value plain object có đúng `resolved` boolean, `by` chuỗi ≤ 40, `clientId` số nguyên ≥ 0, `ts` số hữu hạn ≥ 0, không trường lạ → không thì `'comment_shape'`.
- `listThreads` thay type guard nội bộ bằng `validateCommentValue(key, value) === null`.
- Mục do `addComment`/`replyComment`/`setResolved` sinh ra luôn hợp lệ (test kiểm).
INVARIANTS
- `packages/core` thuần TS: được dùng `yjs`; KHÔNG react, `chrome.*`, `document`/`window`, KHÔNG Yjs provider.
- Hàm này sẽ được Worker (`apps/api` peer-guard, sub-phase sau) gọi trên dữ liệu do client không tin cậy gửi: phải thuần, không throw với bất kỳ input nào (kể cả object có getter, Proxy không cần xét; chỉ JSON), không đọc Y.Doc.
- Không đổi `FORMAT_VERSION`, không sửa `src/doc/schema.ts`.
- Không thêm dependency.
