# Plan: Phase 8 — 8g2 HistoryTimeline
Author: Hao Nguyen. Status: building. Phase: 8. Sub-phase: 8g2

Goal: a right-side panel "Lịch sử" on the extension app page.
- It lists checkpoints from `Y.Array "history"`, newest first, with the author and contributors.
- "Xem" previews that version read-only in the Viewer, under a banner "Đang xem mốc …".
- "Khôi phục" restores it through `restoreCheckpoint` using the app's long-lived tracker, so no duplicate 'auto' entry is written (8g1.2).
- Keyboard: ↑↓ move, Enter preview, Esc leaves the preview or closes the panel.

Facts (guard, branch phase-8):
- `HistoryEntry { id; actor: string; ts: number; label: string; clientIds: number[]; snapshot?: Uint8Array }`.
- Core has `listHistory(doc): HistoryEntry[]` and `getHistory(doc): Y.Array<HistoryEntry>`.
- `textAtCheckpoint(doc, entry)` and `restoreCheckpoint(doc, entry, actor, tracker?)` (8g1).
- `meta.actors` is a Y.Map keyed by String(clientID).
- useDocSession returns `checkpoints: CheckpointTracker | null`; the long-lived tracker is created with actor 'Bạn'.
- App:
  - reading Viewer at ~674: `<Viewer html={html} …/>`, with a second Viewer at ~714; `html` comes from a useMemo at ~338.
  - toolbarActions at ~488-493.
  - the left ToC rail is `.sidebar-toc`; there is no right panel yet.
- IconName has no 'history'/'clock'. Icon.test hard-codes the icon count (32).
- App.test mocks useDocSession by wrapping the real hook, plus a hoisted `docOverride`.

            }

BEHAVIOR    useHistory:
            - entries = listHistory(doc), recomputed on `getHistory(doc).observe`.
            - actors = a plain object from `doc.getMap('meta').get('actors')` (a Y.Map, or a plain object for v1 docs), recomputed on `meta.observeDeep`.
            - preview(id): previewText = textAtCheckpoint(doc, entry), or null. If the text is null, keep previewId null.
            - restore(id): call `restoreCheckpoint(doc, entry, actor, tracker ?? undefined)`, then clear the preview, and return the result.
            - Clear the preview when doc changes.
            - Unsubscribe on cleanup.
            App:
            - Add `historyOpen` state. Add a toolbar action `{ id: 'history', label: 'Lịch sử', icon: 'history', onSelect: toggle }` placed before 'settings'.
            - actor = the same display name the app already uses for collaboration (the trimmed displayName, or 'Bạn').
            - When open, render `<HistoryTimeline …/>` as a right column inside the app layout. Closing it also clears the preview.
            - While previewText is non-null:
              - Both Viewer usages render the html computed from previewText through the SAME render path as the existing `html` memo (same options and plugins).
              - Show a banner above the content: `role="status"` "Đang xem mốc <historyLabel(label)> — <time>. Đây là bản chỉ đọc." with a button "Thoát xem" (calls preview(null)).
              - The editor is untouched; preview never writes to the doc.
INVARIANTS  - apps/extension is the only layer that uses chrome.*. Cross-package imports use workspace names.
            - Restore must pass the app's long-lived tracker (`session.checkpoints`), otherwise a duplicate 'auto' entry appears.
            - Preview is read-only: no Y.Doc writes, and no change to isDirty or the save state.
            - Existing App tests pass unchanged.
