## Invariants
- `ExportModal` has a floating trigger button with download icon, styled identically to `SettingsModal` (glass blur, 10px radius, 38px x 38px).
- The modal dialog features backdrop blur, 16px radius, box-shadow, and 3 format cards: HTML, Word (.docx), and PDF.
- Triggering an export invokes `onExport(format: 'html' | 'docx' | 'pdf')`.
- In `App.tsx`:
  - PDF export triggers `printDocument()`.
  - HTML export calls `exportToHtml(...)` and initiates a browser file download.
  - Word export calls `mdastToDocx(...)` and initiates a browser file download.
- All tests in `@md-reader/ui` and `@md-reader/extension` must pass.
