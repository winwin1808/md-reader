### [x] 20d.1 — `tour.ts`: bước và hook tự chạy một lần
FILES       apps/extension/src/app/tour.ts · apps/extension/src/app/tour.test.ts · packages/ui/src/i18n/catalog/ext.ts
INTERFACES  Tiêu thụ từ `@md-reader/ui`: `type TourStep = { id: string; target: string[] | null; title: string; body: string }`.
            ```ts
            export const TOUR_DONE_KEY = 'mdr:tour-done'
            export const TOUR_PARAM = 'tour'
            export const TOUR_STEP_IDS = ['intro', 'view-mode', 'toc', 'search', 'present', 'mindmap', 'export', 'share', 'settings'] as const
            export function tourSteps(t: (key: string) => string): TourStep[]
            export function useGuidedTour(ready: boolean): { open: boolean; start(): void; onClose(result: 'done' | 'skipped'): void }
            ```
            `tourSteps`: mỗi id → `{ id, title: t(\`ext.tour.${id}.title\`), body: t(\`ext.tour.${id}.body\`), target }` với `intro` → `null`; `view-mode`, `toc` → `[\`[data-tour="${id}"]\`]`; còn lại → `[\`[data-tour="${id}"]\`, '[data-tour="more"]']`. (Kiểu `t` của app có thể chặt hơn — ép kiểu khoá bằng `as` nếu cần, ghi NOTES.)
            `useGuidedTour(ready)`: một lần duy nhất trong vòng đời hook, khi `ready` true và `new URLSearchParams(location.search).get(TOUR_PARAM) === '1'`: đọc `chrome.storage.local.get(TOUR_DONE_KEY)`; không có giá trị `true` → `open = true` (lỗi đọc → không mở, `console.warn`). `onClose(_)`: `open = false`; `chrome.storage.local.set({ [TOUR_DONE_KEY]: true })` (lỗi → `console.warn`, không ném); xoá tham số `tour` khỏi URL bằng `history.replaceState(history.state, '', <url không có tour>)`. `start()`: `open = true` bất kể khoá. `ready` đổi lại false→true không tự mở lần hai. Gọi `chrome.*` qua optional chaining.
            Catalog `ext.ts`, vi và en, 18 khoá `ext.tour.<id>.title` / `.body`:
