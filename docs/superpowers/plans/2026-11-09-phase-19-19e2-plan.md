INTERFACES  Tiêu thụ từ `@md-reader/ui`: `useSlidePagination(slides, { enabled, mermaid, presentationSettings }): { slides: Slide[]; ready: boolean; warnings: SlideFitWarning[]; stage: React.ReactNode }`, `SlideContent({ html, mermaid, zoom })`. `Deck` có prop `fitWarnings`.
            Trong `App.tsx`:
            - Đổi tên memo `slides` hiện tại thành `baseSlides`, deps giữ nguyên.
            - Thêm `presentationSettings = useMemo(...)` từ các trường `readerSettings.slide*` đang viết inline trong JSX của `Deck`; `Deck` dùng biến này.
            - `const { slides, ready: slidesReady, warnings: slideWarnings, stage: slideStage } = useSlidePagination(baseSlides, { enabled: baseSlides.length > 0, mermaid: readerSettings.enableMermaid !== false, presentationSettings })`, gọi TRƯỚC nhánh `if (isSpeakerMode)`.

            - `Deck` chỉ render khi `isPresenting && slidesReady`, khi `isPresenting && !slidesReady` hiện `<LazyFallback />`. Truyền `fitWarnings={slideWarnings}`. `initialSlide` kẹp như trên.
            - Khối in: `(printHtml ?? slides.map((sl) => ({ id: sl.id, html: sl.html, zoom: sl.zoom })))`, mỗi slide render `<div key=... className="deck-print-slide deck-slide"><SlideContent html={slide.html} mermaid={false} zoom={slide.zoom} /></div>`. Kiểu của `printHtml` mở rộng thành `{ id: string; html: string; zoom?: number }[] | null`.
