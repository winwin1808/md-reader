### [x] T1 — Export HTML: allowlist MIME ảnh, escape thuộc tính, meta CSP

INTERFACES  Không đổi `ExportHtmlOptions` / `exportToHtml`. Nội bộ:
            - `const IMAGE_MIME = /^image\/(png|jpe?g|gif|webp|avif|bmp|svg\+xml|x-icon)$/i`.
            - Kiểm MIME ở chỗ dùng kết quả (sau `fetchImage`, áp cho cả fetcher do người gọi truyền vào, không chỉ default): MIME không khớp
              hoặc base64 không khớp `/^[A-Za-z0-9+/]+=*$/` → bỏ qua, giữ nguyên `src` gốc. MIME ghi chữ thường.

            - Trong `<head>`, ngay sau `<meta charset>`: `<meta http-equiv="Content-Security-Policy" content="default-src 'none'; img-src data: https: http:; style-src 'unsafe-inline'; font-src data: https:; base-uri 'none'; form-action 'none'">`.
INVARIANTS  - `packages/core` thuần TS: không react / `chrome.*` / `document`. Không thêm dependency.
            - File export là HTML tự chứa, không script; CSP không được chặn ảnh đã nhúng `data:` hay CSS inline của nó.
            - Ảnh hợp lệ (png/jpeg/webp/svg) vẫn được nhúng như cũ — test export hiện có phải xanh.
TEST        pnpm --filter core test src/export/html.test.ts
            Thêm test (đỏ trước khi sửa): `fetchImage` giả trả `{ base64: 'AAAA', mimeType: 'x" onerror="window.__pwn=1' }` → output không chứa

            output chứa `http-equiv="Content-Security-Policy"` và `default-src 'none'`, không chứa `<script`.
            Sau đó chạy cả `pnpm --filter core test` xanh.
COMMIT      fix(core): export HTML chỉ nhúng ảnh MIME image/*, escape src, thêm CSP (11b)

### [x] T2 — CSP + header bảo mật cho trang web chia sẻ
parallel-group: 11b
FILES       apps/web/public/_headers (mới) · apps/web/src/headers.test.ts (mới — file test mới duy nhất)
INTERFACES  `_headers` (cú pháp Cloudflare static assets):
            ```
            /*
              Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https:; font-src 'self' data:; connect-src 'self'; worker-src 'self' blob:; frame-ancestors 'none'; base-uri 'none'; object-src 'none'; form-action 'self'
              X-Content-Type-Options: nosniff
              Referrer-Policy: no-referrer
              X-Frame-Options: DENY
            ```
            Test đọc file bằng `fs` (đường dẫn tương đối tới file test), parse dòng `Content-Security-Policy`, khẳng định: có `script-src 'self'` và
            không có `'unsafe-inline'`/`'unsafe-eval'` trong script-src; `frame-ancestors 'none'`; `object-src 'none'`; đủ 3 header còn lại.
            Kiểm thêm sau `pnpm --filter web build`: `apps/web/dist/_headers` tồn tại và `dist/index.html` không có `<script>` không `src`.
INVARIANTS  - `apps/web` không dùng `chrome.*`. Không thêm dependency.
            - Web nói với API cùng origin (Worker phục vụ cả assets lẫn `/api/*`, `/parties/*` qua ws cùng host) → `connect-src 'self'` đủ;
              nếu tìm thấy `fetch`/`WebSocket` tới origin khác trong `apps/web/src` thì DỪNG, báo BLOCKED kèm URL.
            - Không chạm máy chủ thật. Được phép xác minh cục bộ: `cd apps/api && npx wrangler dev --local --port 8799` rồi
              `curl -sI http://127.0.0.1:8799/s/x | grep -i content-security` (dừng wrangler sau đó); ghi kết quả vào NOTES. Nếu wrangler dev
              không chạy được, ghi lý do vào NOTES — không phải BLOCKED.
TEST        pnpm --filter web test src/headers.test.ts ; sau đó `pnpm --filter web test` xanh và `pnpm --filter web build` exit 0.
COMMIT      feat(web): CSP và header bảo mật qua _headers (11b)
