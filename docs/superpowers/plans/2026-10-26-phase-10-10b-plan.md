### [x] 10b.1 — Kiểu message và `parseBridgeMessage`
FILES       packages/core/src/bridge/protocol.ts · packages/core/src/bridge/protocol.test.ts · packages/core/src/index.ts
INTERFACES  Sinh ra (export từ `@md-reader/core` qua `export * from './bridge/protocol.js'` trong index.ts — theo đúng kiểu export các module khác trong index.ts):
            ```ts
            export const BRIDGE_PROTOCOL = 1
            export const BRIDGE_PORTS: readonly number[]            // [47821, 47822, …, 47830] (10 cổng)
            export const BRIDGE_MAX_MARKDOWN = 2_000_000
            export const BRIDGE_MAX_TITLE = 200
            export type BridgeTool = 'publish_doc' | 'list_docs' | 'get_doc' | 'update_doc' | 'share_doc' | 'list_links' | 'revoke_link'
            export const BRIDGE_TOOLS: readonly BridgeTool[]        // đúng 7 tên trên, theo thứ tự trên
            export type BridgeErrorCode = 'NOT_CONNECTED' | 'NOT_PAIRED' | 'DENIED' | 'TIMEOUT' | 'NOT_FOUND' | 'CONFLICT' | 'INVALID_ARGS' | 'SHARE_FAILED' | 'INTERNAL'
            export interface PublishDocArgs { title: string; markdown: string; open?: boolean }
            export interface PublishDocResult { docId: string }
            export interface ListDocsResult { docs: Array<{ docId: string; title: string; lastOpenedAt: number; shared: boolean }> }
            export interface GetDocArgs { docId: string }
            export interface GetDocResult { docId: string; title: string; markdown: string; hash: string; shared: boolean }
            export interface UpdateDocArgs { docId: string; markdown: string; baseHash: string }
            export interface UpdateDocResult { hash: string }
            export interface ShareDocArgs { docId: string; role: 'view' | 'edit'; expiresInDays: 7 | 30 | null }
            export interface ShareDocResult { url: string; tokenPrefix: string; expiresAt: number | null }
            export interface ListLinksArgs { docId: string }
            export interface ListLinksResult { links: Array<{ tokenPrefix: string; role: 'view' | 'edit'; label: string; expiresAt: number | null; revokedAt: number | null }> }
            export interface RevokeLinkArgs { docId: string; tokenPrefix: string }
            export interface RevokeLinkResult { revoked: boolean }
            export interface BridgeArgsMap { publish_doc: PublishDocArgs; list_docs: Record<string, never>; get_doc: GetDocArgs; update_doc: UpdateDocArgs; share_doc: ShareDocArgs; list_links: ListLinksArgs; revoke_link: RevokeLinkArgs }
            export interface BridgeResultMap { publish_doc: PublishDocResult; list_docs: ListDocsResult; get_doc: GetDocResult; update_doc: UpdateDocResult; share_doc: ShareDocResult; list_links: ListLinksResult; revoke_link: RevokeLinkResult }
            export interface BridgeHello { type: 'hello'; protocol: 1; client: string; pairKey: string }
            export interface BridgeRequest { type: 'req'; id: string; tool: BridgeTool; args: unknown }
            export interface BridgeWelcome { type: 'welcome'; paired: boolean }
            export interface BridgeReject { type: 'reject'; code: 'DENIED' | 'PROTOCOL' }
            export interface BridgePing { type: 'ping' }
            export type BridgeResponse =
              | { type: 'res'; id: string; ok: true; result: unknown }
              | { type: 'res'; id: string; ok: false; error: { code: BridgeErrorCode; message: string } }
            export type BridgeMessage = BridgeHello | BridgeRequest | BridgeWelcome | BridgeReject | BridgeResponse | BridgePing
            export function parseBridgeMessage(raw: string): BridgeMessage | null
            ```
            `parseBridgeMessage`: JSON.parse trong try (hỏng → null); phải là object không null; theo `type`:
            hello cần `protocol === 1`, `client` string 1..100 ký tự, `pairKey` string 16..200 ký tự;
            req cần `id` string 1..64, `tool` ∈ BRIDGE_TOOLS, có khoá `args` (giá trị bất kỳ, chưa validate ở đây);
            welcome cần `paired` boolean; reject cần `code` ∈ {'DENIED','PROTOCOL'}; ping không cần gì thêm;
            res cần `id` string, `ok` boolean; ok=true cần có khoá `result`; ok=false cần `error.code` ∈ 9 mã và `error.message` string.
            `type` lạ hoặc thiếu trường → null. Trả về object chỉ gồm các trường đã liệt kê (không mang trường thừa).
INVARIANTS  `packages/core` thuần TS: KHÔNG react, KHÔNG `chrome.*`, KHÔNG `document`/`window`, KHÔNG Node API (`fs`, `net`, `ws`) — module này chạy cả trong Node lẫn service worker.
            Không thêm dependency mới vào packages/core.
            Không đụng module khác của core ngoài thêm một dòng export trong `src/index.ts`.

### [x] 10b.2 — `validateToolArgs` và `textHash`
FILES       packages/core/src/bridge/protocol.ts · packages/core/src/bridge/protocol.test.ts · packages/core/src/doc/hash.ts
INTERFACES  Tiêu thụ: các kiểu từ 10b.1; `hashText(text: string): Promise<string>` ở `packages/core/src/doc/hash.ts` (SHA-256 hex — chính là hash dùng cho `originHash`).
            Sinh ra:
            ```ts
            export function validateToolArgs<T extends BridgeTool>(tool: T, args: unknown):
              { ok: true; args: BridgeArgsMap[T] } | { ok: false; message: string }
            export function textHash(text: string): Promise<string>   // = hashText(text), import từ '../doc/hash.js'
            ```
            Luật (args phải là object không null; trả `args` mới chỉ gồm trường đã biết):
            - publish_doc: `title` string, trim dài 1..BRIDGE_MAX_TITLE; `markdown` string dài ≤ BRIDGE_MAX_MARKDOWN; `open` boolean hoặc vắng.
            - list_docs: bất kỳ object (kể cả `{}`) → `{}`.
            - get_doc / list_links: `docId` string không rỗng, ≤ 64 ký tự.
            - update_doc: `docId` như trên; `markdown` như publish; `baseHash` khớp /^[0-9a-f]{64}$/.
            - share_doc: `docId`; `role` ∈ {'view','edit'}, vắng → 'view'; `expiresInDays` ∈ {7, 30, null}, vắng → 7.
            - revoke_link: `docId`; `tokenPrefix` string dài đúng 6.
            `message` là tiếng Anh ngắn nêu trường sai, ví dụ `"title must be 1..200 characters"`.
            Không sửa `hash.ts` trừ khi `hashText` chưa được export (nếu đã export thì bỏ qua file này).
INVARIANTS  `packages/core` thuần TS: KHÔNG react / `chrome.*` / `document` / Node API; `crypto.subtle` qua globalThis như hash.ts đang làm.
            `textHash` phải cho cùng kết quả với `hashText` trên cùng chuỗi (test so sánh trực tiếp) — extension dùng nó làm `baseHash` chống ghi đè.
            Không thêm dependency.
