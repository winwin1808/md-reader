INVARIANTS
- Packages boundary: `packages/ui` is pure React & CSS (NO `chrome.*`), pure presentation.
- Bundle budget constraint: Zero external heavyweight libraries (NO `@excalidraw/excalidraw` directly in package bundle). Hand-crafted clean SVG vector renderer for common Excalidraw primitives.
- In `packages/ui/src/components/ExcalidrawBlock.tsx`:
  - When `isAppPage === false`:
    - Renders lightweight card `.excalidraw-placeholder-card`:
      - Icon 🎨
      - Title "Sơ đồ Excalidraw"
      - Hint "Nhấn để mở trong MD Reader để xem và tương tác đầy đủ"
  - When `isAppPage !== false`:
    - Safely parses `data` (handles JSON object or array, or raw string).
    - If JSON parse fails or elements missing: renders error fallback card showing raw content safely.
    - If valid:
      - Extracts elements: rectangle, diamond, ellipse, line, arrow, text, freedraw.
      - Calculates bounding box `(minX, minY, maxX, maxY)` with padding ~24px.
      - Renders SVG with responsive `viewBox` matching bounding box.
      - Supports shapes:
        - `rectangle`: `<rect x={el.x} y={el.y} width={el.width} height={el.height} stroke={el.strokeColor} fill={el.backgroundColor} ... />`
        - `ellipse`: `<ellipse cx={el.x + el.width/2} cy={el.y + el.height/2} rx={Math.abs(el.width)/2} ry={Math.abs(el.height)/2} ... />`
        - `diamond`: `<polygon points="..." ... />`
        - `line` / `arrow`: `<line>` or `<polyline>` or `<path>` with arrow marker definition `<marker id="arrow" ... />`
        - `text`: `<text x={el.x} y={el.y + (el.fontSize || 16)} fontSize={el.fontSize || 16} fill={el.strokeColor}>{el.text}</text>`
        - `freedraw`: `<path d={pointsToSvgPath(el.points, el.x, el.y)} ... />`
      - Floating mini action bar: Copy SVG (`Sao chép SVG`), Download SVG.
- In `packages/ui/src/theme/excalidraw.css`:
  - Styles for `.excalidraw-container`: margin 24px 0, border 1px solid var(--md-border), border-radius 10px, overflow hidden, background var(--md-bg-card).
  - Styles for `.excalidraw-svg`: width 100%, max-height 500px, display block.
  - Styles for `.excalidraw-placeholder-card`: dashed border, flex row align center, gap 12px, padding 16px 20px, border-radius 8px.
  - Import `excalidraw.css` in `packages/ui/src/viewer.css`.
