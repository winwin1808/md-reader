### [x] 10m.2 — App page: `update_doc` + chờ session + bắt lỗi executor
FILES       apps/extension/src/app/bridge-executor.ts · apps/extension/src/app/bridge-executor.test.ts · apps/extension/src/app/App.tsx
INTERFACES  Tiêu thụ: `applyTextChange(yText, next, origin?) => boolean` và `CheckpointTracker` (`flush(label, actor, opts?: { force?: boolean })`) từ
            `@md-reader/core`; `textHash`, `UpdateDocArgs { docId; markdown; baseHash }`, `UpdateDocResult { hash }` từ `@md-reader/core/bridge`.
            ```ts
            export const ORIGIN_MCP = 'mcp'
            export const AI_CHECKPOINT_LABEL = 'AI: cập nhật'
            export interface ExecSession { docId: string; title: string; yText: Y.Text; shared: boolean; synced: boolean; checkpoints: CheckpointTracker | null }
            // createBridgeExecutor giữ chữ ký cũ (get, opts?: { waitMs; pollMs; sleep })
            ```
            Thay đổi hành vi:
            - Chờ: `get()` trả null cũng coi như "chưa sẵn sàng" — chờ trong cùng vòng `waitMs` như `!synced`; hết giờ mà vẫn null → `NOT_FOUND`
              'document is not open in this tab'; hết giờ mà chưa synced → `TIMEOUT` như cũ. Session có docId KHÁC args.docId → `NOT_FOUND` ngay.
            - update_doc (sau khi chờ xong, dùng session MỚI NHẤT): `cur = yText.toString()`; `await textHash(cur) !== baseHash` → `CONFLICT`
              'document changed since baseHash; current hash <hash>' (agent gọi lại get_doc). Khớp → `checkpoints?.flush('auto', 'Bạn')` (khép sửa
              tay đang dở của người dùng), `changed = applyTextChange(yText, markdown, ORIGIN_MCP)`, nếu `changed` → `checkpoints?.flush(AI_CHECKPOINT_LABEL,
              'AI', { force: true })`. Kết quả `{ hash: await textHash(yText.toString()) }`.
            - share_doc / list_links / revoke_link vẫn `INTERNAL` 'not implemented yet' (10n).
            App.tsx: `execSessionRef` thêm `checkpoints: session.checkpoints ?? null`; listener EXEC đổi thành
            `exec(m.req).then(sendResponse, (err) => sendResponse({ type: 'res', id: m.req.id, ok: false, error: { code: 'INTERNAL', message: String(err) } }))`
            — giữ nguyên kiểm `sender.id === chrome.runtime.id && !sender.tab`.
            Test bridge-executor.test.ts (viết trước, Y.Doc thật tạo bằng `createDoc`/`ensureDoc` của core, tracker thật `createCheckpointTracker`):
            (1) đổi đúng một từ → quan sát `yText.observe` thấy delta chỉ 1 delete + 1 insert, transaction origin `'mcp'`, hash trả về = textHash text mới;
            (2) hội tụ: replica B (Y.Doc thứ hai, đồng bộ qua `Y.encodeStateAsUpdate`/`Y.applyUpdate`) sửa đoạn cuối trong khi A nhận update_doc
                sửa đoạn đầu → sau khi trao đổi update hai bên, cả hai text bằng nhau và chứa cả hai sửa;
            (3) baseHash sai → CONFLICT, text không đổi, message chứa hash hiện tại;
            (4) history có thêm entry label 'AI: cập nhật' actor 'AI'; markdown y hệt → không thêm entry 'AI: cập nhật';
            (5) get() null rồi có session sau 2 lần poll → get_doc trả đúng; luôn null → NOT_FOUND.
            Các test cũ cập nhật thêm `checkpoints: null`.
INVARIANTS  Mọi ghi `Y.Text` đi qua `applyTextChange` (delta nhỏ nhất) — cấm xoá toàn bộ rồi chèn lại.
            Y.Doc là nguồn sự thật; không đổi schema (`Y.Text "source"`, `Y.Map "meta"`, `Y.Array "history"`), không tăng `formatVersion`.
            Checkpoint ghi qua `CheckpointTracker.flush` (có `clientIds` + snapshot) — không push thẳng vào `history`.
            Chỉ `apps/extension` dùng `chrome.*`; App.tsx chỉ đổi ref session + nhánh lỗi của listener; test App.test.tsx xanh nguyên.
