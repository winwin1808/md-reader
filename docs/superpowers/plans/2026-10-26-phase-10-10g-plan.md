### [x] 10g.2 — Form "Báo cáo nội dung" + trang đã gỡ
FILES       packages/core/src/share/share.ts · apps/web/src/share-client.ts · apps/web/src/SharePage.tsx · apps/web/src/SharePage.test.tsx · packages/ui/src/i18n/catalog/web.ts
INTERFACES  Tiêu thụ: `useNotices`, `NoticeStack` (10g.1). Route máy chủ (10f): `POST /api/report` body `{ token, reason }` →
            202 / 400 / 404 / 429 (`{error:'RATE_LIMITED', retryAfter}`).
            core/share: `API_PATHS` thêm `report: '/api/report'`; thêm `export interface ReportRequest { token: string; reason: string }`.
            share-client.ts:
            ```ts
            export type ReportResult = 'sent' | 'limited' | 'failed'
            export async function sendReport(token: string, reason: string, fetchFn: typeof fetch = fetch): Promise<ReportResult>
            //   POST API_PATHS.report, JSON; 202 → 'sent'; 429 → 'limited'; còn lại hoặc lỗi mạng → 'failed'.
            ```
            SharePage: trong `<footer className="web-footer">` thêm nút `t('web.reportLink')` (chỉ khi `token` có); bấm → hiện form
            nhỏ ngay dưới (textarea `aria-label={t('web.reportReason')}`, maxLength 500, nút Gửi `t('web.reportSend')` disabled khi
            trim rỗng, nút Huỷ `t('web.reportCancel')`). Kết quả → `push('info', t('web.reportSent'))` và đóng form /
            `push('error', t('web.reportLimited'))` / `push('error', t('web.reportFailed'))`. Render `<NoticeStack>` trong SharePage.
            Đổi văn bản `'web.linkGone'` thành `'Tài liệu này đã bị gỡ hoặc link không còn hiệu lực'` /
            `'This document was removed or the link is no longer valid'`.
            Khoá mới (vi / en): `web.reportLink` 'Báo cáo nội dung' / 'Report content'; `web.reportReason` 'Lý do báo cáo' /
            'Reason'; `web.reportSend` 'Gửi báo cáo' / 'Send report'; `web.reportCancel` 'Huỷ' / 'Cancel';
            `web.reportSent` 'Đã gửi báo cáo. Cảm ơn bạn.' / 'Report sent. Thank you.'; `web.reportLimited`
            'Bạn đã gửi quá nhiều báo cáo hôm nay' / 'Too many reports today'; `web.reportFailed` 'Không gửi được báo cáo' /
            'Could not send the report'.
            Test (viết trước): `sendReport` map 202/429/500/throw đúng; SharePage với `load` giả trạng thái ready: mở form, gõ lý do,
            gửi với fetch giả 202 → hiện "Đã gửi báo cáo" và form đóng; 429 → hiện thông báo giới hạn; nút Gửi disabled khi rỗng.
INVARIANTS  `packages/core/src/share/share.ts` chỉ thêm export, không đổi export có sẵn; core KHÔNG react/`chrome.*`/`document`.
            `apps/web` KHÔNG `chrome.*`; import bằng tên workspace.
            Không gửi gì lên máy chủ khi người dùng chưa bấm Gửi; lý do ≤ 500 ký tự (khớp `MAX_REASON` của api).
            Test cũ của web/core/ui xanh nguyên (kiểm i18n test nếu có so số khoá vi/en).
TEST        pnpm --filter @md-reader/web test src/SharePage.test.tsx
