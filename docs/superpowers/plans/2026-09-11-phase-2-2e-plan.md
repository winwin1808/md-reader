## Invariants
- Per constraint #7: PDF is generated via Print CSS + `window.print()`. NO external PDF libraries, NO headless browsers.
- Print CSS resets background to pure white `#ffffff`, foreground to crisp black `#000000`.
- Hides UI elements: sidebars, ToC, settings button, modal dialogs, and floating controls during printing.
- Uses `@page` rules with standard margins and proper page-break controls (`break-inside: avoid` for tables/code/images, `break-after: avoid` for headings).
- `printDocument()` triggers `window.print()`, gracefully checking for window existence.
- Export `printDocument` from `@md-reader/ui`.
