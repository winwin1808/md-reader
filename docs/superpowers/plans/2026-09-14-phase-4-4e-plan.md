- In `packages/ui/src/export/export-mindmap.ts`:
  - `exportMindmapToSvg(svgElement: SVGSVGElement, title: string)`:
    - Clones SVG node.
    - Ensures `xmlns="http://www.w3.org/2000/svg"`.
    - Resets transform attribute on inner `<g>` to capture entire bounds with padding, or uses `viewBox`.
    - Serializes via `XMLSerializer`.
  - `exportMindmapToPng(svgElement: SVGSVGElement, title: string, scale = 2)`:
    - Obtains SVG string.
    - Loads into `new Image()` via `data:image/svg+xml;charset=utf-8,...` or `URL.createObjectURL(svgBlob)`.
    - Draws onto HTML5 `<canvas>` sized `width * scale` and `height * scale`.
    - Resolves canvas as PNG Blob (`image/png`).
  - `downloadBlob(blob: Blob, filename: string)`:
    - Creates temporary object URL and `<a>` download anchor, clicks, and revokes URL.
