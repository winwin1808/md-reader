- Packages boundary: `apps/extension` is the ONLY layer allowed to use `chrome.*`.
- Content script budget: `dist/content.js` <= 61440 bytes gz.
- In `apps/extension/src/app/App.tsx`:
  - Manage state for `readerSettings: ReaderSettings` backed by `chrome.storage.sync`:
    - Defaults:
      - `stripFrontmatter: true`
      - `displayMetadata: false`
      - `advancedTables: true`
      - `taskLists: true`
      - `enableMath: true`
      - `enableMermaid: true`
      - `enablePlantUml: false`
      - `enableGraphviz: false`
      - `githubAlerts: true`
      - `localizeAlerts: false`
      - `typographer: false`
      - `externalLinks: false`
      - `showWordCount: true`
      - `autoHideWordCount: true`
      - `showReadingProgress: true`
      - `celebrationConfetti: true`
  - In `renderToHtml(parsed, renderOptions)`:
    - Pass `{ stripFrontmatter, displayMetadata, typographer, externalLinks, githubAlerts, localizeAlerts: localizeAlerts ? 'vi' : 'en' }`.
  - Condition `ReadingProgress` on `showReadingProgress !== false`.
  - Render `WordCountBar`:
    `<WordCountBar text={markdown} visible={readerSettings.showWordCount !== false} autoHide={readerSettings.autoHideWordCount !== false} />`
  - Confetti celebration at document end:
    - Detect when user reaches scroll bottom (`window.innerHeight + window.scrollY >= document.documentElement.scrollHeight - 60`).
    - If `celebrationConfetti !== false`, trigger confetti active for 3s (one time per document read).
    - Render `<CelebrationConfetti active={isConfettiActive} onComplete={() => setIsConfettiActive(false)} />`.
  - In `<Deck ... />`:
    - Pass `presentationSettings={{ slideBgColor: readerSettings.slideBgColor, slideTextColor: readerSettings.slideTextColor, slideHeadingColor: readerSettings.slideHeadingColor, slideAccentColor: readerSettings.slideAccentColor, slideFont: readerSettings.slideFont, slideBgImage: readerSettings.slideBgImage, slideImageOpacity: readerSettings.slideImageOpacity }}`.
  - In `<SettingsModal ... />`:
    - Pass `settings={readerSettings}` and `onSettingChange={handleSettingChange}`.
    - `handleSettingChange` updates local React state and writes `{ [key]: value }` to `chrome.storage.sync.set(...)`.
- In `apps/extension/src/app/App.test.tsx`:
  - Test initial loading of settings from `chrome.storage.sync`.
  - Test updating setting persists to `chrome.storage.sync.set`.
  - Test WordCountBar, CelebrationConfetti, and Deck receive settings properly.
