## Invariants
- `packages/core` is pure TypeScript: NO `react`, NO `document` or DOM APIs, NO `chrome.*`.
- Uses `docx` library (browser and Node compatible) to map `mdast` Root AST into a Document and export with `Packer.toBlob(doc)`.
- Support standard Markdown constructs: Headings (H1-H6), Paragraphs with formatting (bold, italic, strikethrough, inline code, link text), Lists (ordered, unordered), Code blocks, Blockquotes, Tables, Thematic breaks.
- Graceful fallbacks: If image is not in `imageMap` or node is unknown, fall back to alt text / text representation without throwing.
- Export `mdastToDocx` and `ExportDocxOptions` from `@md-reader/core`.
