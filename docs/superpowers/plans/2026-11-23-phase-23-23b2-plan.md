### [x] 23b2-1 — `CommentLayer`: chọn chữ → nút "Bình luận" → hộp nhập → `onCreate`
FILES       packages/ui/src/components/CommentLayer.tsx (mới), packages/ui/src/components/CommentLayer.test.tsx (mới), packages/ui/src/index.ts, packages/ui/src/i18n/catalog/shell.ts
INTERFACES  (consume từ `@md-reader/core`) `CommentThread`, `parseSourcePos(attr: string | null): SourceBlock | null`, `selectionToSourceRange(source, block, selectedText, occurrence): { from; to; exact }`, `COMMENT_BODY_MAX` (4000), `COMMENT_AUTHOR_MAX` (40). (produce, export từ `packages/ui/src/index.ts`)
```ts
export interface CommentLayerProps {
  container: HTMLElement | null           // phần tử gốc của Viewer
  source: string
  threads: CommentThread[]
  activeId: string | null
  enabled: boolean                        // false: không nút, không tô (ví dụ đang xem mốc lịch sử)
  onCreate(range: { from: number; to: number }, body: string, author?: string): void
  onSelect(id: string): void
  askName: boolean                        // true: hộp bình luận có ô "Tên của bạn"
}
export function CommentLayer(props: CommentLayerProps): JSX.Element | null
```
Hành vi:
- Lắng `selectionchange` trên `document` (gỡ khi unmount / `container` đổi). Khi vùng chọn không rỗng, `!isCollapsed`, và cả đầu lẫn cuối nằm trong `container` → hiện nút nổi `<button className="comment-add-btn">{t('comments.add')}</button>` (render qua portal vào `container.ownerDocument.body`, vị trí `position: fixed` theo `range.getBoundingClientRect()` — dùng 0 nếu jsdom trả rect rỗng). Vùng chọn ra ngoài/thu gọn → ẩn nút (trừ khi hộp nhập đang mở).
- `enabled=false` hoặc `container=null` → không lắng, không nút, render `null`.
- Bấm nút → chụp lại range nguồn NGAY lúc đó (vùng chọn sẽ mất khi focus textarea) rồi mở hộp nhập `.comment-composer`: textarea (`maxLength={COMMENT_BODY_MAX}`, `aria-label={t('comments.add')}`), nếu `askName` thì thêm `<input aria-label={t('comments.yourName')} maxLength={COMMENT_AUTHOR_MAX}>`, nút Gửi (`t('comments.send')`) và Huỷ (`t('comments.cancel')`). Ctrl/Cmd+Enter trong textarea → gửi; Esc → huỷ. Gửi khi `body.trim()` rỗng → không làm gì; ngược lại `onCreate(range, body, askName ? (name.trim() || undefined) : undefined)` rồi đóng hộp.
- Ánh xạ vùng chọn → range nguồn:
  - Khối của một điểm = phần tử tổ tiên gần nhất (kể cả chính nó) có thuộc tính `data-sp`, nằm trong `container`; `parseSourcePos(el.getAttribute('data-sp'))`. Không có khối nào ở đầu hoặc cuối → không hiện nút.
  - Cùng khối: `selectedText = range.toString()`; `occurrence` = số lần `selectedText` xuất hiện (không chồng) trong `textContent` của khối TRƯỚC điểm đầu vùng chọn (dựng `Range` từ đầu khối tới điểm đầu, lấy `toString()`); → `selectionToSourceRange(source, block, selectedText, occurrence)`.
  - Khác khối: `from` = kết quả ánh xạ phần chọn nằm trong khối đầu (chữ từ điểm đầu tới hết khối đầu, occurrence tính như trên), `to` = `end` của khối cuối.
  - Kết quả `from >= to` → không hiện nút.
- i18n vi + en, thêm vào `shell.ts` cạnh các khoá `comments.*` hiện có: `comments.add` ("Bình luận" / "Comment"), `comments.yourName` ("Tên của bạn" / "Your name"), `comments.cancel` ("Huỷ" / "Cancel"). `comments.send` đã có.
INVARIANTS
- `packages/ui` là React; KHÔNG `chrome.*`. Import chéo package bằng tên workspace `@md-reader/core`.
- KHÔNG sửa `Viewer.tsx` và không import CommentLayer vào bất kỳ thứ gì content script dùng — content.js (≤ 60KB gz) phải không đổi.
- Nội dung bình luận là văn bản thuần, tối đa 4000 ký tự; tên tối đa 40.
- Không thêm dependency; không state-manager toàn cục. Mọi chuỗi qua i18n vi + en.

### [x] 23b2-2 — `CommentLayer`: tô vùng chữ, viền khối, mốc lề
FILES       packages/ui/src/components/CommentLayer.tsx, packages/ui/src/components/CommentLayer.test.tsx, packages/ui/src/theme/comments.css
INTERFACES  không đổi `CommentLayerProps`. CSS sẵn có trong `comments.css` (từ 23b1): `::highlight(mdr-comment)`, `::highlight(mdr-comment-active)`, `.comment-block-marked`.
Hành vi:
- Chỉ khi `enabled && container`: với mỗi thread `!resolved && range !== null`:
  - Khối đích = các phần tử `[data-sp]` trong `container` có khoảng giao `[range.from, range.to)`; lấy khối giao đầu tiên theo thứ tự tài liệu (khối lồng: ưu tiên khối sâu nhất — bỏ khối chứa khối con cũng giao).
  - Tìm `quote` trong `textContent` của khối đích (đi qua các text node, dựng DOM `Range` theo offset ký tự); tìm thấy → thêm `Range` vào `Highlight` của `'mdr-comment'` (hoặc `'mdr-comment-active'` nếu `id === activeId`); không thấy, hoặc môi trường không có `CSS.highlights`/`Highlight` → thêm class `comment-block-marked` (và `data-comment-active` nếu active) vào khối.
  - Mỗi lần `threads`/`activeId`/`enabled`/`container`/`source` đổi: xoá highlight cũ (`CSS.highlights.delete` hai tên) và gỡ mọi class/thuộc tính đã thêm trước đó, rồi áp lại. Unmount → dọn sạch như trên.
- Mốc lề: lớp `<div className="comment-markers" aria-hidden="false">` đặt tuyệt đối trong `container` (portal vào `container`; `container` cần `position: relative` — đặt qua CSS `.comment-markers` dùng `position:absolute; inset:0 0 auto auto; pointer-events:none`, nút bên trong `pointer-events:auto`). Với mỗi khối đích có ≥1 thread mở: một `<button className="comment-marker" aria-label={`${t('comments.title')}: ${n}`}>` hiển thị số thread, `top` = `block.offsetTop`, nằm lề phải; bấm → `onSelect(id thread đầu tiên của khối)`; khối có thread active → thêm `data-active`. Vị trí cập nhật bằng `ResizeObserver` trên `container` (kiểm tồn tại trước khi dùng — jsdom không có).
- Bấm (click) vào chữ trong container khi vùng chọn đang thu gọn: khối `[data-sp]` gần nhất chứa đích bấm là khối đích của ≥1 thread mở → `onSelect(id thread đầu tiên của khối)`. (Không dùng `caretRangeFromPoint` — jsdom không có.)
- `comments.css`: thêm style `.comment-markers`, `.comment-marker` (chấm tròn token accent, số nhỏ, `[data-active]` đậm hơn), `.comment-add-btn`, `.comment-composer` (thẻ nổi, bóng nhẹ, token có sẵn, không mã màu cứng). i18n: không thêm khoá mới — `aria-label` của mốc = `${t('comments.title')}: ${n}` (khoá đã có), nên task này không chạm `shell.ts`.
INVARIANTS
- `packages/ui` là React; KHÔNG `chrome.*`. Import `@md-reader/core` bằng tên workspace.
- KHÔNG sửa `Viewer.tsx`; content.js không đổi. Không sửa DOM nội dung tài liệu ngoài thêm/gỡ class `comment-block-marked` và thuộc tính `data-comment-active` (gỡ sạch khi dọn).
- CSS chỉ dùng token có sẵn (Giấy / Than chì / tương phản cao). Không thêm dependency.
