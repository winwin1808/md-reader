### [x] 10n.3 — Executor: share_doc / list_links / revoke_link
FILES       apps/extension/src/app/bridge-executor.ts · apps/extension/src/app/bridge-executor.test.ts
INTERFACES  Tiêu thụ: `ConfirmRequest` từ `@md-reader/ui`; `ShareLink`, `CreateLinkRequest`, `buildShareUrl(serverUrl, token)` từ `@md-reader/core`;
            `ShareDocArgs/Result`, `ListLinksArgs/Result`, `RevokeLinkArgs/Result` từ `@md-reader/core/bridge`.
            ```ts
            export interface ExecShare {
              serverUrl: string
              enable(): Promise<unknown>                          // = useShare().enable
              createLink(req: CreateLinkRequest): Promise<ShareLink>
              revoke(prefix: string): Promise<void>
              refresh(): Promise<unknown>
              links(): ShareLink[]                                 // danh sách mới nhất (ref)
              bound(): boolean                                     // đã có binding phòng
            }
            export interface ExecSession { …giữ nguyên…; share: ExecShare | null;
              confirm: ((c: ConfirmRequest, client: string) => Promise<boolean>) | null }
            export const DAY_MS = 86_400_000
            // executor: (req: BridgeRequest, client: string) => Promise<BridgeResponse>
            ```
            Chờ sẵn sàng như get_doc (`synced`). `share`/`confirm` null → `INTERNAL` 'sharing unavailable'.
            - list_links: không hỏi. `bound()` false → `{ links: [] }`. Ngược lại `await refresh()` rồi map `links()` →
              `{ tokenPrefix, role, label, expiresAt, revokedAt }` (KHÔNG trả token).
            - share_doc: `ok = await confirm({ kind:'share', docTitle: title, role, expiresInDays }, client)`; false → `DENIED` 'user declined'.
              Đồng ý → `await enable()`; `l = await createLink({ role, expiresIn: expiresInDays === null ? null : expiresInDays * DAY_MS, label: \`AI · ${client}\`.slice(0, 60) })`;
              `l.token` rỗng → `SHARE_FAILED`. Kết quả `{ url: buildShareUrl(serverUrl, l.token), tokenPrefix: l.tokenPrefix, expiresAt: l.expiresAt }`.
              Lỗi enable/createLink (kể cả thông điệp 429 đã dịch) → `SHARE_FAILED` kèm message.
            - revoke_link: `bound()` false → `NOT_FOUND` 'document is not shared'. `await refresh()`; prefix không có trong `links()` (hoặc đã revokedAt)
              → `NOT_FOUND`. `confirm({ kind:'revoke', docTitle: title, tokenPrefix }, client)` false → `DENIED`. Đồng ý → `await revoke(prefix)` →
              `{ revoked: true }`; lỗi → `SHARE_FAILED`.
            - Hộp hết giờ: `confirm` reject với `Error('timeout')` → `TIMEOUT` 'no answer from user'.
            Test (sửa trước, đỏ; share và confirm giả): list chưa share → []; list có link → map đúng, không có token; share allow → enable+createLink
            đúng expiresIn (7 → 7*DAY_MS, null → null), url = buildShareUrl; share deny → DENIED, createLink không gọi; createLink ném → SHARE_FAILED;
            confirm reject timeout → TIMEOUT; revoke prefix lạ → NOT_FOUND, confirm không gọi; revoke allow → revoke(prefix) gọi; revoke deny → DENIED.
            Xoá test cũ 'share_doc → INTERNAL not implemented'. Các test cũ thêm `share: null, confirm: null`.
INVARIANTS  Chia sẻ chỉ đi qua luồng `useShare` có sẵn (máy chủ chỉ lưu hash token; token đầy đủ cache trong `chrome.storage.local` do useShare lo).
            `share_doc` và `revoke_link` LUÔN hỏi người dùng trước; `list_links` không bao giờ trả token đầy đủ.
            Executor không gọi `chrome.*` và không `fetch` trực tiếp.

### [x] 10n.4 — App page: nối share + hộp xác nhận 110 s
FILES       apps/extension/src/app/hooks/useAgentConfirm.ts · apps/extension/src/app/hooks/useAgentConfirm.test.tsx · apps/extension/src/app/App.tsx
INTERFACES  ```ts
            export const AGENT_CONFIRM_MS = 110_000
            export function useAgentConfirm(): {
              pending: { req: ConfirmRequest; client: string } | null
              confirm(c: ConfirmRequest, client: string): Promise<boolean>   // một hộp một lúc: đang có hộp → reject Error('busy')
              allow(): void; deny(): void
            }
            ```
            `confirm` mở hộp (set `pending`), resolve true/false theo allow/deny; sau `AGENT_CONFIRM_MS` không bấm → đóng hộp, reject `Error('timeout')`.
            Unmount khi đang chờ → reject `Error('timeout')`.
            App.tsx: dùng `useAgentConfirm()`; render `<ConfirmAgentDialog req client onAllow={allow} onDeny={deny} />` khi `pending`;
            `execSessionRef` thêm `share: { serverUrl: <server đang dùng>, enable: share.enable, createLink: share.createLink, revoke: share.revoke,
            refresh: share.refresh, links: () => <ref luôn trỏ share.links mới nhất>, bound: () => !!<ref binding mới nhất> }` và `confirm`;
            listener EXEC chuyển `m.client` (mặc định 'AI' nếu thiếu/không phải string) vào executor `(m.req, client)`.
            Executor `confirm` 'busy' → coi như `DENIED`? KHÔNG — để executor trả `INTERNAL` với message 'busy' (rơi vào nhánh lỗi chung).
            Test useAgentConfirm.test.tsx (viết trước, đỏ, fake timers): allow → true; deny → false; 110 s → reject timeout và pending null;
            confirm lần hai khi đang chờ → reject busy; unmount đang chờ → reject.
INVARIANTS  Chỉ `apps/extension` dùng `chrome.*`; listener EXEC giữ nguyên kiểm `sender.id === chrome.runtime.id && !sender.tab`.
            App.tsx chỉ thêm hook + render hộp + mở rộng ref/listener; không đổi ShareModal hay luồng chia sẻ tay; App.test.tsx xanh nguyên.
            Hộp xác nhận chỉ là UI, không tự đồng ý; hết giờ = không cho phép.
