### [x] 10h.1 — Khoá bản cài + header + thông báo 429
FILES       apps/extension/src/app/collab/tenancy.ts · apps/extension/src/app/collab/tenancy.test.ts · apps/extension/src/app/collab/useShare.ts · apps/extension/src/app/image-saver.ts · packages/ui/src/i18n/catalog/ext.ts
INTERFACES  Tiêu thụ: `INSTALL_HEADER` ('x-mdr-install'), `LimitErrorCode` từ `@md-reader/core`.
            ```ts
            // tenancy.ts
            export const INSTALL_KEY_STORAGE = 'mdr.installKey'
            export function newInstallKey(): string                      // 32 byte crypto.getRandomValues → base64url không padding (43 ký tự)
            export function getInstallKey(store?: { get(k: string): Promise<Record<string, unknown>>; set(v: Record<string, unknown>): Promise<void> }): Promise<string>
            //   mặc định store = chrome.storage.local; đọc khoá; không có/không phải string dài 16..200 → sinh, lưu, trả.
            //   Gọi đồng thời nhiều lần trong một trang → cùng một promise (cache module-level), không sinh hai khoá.
            export function limitMessage(t: TFunction, status: number, body: unknown, now?: number): string | null
            //   status !== 429 → null. body.error === 'QUOTA_EXCEEDED' → t('ext.limit.quota').
            //   Còn lại → t('ext.limit.rate', { hours: max(1, ceil(retryAfter/3600)) }) nếu body.retryAfter là số > 0, ngược lại t('ext.limit.rateSoon').
            ```
            useShare.ts: `enable` gửi `headers: { [INSTALL_HEADER]: await getInstallKey() }` khi POST tạo phòng; `call` đọc body khi 429 và
            ném `Error(limitMessage(...))` (giữ `status` trên error như nhánh lỗi hiện có).
            image-saver.ts: `uploadImage` thêm header `[INSTALL_HEADER]: await getInstallKey()`; 429 → ném `Error(limitMessage(...))`.
            Catalog ext.ts (vi / en): `ext.limit.rate` 'Đã đạt giới hạn hôm nay, thử lại sau khoảng {hours} giờ' /
            'Daily limit reached, try again in about {hours} h'; `ext.limit.rateSoon` 'Đã đạt giới hạn, thử lại sau' / 'Limit reached, try again later';
            `ext.limit.quota` 'Đã hết dung lượng chia sẻ của máy này. Xoá bớt tài liệu đã chia sẻ để giải phóng.' /
            'This device has used its sharing quota. Delete some shared documents to free space.'.
            Test tenancy.test.ts (viết trước): newInstallKey dài 43, chỉ [A-Za-z0-9_-], hai lần khác nhau; getInstallKey với store giả: lần đầu
            sinh + set, lần sau đọc lại cùng giá trị, giá trị hỏng bị thay; hai lời gọi song song chỉ set một lần; limitMessage cho 200/429 rate có
            retryAfter 7200 → "2 giờ"/429 không retryAfter/429 QUOTA_EXCEEDED.
            Test hiện có useShare.test.ts / image-saver.test.ts phải xanh; nếu chúng kiểm chính xác headers thì cập nhật kỳ vọng là lỗi plan → báo BLOCKED.
INVARIANTS  Chỉ `apps/extension` dùng `chrome.*`; `packages/ui` (catalog) KHÔNG `chrome.*`.
            Khoá bản cài chỉ gửi kèm request tạo phòng và upload ảnh tới máy chủ người dùng đã chọn — không gửi đi đâu khác, không log.
            Content script KHÔNG import tenancy.ts (ngân sách ≤ 60 KB gz).
            Thêm khoá i18n vào CẢ hai khối vi và en.
TEST        pnpm --filter extension test src/app/collab/tenancy.test.ts src/app/collab/useShare.test.ts src/app/image-saver.test.ts

### [x] 10h.2 — `deleteRemote` trong useShare
FILES       packages/core/src/share/share.ts · apps/extension/src/app/collab/link-cache.ts · apps/extension/src/app/collab/useShare.ts · apps/extension/src/app/collab/useShare.test.ts
INTERFACES  core: `API_PATHS` thêm `room: (roomId: string) => \`/api/rooms/${roomId}\`` (chỉ thêm, không đổi khoá cũ).
            link-cache.ts: `export async function forgetRoomTokens(room: string): Promise<void>` — xoá khoá cache của phòng trong chrome.storage.local
            (dùng cùng hàm `key(room)` đang có).
            useShare: thêm vào giá trị trả về `deleteRemote: () => Promise<void>`:
            `run(async (stale) => { b = need(); try { await call(t, \`${b.serverUrl}${API_PATHS.room(b.roomId)}\`, { method: 'DELETE', headers: auth(b) }) }
            catch (e) { if ((e as {status?:number}).status !== 404) throw e }; await forgetRoomTokens(b.roomId); await touchRecord(docId, { room: undefined });
            if (!stale()) { bindingRef.current = null; tokens/session clear; setBinding(null); setLinks([]) } })`.
            404 coi như đã xoá (phòng không còn). 401 → lỗi `ext.share.forbidden` như hiện tại, KHÔNG gỡ binding.
            Test (viết trước): fetch giả 204 → binding null, links rỗng, touchRecord nhận `{ room: undefined }`, forgetRoomTokens được gọi; 404 → như 204;
            401 → ném lỗi, binding giữ nguyên; request đúng method DELETE, URL `<server>/api/rooms/<id>`, header Authorization ownerToken.
