Hành vi:
- StateField `DecorationSet`: dựng từ `get().threads` lúc khởi tạo và khi transaction có effect `refreshComments`; khi `docChanged` mà không có effect → `decos.map(tr.changes)`. Thread được tô: `!deleted && !resolved && range && range.from < range.to`, kẹp vào `[0, doc.length]`. Mark `class: 'cm-comment'` (thêm `cm-comment-active` khi `id === activeId`), attribute `data-comment-id: id`. Sắp theo `from` trước khi `RangeSet` (dùng `Decoration.set(ranges, true)`).
- Tooltip: StateField `Tooltip | null` cấp qua `showTooltip.from(field)`: vùng chọn chính khác rỗng (`!main.empty`) và view không readOnly → tooltip `pos: main.head`, `above: true`, DOM một `<button class="cm-comment-add" type="button">` chữ `state.facet(translateFacet)('comments.add')`; `mousedown` → `preventDefault()` (giữ vùng chọn); `click` → `get().onCreate({ from: main.from, to: main.to })`. Vùng chọn rỗng → `null`.
- `EditorView.domEventHandlers({ click })`: target (hoặc tổ tiên trong `view.contentDOM`) có `data-comment-id` → `get().onSelect(id)`; không chặn hành vi mặc định.
- CSS (thêm vào `comments.css`): `.cm-comment { background-color: color-mix(in srgb, var(--hl) 35%, transparent); }` · `.cm-comment-active { background-color: color-mix(in srgb, var(--hl) 70%, transparent); }` · `.cm-comment-add` cùng kiểu `.comment-add-btn` hiện có (dùng chung selector `.comment-add-btn, .cm-comment-add`).
INVARIANTS
- `packages/ui` là React/CM6: không `chrome.*`. Import chéo package chỉ bằng `@md-reader/core`.
- CM bind thẳng `Y.Text "source"` qua yCollab: offset CM = offset `source`; không ghi Y.Doc ở đây (host gọi `addComment`).
- Cập nhật decoration bằng StateEffect, không dựng lại view. Không thêm dependency (`@codemirror/state`/`view` đã có).
