### [x] T1 — resolve trả thêm prefix + expiresAt
parallel-group: 11c-a
FILES       apps/api/src/tokens.ts · apps/api/src/tokens-d1.ts · apps/api/src/tokens.test.ts
INTERFACES  `export interface ResolvedToken { roomId: string; role: ShareRole; prefix?: string; expiresAt?: number | null }`
            `TokenStore.resolve(token): Promise<ResolvedToken | null>`. Link → `prefix` = `token_prefix` của link, `expiresAt` = `expires_at` (ms hoặc null).
            Owner token → không có `prefix`, `expiresAt: null`. Memory store làm y hệt. Trường optional để fake store cũ trong test khác vẫn typecheck.
INVARIANTS  - Token chỉ lưu SHA-256 + prefix; không lưu/trả token đầy đủ.
            - Link thu hồi hoặc hết hạn vẫn resolve → null như cũ.
            - Không đổi schema D1 (cột `token_prefix`, `expires_at` đã có trong `links`); nếu không có → BLOCKED.
TEST        pnpm --filter api test src/tokens.test.ts (thêm test đỏ trước: resolve link có hạn trả đúng prefix + expiresAt; owner → prefix undefined)
COMMIT      feat(api): resolve trả prefix và hạn của link (11c)
