# Plan: Phase 7 / 7g1 — alerts in the margin, tables, code, metadata
Author: haonq (coordinator: Claude Opus). Status: built. Phase: 7. Sub-phase: 7g1
Spec: docs/superpowers/specs/2026-10-24-phase-7-design.md
Branch: phase-7-7g1-reading-surfaces
BranchPoint: 1088e6b
Split at plan time: 7g1 = alerts/tables/code/metadata; 7g2 = in-document search bar + highlight.
Decision: the margin column uses `:has()` + a container query (Chromium-only extension, both supported), so no JS class
is needed and the sidenote layout turns on only when the SHEET is wide enough (ToC rail open or not).
Facts: alerts render as `div.markdown-alert.markdown-alert-{note|tip|important|warning|caution}` > `p.markdown-alert-title`
(svg.markdown-alert-icon + span) + content (core rehypeGithubAlerts). Metadata card = `div.markdown-metadata-card`.
The A4 sheet is `.a4-document-container` (a4.css, max-width calc(var(--measure) + 112px), padding 40px 56px 160px).
Code blocks get a header (language badge + copy button "Copy") built in Viewer.tsx. Two zebra rule sets exist
(table-enhanced.css and typography.css), patched with !important.
