- Packages boundary:

  - `apps/extension` handles browser APIs (`saveToHandle`, `openLocalFile`, `saveFileAs`, keyboard shortcuts).
- `TopToolbar.tsx`:
  - Displays unsaved dirty dot `•` in or next to document title / title bar when `isDirty === true`.
  - Has optional `onSave` callback (can be triggered by a save button or keyboard).
- `App.tsx`:
  - States:
    - `viewMode`: `ViewMode` ('reading' | 'editor' | 'split'), default `'reading'`.
    - `isDirty`: `boolean`, default `false`.
    - `activeHandle`: `FileSystemFileHandle | null`, default `null`.
    - `conflictState`: `{ isOpen: boolean; diskContent: string; localContent: string }`, default closed.
    - `undoManager`: `Y.UndoManager` for `yText`.
  - Observe `yText`:
    - Listen for `yText.observe(...)`: when text changes, set `isDirty(true)`.
    - Also update raw markdown state so `Viewer` re-renders with debounced AST.
  - Save pipeline (`handleSave`):
    - If `!activeHandle`: fallback to `handleSaveAs()`.
    - Before writing:
      - Read current file from handle via `file = await activeHandle.getFile(); const diskText = await file.text();`.
      - Check conflict: `const conflict = detectConflict(currentOriginHash, diskText);`.
      - If conflict exists and not force-overwriting: open `ConflictModal` with `localContent` and `diskContent`.
      - If no conflict (or user chooses `onKeepLocal`):
        - Option "Format on save" (default true): format markdown source via `formatMarkdown(source)` before saving.
        - Write to handle via `saveToHandle(activeHandle, formattedText)`.
        - Update doc originHash: `setDocMeta(doc, { originHash: await sha256(formattedText) })`.
        - Append history checkpoint: `appendHistory(doc, { source: formattedText, timestamp: Date.now() })`.
        - Set `isDirty(false)`.
  - ConflictModal integration:
    - `onKeepLocal`: perform force save to disk, close modal.
    - `onRevertToDisk`: replace `yText` with `diskContent`, update originHash, close modal, `isDirty(false)`.
    - `onClose`: close modal.
  - Auto-save:
    - Debounced by 2000ms after last `yText` change if `activeHandle !== null` and `isDirty === true`.
  - Keyboard Shortcuts:
    - `Cmd+S` / `Ctrl+S`: `e.preventDefault()`, call `handleSave()`.
  - View layout:
    - When `viewMode === 'reading'`: render Viewer (existing A4 layout).
    - When `viewMode === 'editor'`: render FormattingToolbar and Editor.
    - When `viewMode === 'split'`: render FormattingToolbar and `SplitViewContainer` with Editor and Viewer panes.
- Tests in `apps/extension/src/app/App.test.tsx`:
  - Test viewMode switching updates displayed layout (reading -> split -> editor).
  - Test editing text marks document as dirty (isDirty dot shows).
  - Test Cmd+S triggers save and clears dirty state.
  - Test conflict detection opens ConflictModal when disk text hash differs.
