INTERFACES  table-grid.ts (pure helpers + widget):
              export interface CellRef { row: number; col: number; from: number; to: number }  // doc offsets of the cell TEXT (trimmed, inside pipes)
              export function tableCells(state: EditorState, tableFrom: number, tableTo: number): CellRef[][]  // from Lezer Table/TableHeader/TableRow/TableCell; header = row 0; delimiter row skipped; empty cells get a zero-width range at the right spot
              export function escapeCell(text: string): string   // '|' → '\|', newlines → ' '
              export function cellChange(cell: CellRef, newText: string): { from: number; to: number; insert: string }  // padded with one space each side when the cell was empty
              export class TableGridWidget extends WidgetType — renders <table class="cm-live-grid"> with one contenteditable="plaintext-only"
                (fallback "true") <div> per cell; textContent = unescaped cell text; ignoreEvent() true for events inside cells (CM must
                not steal them); on 'input' → view.dispatch({ changes: cellChange(currentRef, text), userEvent: 'input.table',
                annotations: [tableEdit.of(true)] }) — recompute the ref from the CURRENT state (positions shift) via tableCells using the
                widget's tableFrom mapped through the transaction; eq() compares source text + structure so typing in a cell does NOT
                re-create the DOM (focus/caret stay); if a remote change alters the table, the widget updates cell texts in place except
                the focused cell.
              Keys inside a cell: Tab / Shift+Tab next/prev cell (wrap rows); Enter → cell below (on last row: no-op in 9g1); ↑/↓ cell
                above/below; Escape → blur and put the CM cursor after the table. Prevent default for handled keys.
            block-widgets.ts: Table blocks always use TableGridWidget (not only when the cursor is outside); math/mermaid unchanged.
            theme.ts: .cm-live-grid same look as reading tables (typography.css tokens), cell focus ring var(--accent), min cell width 3ch.
INVARIANTS  - Y.Text is the only state; every keystroke = one minimal change inside one cell (never rewrite the whole table).
