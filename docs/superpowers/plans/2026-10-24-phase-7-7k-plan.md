INTERFACES  export function fitScale(stageW: number, stageH: number, slideW = 1280, slideH = 720): number
              = Math.min(stageW / slideW, stageH / slideH) (exported from Deck.tsx for tests; > 0 guard → 1 when stage is 0).
            Deck: slides render in a logical 1280×720 box (`.deck-slide-frame`, width 1280px, height 720px, transform-origin
              top left / centred via a wrapper) scaled with `transform: scale(fitScale(stage))` from a ResizeObserver on the stage
              (jsdom: no RO → scale 1). Stage background var(--ink) (letterbox), slide default background var(--paper), text
              var(--ink), headings var(--font-body) 600, body var(--font-body) 32px/1.45 in the logical box, code var(--font-code);
              custom presentation settings still override (keep the existing var/inline mechanism, colours only from settings).
              Controls bar: autohide after 2s of no pointer movement (shows on move/focus), var(--font-ui), Icon buttons as in 7d;
              progress line 3px var(--accent) at the bottom; counter "Trang N / M" in var(--font-ui) tabular-nums.
              Keyboard unchanged (←/→/Space/PageUp/PageDown/Home/End/Esc).
            SpeakerView: layout = current slide (scaled with fitScale into its pane) | next slide preview + notes; clock 44px and
              elapsed 32px in var(--font-ui) tabular-nums; notes var(--font-body) 22px/1.5, colour var(--ink) on var(--paper);
              labels sentence case ("Trang hiện tại", "Trang tiếp theo", "Ghi chú", "Đã trình bày") — no uppercase, no letter-spacing;
              tokens only (speaker-view.css no hex/rgb literals). Behaviour/sync unchanged.
INVARIANTS  - Slide splitting, notes, BroadcastChannel sync and print path unchanged.
            - packages/ui: tokens only (except user-chosen presentation colours); no chrome.*; no emoji.
TEST        Deck.test: fitScale(1920,1080)=1.5, fitScale(800,800)=0.625, fitScale(0,0)=1; the slide frame has width 1280px and a
            scale transform after a mocked ResizeObserver callback; controls hide after 2s (fake timers) and reappear on mousemove;
            existing navigation tests green. SpeakerView: label texts are sentence case (no element textContent fully uppercase
            among labels) — add to the existing SpeakerView.test if needed (allowed; list it). Then `pnpm --filter ui test`,
            `pnpm --filter extension test`, `pnpm -r typecheck`, `pnpm --filter extension build`; report.
COMMIT      feat(ui): slides scale to the screen; speaker view readable from the lectern
