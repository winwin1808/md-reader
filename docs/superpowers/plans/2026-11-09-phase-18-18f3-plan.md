INTERFACES  `export const REVIEW_MIN_OPENS = 10`; `export const REVIEW_MIN_AGE_MS = 7 * 86_400_000`.

            `export function setReview(s: LifecycleState, v: 'dismissed' | 'accepted'): LifecycleState` — object mới với `review = v`.

### [x] 18f3.3 — `useReviewPrompt` và nối vào app page
FILES       apps/extension/src/app/hooks/useReviewPrompt.ts · apps/extension/src/app/hooks/useReviewPrompt.test.ts · apps/extension/src/app/App.tsx
INTERFACES  `export const REVIEW_URL = 'https://chromewebstore.google.com/detail/eolclccibhickmpbpbdodbhopnddcdog/reviews'`
            `export function useReviewPrompt(docId: string | null): { show: boolean; onRate(): void; onDismiss(): void }`:
            - Khi `docId` đổi sang giá trị khác null và khác lần trước trong vòng đời hook: đọc-sửa-ghi `chrome.storage.local[LIFECYCLE_KEY]` bằng `bumpDocOpens` (lỗi → `console.warn`).
            - `show` = `!isFirefox && shouldAskReview(state, Date.now())`, với `state` đọc từ storage (sau mỗi lần ghi và qua `chrome.storage.onChanged` area `local` key `LIFECYCLE_KEY`); `isFirefox` = `/Firefox\//.test(navigator.userAgent)`. Lỗi đọc → `show: false`.
            - `onRate`: `chrome.tabs?.create?.({ url: REVIEW_URL })` rồi ghi `setReview(s, 'accepted')`; `onDismiss`: ghi `setReview(s, 'dismissed')`. Cả hai ẩn dải ngay (state cục bộ) dù ghi lỗi.
            - Gỡ listener khi unmount.
            Tiêu thụ từ `../../worker/lifecycle`: `LIFECYCLE_KEY`, `parseLifecycleState`, `shouldAskReview`, `bumpDocOpens`, `setReview`.
            `App.tsx`: `const review = useReviewPrompt(session.docId)`; render `{review.show && <ReviewPrompt onRate={review.onRate} onDismiss={review.onDismiss} />}` ở cuối khung app page (không trong chế độ trình chiếu/speaker).
INVARIANTS  `apps/extension` là lớp duy nhất dùng `chrome.*`; gọi qua optional chaining.
            Bộ đếm không rời máy; không gửi gì lên mạng.
            Ẩn ở Firefox. Chỉ hỏi khi `review === 'idle'`, ≥ 10 lần mở, ≥ 7 ngày; đã chọn thì không hỏi lại.
TEST        pnpm --filter extension test src/app/hooks/useReviewPrompt.test.ts
            Sau đó `pnpm --filter extension typecheck` exit 0 và `pnpm --filter extension test` xanh toàn bộ.
            Test (viết trước, ghi lượt đỏ; `renderHook` với `chrome` giả): đổi `docId` 'a' → 'b' ghi storage `docOpens` +1 mỗi lần, render lại cùng 'b' không tăng, `null` không tăng; state 10 lần + 8 ngày + idle → `show` true (waitFor); UA Firefox → false; `onRate` gọi `tabs.create` với `REVIEW_URL`, ghi `review: 'accepted'`, `show` false; `onDismiss` ghi `'dismissed'`, `show` false; storage reject → `show` false, không ném; unmount gỡ listener.
