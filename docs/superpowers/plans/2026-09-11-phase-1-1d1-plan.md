## Phase con này làm gì

Xây dựng tầng document model cốt lõi trên nền Yjs cho `@md-reader/core`:
1. Schema Y.Doc với 3 key chuẩn hoá cố định: `source` (`Y.Text`), `meta` (`Y.Map`), `history` (`Y.Array`).
2. Định nghĩa cấu trúc `DocMeta`, `HistoryEntry`, hằng số `FORMAT_VERSION = 1`, `DOC_KEYS`, và ngoại lệ `UnsupportedFormatVersionError`.
3. `createDoc(init)`: khởi tạo Y.Doc kèm giá trị mặc định cho `meta` và nạp `source` ban đầu nếu có.
4. `getSource`, `getMeta`, `getHistory`: các accessor truy xuất trực tiếp các cấu trúc CRDT.
5. `readMeta(doc)`: đọc metadata ra plain object TypeScript, tự động điền default khi thiếu field (không throw trên doc lạ/doc cũ).
6. `hashText(text)`: tính chuỗi SHA-256 hex bất đồng bộ qua `globalThis.crypto.subtle` (chạy đồng nhất trên Node 18+ và Browser).
7. `importText(doc, text, opts)`: thay thế toàn bộ nội dung `Y.Text` bằng delete + insert trong **MỘT** transaction duy nhất, cập nhật `originPath` và `originHash`.
8. `exportText(doc)`: trích xuất chuỗi nội dung Markdown nguyên vẹn từ `Y.Text`.
9. `migrateDoc(doc)`: hook kiểm tra phiên bản định dạng tài liệu, no-op với v1, throw `UnsupportedFormatVersionError` nếu `formatVersion > FORMAT_VERSION`.

            Chi tiết thực thi importText, exportText, migrateDoc:
              - importText:
                doc.transact(() => {
                  const source = getSource(doc)
                  if (source.length > 0) {
                    source.delete(0, source.length)
                  }
                  source.insert(0, text)
                  const meta = getMeta(doc)
                  if (opts.originPath !== undefined) {
                    meta.set('originPath', opts.originPath)
                  }
                  meta.set('originHash', opts.originHash)
                })
              - exportText:
                return getSource(doc).toString()
              - migrateDoc:
                const meta = getMeta(doc)
                const currentVersion = (typeof meta.get('formatVersion') === 'number'
                  ? meta.get('formatVersion')
                  : FORMAT_VERSION) as number
                if (currentVersion > FORMAT_VERSION) {
                  throw new UnsupportedFormatVersionError(currentVersion, FORMAT_VERSION)
                }
                return { from: currentVersion, to: FORMAT_VERSION }

            Test cases bắt buộc theo spec (packages/core/src/doc/doc.test.ts):
              1. createDoc: sinh đúng 3 key ('source', 'meta', 'history') và formatVersion === 1.
