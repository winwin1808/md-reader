### [x] T1 — IP luôn bị tính + IPv6 /64
FILES       apps/api/src/limits.ts · apps/api/src/limits.test.ts
INTERFACES  - `export function ipSubject(ip: string): string` — IPv4 giữ nguyên; IPv6 (có `:`) → mở rộng `::`, chữ thường, lấy 4 nhóm đầu nối `:` + `::/64`
              (vd `2001:db8:1:2:aaaa::1` → `2001:db8:1:2::/64`); IPv4-mapped `::ffff:a.b.c.d` → `a.b.c.d`; chuỗi rỗng/không parse được → `'unknown'`.
              `subjectFrom` hash `ipSubject(CF-Connecting-IP)`.
            - `decide('asset')`: LUÔN kiểm `ip` asset count + asset_bytes (trước), rồi nếu phòng có install owner thì kiểm thêm các ngưỡng install như cũ.
            - `record('asset')` (Memory + D1): LUÔN cộng `ip` asset + asset_bytes; có install owner thì cộng thêm nhánh install như cũ.
            - Ngưỡng `LIMITS` giữ nguyên.
INVARIANTS  - Không đổi schema D1 (bảng usage/room_installs hiện có); không thêm dependency.
            - Không lưu IP thô — chỉ hash (qua `hashToken`) của chuỗi đã chuẩn hoá.
            - Mã lỗi giữ nguyên: vượt ngưỡng theo ngày → rate (429 + retry-after); vượt dung lượng install → QUOTA_EXCEEDED.
