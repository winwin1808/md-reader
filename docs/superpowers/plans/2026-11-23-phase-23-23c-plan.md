### [ ] 23c-2 — extension: hook `useComments`
parallel-group: c-a
FILES       apps/extension/src/app/hooks/useComments.ts, apps/extension/src/app/hooks/useComments.test.ts
INTERFACES  (produce)
```ts
import type { CommentThread } from '@md-reader/core'
import type { CommentsPanelProps } from '@md-reader/ui'
export function useComments(doc: Y.Doc | null, actor: string): {
  threads: CommentThread[]; openCount: number
  activeId: string | null; setActive(id: string | null): void
  create(range: { from: number; to: number }, body: string): string | null
  reply(threadId: string, body: string): void
  resolve(threadId: string, resolved: boolean): void
  remove(id: string): void
  me: CommentsPanelProps['me']
}
```
(Bỏ tham số `opts.shared` của spec — không có hành vi nào phụ thuộc nó.)
Hành vi:
- `threads` = `listThreads(doc)`; tính lại khi `getComments(doc)` đổi (`observeDeep`) hoặc `doc.getText('source')` đổi (`observe`), debounce 120 ms (timer huỷ khi unmount/đổi doc); lần đầu tính ngay (không chờ debounce). `doc` null → `threads: []`.
- `threads` giữ cùng tham chiếu mảng khi không có gì đổi (memo) để host truyền thẳng vào `Editor` mà không dispatch thừa.
- `openCount` = số thread `!deleted && !resolved`.
- `create`: `addComment(doc, { author: actor, body, from, to })`, trả id, `setActive(id)`; ném `RangeError` → trả `null` (không ném lên UI). `reply`/`resolve`/`remove`: gọi `replyComment(doc, id, { author: actor, body })` / `setResolved(doc, id, resolved, actor)` / `deleteComment(doc, id)`, nuốt `RangeError`. Sau mỗi thao tác cập nhật `threads` ngay (không chờ debounce).
- `me`: `clientIds` = `doc.clientID` cộng mọi khoá số của `meta.actors` có giá trị `=== actor` (không trùng); `canModerate: true`, `canResolveAll: true`.
- Đổi `doc` → `activeId` về `null`.
INVARIANTS
- `apps/extension` là lớp duy nhất dùng `chrome.*` (hook này không cần `chrome.*`); import chéo chỉ `@md-reader/core`/`@md-reader/ui`.
- Y.Doc là nguồn sự thật: bình luận ghi qua API `@md-reader/core` vào root `comments`, không giữ bản sao riêng.
- Debounce 120 ms như re-parse. Không thêm dependency.
TEST        pnpm --filter extension test src/app/hooks/useComments.test.ts && pnpm --filter extension typecheck
Test (`renderHook` + `Y.Doc` thật, fake timers cho debounce) chứng minh: create → `threads` có thread, `activeId` = id, `openCount` 1; reply → reply xuất hiện; resolve(true) → `openCount` 0; remove → thread `deleted`; create với range sai → `null`, không ném; doc khác (remote) thêm bình luận qua `applyUpdate` → sau 120 ms `threads` cập nhật; rerender không đổi gì → `threads` cùng tham chiếu; `meta.actors` có clientID khác cùng tên actor → `me.clientIds` chứa cả hai; đổi `doc` → `activeId` null. Viết test đỏ trước.
COMMIT      feat(extension): hook useComments

### [ ] 23c-3 — extension: gắn bình luận vào App
FILES       apps/extension/src/app/App.tsx, apps/extension/src/app/app.css, apps/extension/src/app/hooks/useShortcuts.ts, apps/extension/src/app/App.test.tsx
INTERFACES  (consume) `useComments(doc, actor)` (23c-2); `CommentsPanel`, `CommentLayer`, `Editor` prop `comments` từ `@md-reader/ui`; `IconName 'comment'` (23c-1). (produce) `useShortcuts` map thêm `onToggleComments(): void`.
Hành vi:
- `const comments = useComments(doc, displayName)`; state `commentsOpen`. Mở bình luận đóng lịch sử (`closeHistory()`), mở lịch sử đóng bình luận.
- `toolbarActions` thêm (sau `history`) `{ id: 'comments', label: openCount > 0 ? \`${t('comments.title')} (${openCount})\` : t('comments.title'), icon: 'comment', badge: openCount > 0, onSelect: toggle }`.
- `useShortcuts`: Cmd/Ctrl+Shift+M (`e.shiftKey && (key 'm'|'M')`) → `onToggleComments`, `preventDefault`; bỏ qua khi đang gõ trong input/textarea/contentEditable như các phím khác; Cmd/Ctrl+M (mindmap) chỉ khi `!e.shiftKey`.
- `renderHtmlFor` truyền `sourcePositions: true` cho bản render chính (`html`); preview lịch sử không cần.
- Chế độ Đọc: trong `.a4-document-container` (thêm `position: relative` qua class CSS `.a4-document-container { position: relative }` nếu chưa có) render `<CommentLayer container={docContainerRef.current} source={content} threads={comments.threads} activeId={comments.activeId} enabled={previewHtml === null} onCreate={(r, body) => comments.create(r, body)} onSelect={openThread} askName={false} />`. Cần re-render khi ref gắn: dùng state `docContainerEl` qua callback ref nếu `docContainerRef.current` là null lúc render đầu.
- Chế độ Sửa: `Editor` nhận `comments={{ threads, activeId, onCreate: (r) => setPendingRange(r), onSelect: openThread }}` (memo bằng `useMemo` theo `threads`/`activeId`). `pendingRange` khác null → hiện `CommentComposer` (`askName={false}`) cố định góc trên phải vùng editor (class `.editor-comment-composer`); gửi → `comments.create(pendingRange, body)` rồi `setPendingRange(null)`; huỷ → null. Khi `previewHtml !== null` không truyền `comments`.
- Drawer: `commentsOpen` → `<div className="comments-drawer"><CommentsPanel threads activeId me onSelect={openThread} onReply onResolve onDelete={comments.remove} onClose /></div>`, CSS dùng chung khuôn `.history-drawer` (vị trí/kích thước).
- `openThread(id)`: `setActive(id)`; mở drawer; chế độ Đọc → `docContainerRef.current?.querySelector('[data-sp]')`… cuộn tới khối chứa `range.from`: chọn phần tử `[data-sp]` cuối cùng có `start <= from` (parse `data-sp="start-end"` hoặc định dạng hiện có) và `scrollIntoView({ block: 'center' })`; chế độ Sửa → `editorViewRef.current?.dispatch({ selection: { anchor: from }, scrollIntoView: true })`. Thread mồ côi (`range` null) chỉ chọn.
INVARIANTS
- `apps/extension` là lớp duy nhất dùng `chrome.*`; import chéo chỉ `@md-reader/core`/`@md-reader/ui`.
- Content script KHÔNG dùng Yjs, ngân sách ≤ 60 KB gz: không import gì mới vào `src/content*`; bình luận chỉ ở app page.
- Re-parse toàn bộ với debounce 120 ms giữ nguyên; `sourcePositions` chỉ thêm attribute.
- Không thêm dependency, không thêm state-manager toàn cục.
TEST        pnpm --filter extension test src/app/App.test.tsx && pnpm --filter extension typecheck
Test tích hợp (theo cách `App.test.tsx` hiện dựng App với doc thật) chứng minh: menu có mục "Bình luận"; bấm → drawer `CommentsPanel` hiện, lịch sử đóng (và ngược lại); thêm bình luận vào doc bằng `addComment` → nhãn menu thành "Bình luận (1)"; HTML chế độ Đọc có `data-sp`; Ctrl+Shift+M mở/đóng drawer, Ctrl+M vẫn mở mindmap; trả lời trong panel → reply ghi vào doc (`listThreads`). Viết test đỏ trước.
COMMIT      feat(extension): bình luận trong app — panel, lớp đọc, editor
