            export interface TourStep { id: string; target: string[] | null; title: string; body: string }
            export interface GuidedTourProps { steps: TourStep[]; open: boolean; onClose(result: 'done' | 'skipped'): void }
            export function GuidedTour(props: GuidedTourProps): React.JSX.Element | null
            ```
            Export có tên từ `packages/ui/src/index.ts` (`export { GuidedTour } from './components/GuidedTour'` và `export type { TourStep, GuidedTourProps } from './components/GuidedTour'`).
            Khi `open && steps.length > 0`, `createPortal(…, document.body)` render đúng các phần tử/class sau (class là hợp đồng với CSS sub-phase khác — KHÔNG viết CSS, chỉ style inline cho vị trí):
            - `<div className="tour-layer" aria-hidden="true">` (chặn click; click vào nó không làm gì).
            - `<div className="tour-spotlight" data-centered={'true'|'false'} aria-hidden="true" style={{ top, left, width, height }}>` — rect đích nới 6 px mỗi phía; không có đích → `data-centered="true"`, `width/height: 0`, `top: innerHeight/2`, `left: innerWidth/2`.
            - `<div className="tour-pop" role="dialog" aria-modal="true" aria-labelledby={titleId} aria-describedby={bodyId} data-placement={'below'|'above'|'center'} style={{ top, left }}>` chứa theo thứ tự: `<p className="tour-progress" aria-label={t('tour.progressLabel', {current,total})}>{t('tour.progress', {current,total})}</p>`, `<h2 id={titleId} className="tour-title">`, `<p id={bodyId} className="tour-body">`, `<div className="tour-actions">` với `<button type="button" className="tour-skip">` (`tour.skip`), `<button className="tour-prev">` (`tour.prev`, không render ở bước đầu), `<button className="tour-next">` (`tour.next`, bước cuối là `tour.done`).
            Đích: lần lượt `document.querySelector(sel)` theo `target`; lấy phần tử đầu tiên có `getBoundingClientRect()` width > 0 và height > 0. Không có → center.
            Vị trí popover: đo kích thước popover thật (ref, sau render — `useLayoutEffect`); `below` nếu `rect.bottom + 12 + popH <= innerHeight - 16`, không thì `above` (`top = rect.top - 12 - popH`, kẹp ≥ 16); `left = clamp(rect.left + rect.width/2 - popW/2, 16, innerWidth - 16 - popW)`; center → giữa màn hình.
            Hành vi: mở → focus `tour-next`; Tab/Shift+Tab xoay vòng trong popover; keydown trên document: `Escape` → `onClose('skipped')`, `ArrowRight` → tiếp (bước cuối → `onClose('done')`), `ArrowLeft` → trước (bước đầu: không làm gì); bấm Bỏ qua → `onClose('skipped')`; Tiếp ở bước cuối → `onClose('done')`. Đổi bước: nếu đích nằm ngoài khung nhìn → `el.scrollIntoView?.({ block: 'center' })`. `resize` và `scroll` (capture) → tính lại qua `requestAnimationFrame`; gỡ listener khi đóng/unmount. Mỗi lần `open` chuyển false→true bắt đầu lại từ bước 0. Khi đóng, trả focus về `document.activeElement` lúc mở (nếu còn trong DOM).
            Catalog `shell.ts`, vi và en (cú pháp nội suy giống khoá sẵn có có `{…}`): `tour.skip` ("Bỏ qua"/"Skip"), `tour.prev` ("Trước"/"Back"), `tour.next` ("Tiếp"/"Next"), `tour.done` ("Xong"/"Done"), `tour.progress` ("{current}/{total}"), `tour.progressLabel` ("Bước {current} trên {total}"/"Step {current} of {total}").
