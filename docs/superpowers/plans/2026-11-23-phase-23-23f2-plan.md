### [ ] 23f2-2 — executor: `list_comments` / `reply_comment` / `resolve_comment`
FILES       apps/extension/src/app/bridge-executor.ts, apps/extension/src/app/bridge-executor.test.ts
INTERFACES  (consume) `commentAsActor`, `listThreads`, `replyComment`, `setResolved` từ `@md-reader/core`; kiểu kết quả từ `@md-reader/core/bridge`.
Hành vi:
- `ready` cho ba tool: chỉ cần `synced` (như `get_doc`). Không hỏi xác nhận, kể cả tài liệu đang chia sẻ (quyết định người dùng).
- Tách helper `actorFor(client)` + đọc/ghi khoá `mdr-mcp-actor:${docId}:${actor}` dùng chung với `update_doc` (không đổi hành vi `update_doc`).
- `list_comments`: `listThreads(doc)` bỏ thread `deleted`; `status: 'open'` → chỉ `!resolved`. Map: `threadId=id`, `quote`, `currentText = range ? source.slice(range.from, range.to) : null`,
  `line = range ? source.slice(0, range.from).split('\n').length : null`, `status = resolved ? 'resolved' : 'open'`, `author`, `ts = new Date(ts).toISOString()`, `body`,
  `replies = replies.map(r => ({ author, ts: ISO, body }))`. Thứ tự giữ như `listThreads`.
- `reply_comment`: `commentAsActor(doc, actor, d => replyComment(d, threadId, { author: actor, body }), ORIGIN_MCP, { reuseClientId })` → `{ ok: true, id }`.
- `resolve_comment`: trong MỘT `commentAsActor`: nếu có `reply` → `replyComment` trước, rồi `setResolved(d, threadId, true, actor)` → `{ ok: true }`.
- Sau ghi: lưu clientID mới vào khoá như `update_doc`; chờ `Promise.race([s.persisted?.() ?? Promise.resolve(), sleep(2000)])`.
- Lỗi: `RangeError` message `comment_thread` → `fail(id, 'NOT_FOUND', 'comment_thread')`; `RangeError` khác (body) → `INVALID_ARGS` với message lỗi; doc không có `Y.Doc` → `INTERNAL`.
INVARIANTS
- `apps/extension` là lớp duy nhất dùng `chrome.*`; import chéo package chỉ bằng `@md-reader/core`.
- Bình luận AI ghi dưới clientID của tác giả AI (tên client MCP đã ghép, ≤40 ký tự) với origin `ORIGIN_MCP`; không ghi đĩa.
- AI resolve không cần xác nhận riêng. Chờ ghi IDB trước khi trả kết quả như `update_doc`.
- Không đổi giao thức bridge, không thêm dependency.
