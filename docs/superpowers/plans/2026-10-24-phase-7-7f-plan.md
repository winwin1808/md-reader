INTERFACES  Viewer: when `onActiveHeadingChange` is given, an IntersectionObserver (root = the nearest scrolling ancestor of the
              viewer, found by walking up for overflow-y auto|scroll, else null/viewport; rootMargin '0px 0px -70% 0px';
              threshold 0) watches h1–h3 inside the rendered HTML; re-observe when `html` changes; the active id is the last
              heading whose top is above the 30% line (track a Set of intersecting + fall back to the last heading above);
              call the callback only when the id changes. Disconnect on unmount. Guard missing IntersectionObserver (jsdom) → no-op.
            Toc: `aria-current="location"` (not "true") on the active link; scrolls the active link into view inside the ToC
              (block 'nearest') when it changes; heading "Mục lục" is a visually-hidden h2 (class `sr-only`), no visible eyebrow.
              New optional prop `onNavigate?(id: string): void` called after a link click (the drawer uses it to close).
            App.tsx: hold `activeHeadingId` state; pass Viewer onActiveHeadingChange → setActiveHeadingId and Toc activeId.
              ≤ 1080px (matchMedia live): the ToC is a left drawer driven by the existing tocOpen state: `role="dialog"`,
              aria-modal="true", aria-label "Mục lục", backdrop (click closes), Esc closes, focus moves into the drawer on open
              (first link or the active one) and back to the ToC toggle on close; choosing an item closes it (onNavigate).
              > 1080px: the rail behaves as today (tocOpen shows/hides it).
            app.css (tokens only): rail `.md-toc` font var(--font-ui) 14px/1.45, colour var(--pencil); links colour inherit, no underline,
              padding 3px 8px, radius 0; hover colour var(--ink); active `[aria-current="location"]`: colour var(--hl-ink),
              background linear-gradient(transparent 18%, var(--hl) 18%, var(--hl) 86%, transparent 86%); nesting indent 12px per
              level with a 1px var(--rule) guide line. `.md-toc-title` rules removed (no uppercase, no letter-spacing). Drawer:
              fixed left 0 top 48px bottom 0, width min(320px, 86vw), background var(--paper), border-right 1px var(--rule),
              shadow var(--elev-2), padding 16px; backdrop color-mix(in srgb, var(--ink) 30%, transparent); slide-in transform
              transition var(--dur-2) var(--ease) (reduced-motion handled globally). `.sr-only` utility if not present.
