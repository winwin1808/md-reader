Goal: a pure `ShareModal` component in `@md-reader/ui` (unshared and shared states, create view link,
copy, revoke), plus an optional "Chia sẻ" button on `TopToolbar`. No fetch and no chrome.* here:
all I/O comes in through callbacks. Wiring into the extension is 8b4.

Decision recorded here: `ShareLink.token` is '' in server lists. It is only filled in the create
response. So a row shows the copy button only when `token !== ''`. Other rows show the prefix with
the note "Chỉ sao chép được ngay khi tạo".

### [x] 8b3.1 — ShareModal component
FILES       packages/ui/src/components/ShareModal.tsx (new) · packages/ui/src/components/ShareModal.test.tsx (new) · packages/ui/src/index.ts
INTERFACES  consumes from `@md-reader/core` (already a dependency of ui): `ShareLink { token; tokenPrefix; roomId; role: 'view'|'edit'; label; createdAt; expiresAt: number|null; revokedAt: number|null }`, `RoomBinding { serverUrl; roomId; ownerToken }`, `CreateLinkRequest { role; label?; expiresIn: number|null }`, `SHARE_EXPIRY_PRESETS` (`'30d'` = 30 days in ms).
            produces and exports from packages/ui/src/index.ts:
            export interface ShareModalProps {
              open: boolean; onClose(): void
              binding: RoomBinding | null; links: ShareLink[]
              onEnable(): Promise<void>
              onCreateLink(req: CreateLinkRequest): Promise<ShareLink>
              onRevoke(prefix: string): Promise<void>
              buildUrl(token: string): string
              busy?: boolean; error?: string | null
            }
            export function ShareModal(props: ShareModalProps): JSX.Element | null
BEHAVIOR    open=false → render null. role="dialog", aria-modal, aria-labelledby on the title "Chia sẻ"; Esc and the close button call onClose.
            binding=null → text "Tài liệu sẽ được tải lên máy chủ đồng bộ. Chỉ người có link mới xem được." and button "Bật chia sẻ" → onEnable().
            binding set → button "Tạo link xem" → onCreateLink({ role: 'view', expiresIn: SHARE_EXPIRY_PRESETS['30d'] }). Show links where revokedAt === null. Each row: label (or "Link xem"), tokenPrefix + "…", expiry date or "Không hết hạn". If token !== '': a readonly input showing buildUrl(token) and button "Sao chép" → navigator.clipboard.writeText(buildUrl(token)), then the button text becomes "Đã sao chép". If token === '': text "Chỉ sao chép được ngay khi tạo". Button "Thu hồi" → onRevoke(tokenPrefix).
            Empty list → "Chưa có link nào." busy → all action buttons disabled. error → role="alert" with the message.
            Clipboard rejection → show "Không sao chép được" (no throw).
            Style follows existing modals (ExportModal/ConflictModal): reuse their overlay/class conventions and CSS vars; no new global CSS file.
INVARIANTS  - packages/ui is React and must NOT use chrome.* or fetch; all I/O goes through props callbacks.
            - Cross-package imports by workspace name only (`@md-reader/core`), never relative paths into packages/core.
            - Colors only from Lề sách CSS vars (--paper --surface --ink --pencil --rule --accent); no hex literals.
            - UI copy is Vietnamese.
            - Raw tokens are never logged (no console.* with a token or URL).
TEST        pnpm --filter ui test src/components/ShareModal.test.tsx — cover: closed renders nothing; unshared text + Bật chia sẻ calls onEnable; shared Tạo link xem calls onCreateLink with role 'view' and the 30d expiresIn; copy writes buildUrl(token) to a stubbed navigator.clipboard and shows "Đã sao chép"; row with token '' shows the note and no copy button; revoked links hidden; Thu hồi calls onRevoke(prefix); busy disables buttons; error renders role=alert; Esc calls onClose. Then pnpm --filter ui typecheck.
COMMIT      feat(ui): ShareModal — bật chia sẻ, tạo link xem, sao chép, thu hồi (8b3)
