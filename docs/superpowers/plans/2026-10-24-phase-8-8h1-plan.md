# Plan: Phase 8 — 8h1 core: render plugins and yaml injected by the caller
Author: Hao Nguyen. Status: built. Phase: 8. Sub-phase: 8h1
Spec: docs/superpowers/specs/2026-10-24-phase-8-design.md
Branch: phase-8-8h1-core-plugins
BranchPoint: 3a0b75d

Goal: `@md-reader/core`'s main entry no longer statically imports rehype-raw, rehype-highlight, rehype-katex, katex or yaml. This verdict comes from the 7n spike: content.js would reach 152.9 KB gz. The callers inject these libraries through a new subpath, `@md-reader/core/plugins`. This unblocks 8h2, which reads markdown in place inside the content script.

Order: every step keeps the suites green.
1. Add the injection points, with the static modules as a TEMPORARY fallback.
2. Add the plugins entry.
3. Switch the callers.
4. Remove the render fallbacks and update the tests.
5. Remove the yaml fallback and update the tests.
