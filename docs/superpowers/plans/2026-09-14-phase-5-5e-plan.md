INVARIANTS
- Packages boundary: `packages/ui` is pure React & CSS (NO `chrome.*`), pure presentation.
- Layout modes in `SplitViewContainer`:
  - `mode === 'reading'`: Only `preview` pane is rendered/visible. `editor` is not displayed.
  - `mode === 'editor'`: Only `editor` pane is rendered/visible. `preview` is not displayed.
  - `mode === 'split'`: Both `editor` and `preview` panes are rendered side-by-side in 50:50 ratio.
- 2-Way Synchronized Scroll:
  - Uses `useRef` for `editorPaneRef` and `previewPaneRef`.
  - On scroll event in either pane:
    - Check if the pane has mouse hover (`pane.matches(':hover')`) or use an active scrolling source guard (`isScrollingRef`).
    - Calculate scroll progress ratio: `ratio = scrollTop / Math.max(1, scrollHeight - clientHeight)`.
    - If scrolled pane is active/hovered, sync opposite pane's `scrollTop = ratio * (targetScrollHeight - targetClientHeight)` using `requestAnimationFrame`.
    - Call optional `onSyncScroll?.(source, ratio)`.
    - Avoid circular infinite scroll feedback loops by skipping sync if the opposite pane is currently triggering the scroll.
