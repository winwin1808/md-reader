            `export interface LifecycleState { v: 1; startedAt: number | null; lastSeenVersion: string | null; pendingWhatsNew: string | null; pendingWelcome: boolean; autoOpenWhatsNew: boolean; docOpens: number; review: 'idle' | 'dismissed' | 'accepted' }`
            `export type LifecycleEvent = { type: 'installed'; reason: string; previousVersion?: string } | { type: 'startup' }`
            `export type TabToOpen = 'welcome' | 'whatsnew'`
            `export function parseLifecycleState(raw: unknown): LifecycleState` — mặc định `{ v:1, startedAt:null, lastSeenVersion:null, pendingWhatsNew:null, pendingWelcome:false, autoOpenWhatsNew:true, docOpens:0, review:'idle' }`; trường sai kiểu thay bằng mặc định từng trường; không phải object → mặc định.
            `export function compareVersions(a: string, b: string): number` — so từng phần số `x.y.z`, thiếu phần coi là 0; trả âm/0/dương.
            `export function pendingNote(notes, seen: string | null, current: string): ReleaseNote | null` — mục mới nhất (theo `compareVersions`, không theo thứ tự mảng) có `showOnUpdate`, `> seen` (seen null → mọi bản), `<= current`.
            `export function decideLifecycle(ev, s, notes, current, now): { next: LifecycleState; open: TabToOpen[] }`:
            - `installed` + `reason 'install'`: `startedAt = now`, `lastSeenVersion = current`, `pendingWelcome = true`, `open = ['welcome']`.
            - `installed` + `reason 'update'`: nếu `s.lastSeenVersion === null` thì `lastSeenVersion = previousVersion ?? null` và `startedAt = s.startedAt ?? now`. Có `pendingNote(notes, lastSeenVersion, current)` thì `pendingWhatsNew = note.version`. `open = []`. Không đặt `pendingWelcome`.
            - `installed` + reason khác (`chrome_update`, `shared_module_update`, …): `next` giống hệt `s`, `open = []`.
            - `startup`: `pendingWhatsNew` khác null và `autoOpenWhatsNew` → `open = ['whatsnew']`, `lastSeenVersion = pendingWhatsNew`, `pendingWhatsNew = null`. Ngược lại `next = s`, `open = []`.
            - Hàm không sửa `s` (trả object mới).
            `export function uninstallUrl(version: string, uiLang: string): string` → `https://winwin1808.github.io/md-reader/uninstall.html?v=<version>&lang=<vi|en>` (`lang = 'vi'` khi `uiLang` bắt đầu bằng `vi`, ngược lại `en`; `version` qua `encodeURIComponent`).
INVARIANTS  `apps/extension` là lớp duy nhất dùng `chrome.*`, nhưng `lifecycle.ts` và `release-notes.ts` phải thuần (không `chrome.*`, không `document`) để test không cần mock.
            Không thu telemetry: URL gỡ cài chỉ có `v` và `lang`, không định danh.
            Storage hỏng → không mở tab (mặc định `pendingWelcome: false`).
            "Có gì mới" chỉ mở cho bản có `showOnUpdate`, và chỉ một lần.

### [x] 18a.2 — Nối vào worker
FILES       apps/extension/src/worker/index.ts · apps/extension/src/worker/index.test.ts
INTERFACES  Tiêu thụ từ `./lifecycle`: `LIFECYCLE_KEY`, `parseLifecycleState`, `decideLifecycle`, `uninstallUrl`; từ `../shared/release-notes`: `RELEASE_NOTES`.
            Trong `index.ts`, thay `onBoot` dùng chung bằng hai handler:
            - `chrome.runtime?.onInstalled?.addListener((details) => enqueue(() => onInstalled(details)))` với `onInstalled({ reason, previousVersion })` → `runLifecycle({ type: 'installed', reason, previousVersion })` rồi `purgeStaleCache()` và `tick()` như `onBoot` cũ.
            - `chrome.runtime?.onStartup?.addListener(() => enqueue(() => onStartup()))` → `runLifecycle({ type: 'startup' })` rồi `purgeStaleCache()`, `tick()`.
            - `enqueue(fn)`: một promise chain module-level để các handler chạy tuần tự (`chain = chain.then(fn, fn)` hoặc tương đương, lỗi không làm đứt chain).
            - `runLifecycle(ev)`: đọc `chrome.storage.local.get(LIFECYCLE_KEY)`, `parseLifecycleState`, `decideLifecycle(ev, s, RELEASE_NOTES, chrome.runtime.getManifest().version, Date.now())`, ghi `next` vào `chrome.storage.local.set({ [LIFECYCLE_KEY]: next })`. **Bỏ qua `open` ở phase con này** (chưa mở tab; 18b2, 18c1 nối). Sau đó gọi `chrome.runtime.setUninstallURL?.(uninstallUrl(version, chrome.i18n?.getUILanguage?.() ?? 'en'))` trong try/catch; lỗi → `console.warn`. Toàn bộ `runLifecycle` bọc try/catch, lỗi → `console.warn`, không chặn `purgeStaleCache`/`tick`.
INVARIANTS  `apps/extension` là lớp duy nhất dùng `chrome.*`; dùng optional chaining để Firefox và test không vỡ.
            Không mở tab nào ở phase con này.
            Lỗi vòng đời không được chặn dọn cache và `tick` của cầu nối MCP.
            Hai sự kiện tới sát nhau không được ghi đè trạng thái của nhau (tuần tự).
TEST        pnpm --filter extension test src/worker/index.test.ts
            Sau đó `pnpm --filter extension typecheck` phải exit 0.
            Mock thêm trong test: `chrome.runtime.getManifest`, `chrome.runtime.setUninstallURL`, `chrome.i18n.getUILanguage`, `storage.local.get/set` cho `LIFECYCLE_KEY`. Test phải chứng minh: `onInstalled({reason:'install'})` ghi trạng thái có `pendingWelcome: true` và không gọi `tabs.create`; `setUninstallURL` được gọi với URL có `v=<manifest version>` ở cả `onInstalled` và `onStartup`; `setUninstallURL` ném lỗi thì `tick`/dọn cache vẫn chạy; gọi `onInstalled` rồi `onStartup` liên tiếp không chờ thì lần ghi thứ hai đọc được trạng thái của lần thứ nhất (tuần tự).
