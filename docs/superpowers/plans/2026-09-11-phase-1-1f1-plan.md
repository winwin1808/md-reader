INTERFACES  
```ts
export type ThemeMode = 'light' | 'dark' | 'system'
export interface ThemeContextValue { mode: ThemeMode; resolved: 'light' | 'dark'; setMode: (mode: ThemeMode) => void }
export interface ThemeProviderProps { mode: ThemeMode; onModeChange?: (mode: ThemeMode) => void; children: React.ReactNode }
export function ThemeProvider(props: ThemeProviderProps): JSX.Element
export function useTheme(): ThemeContextValue
```
INVARIANTS  
- `packages/ui`: không `chrome.*`. Nhận dữ liệu qua props. Không component nào tự đọc file hay biết provider.
- `ThemeProvider` đặt `data-theme={resolved}` trên phần tử bọc của nó (một thẻ `div`), không trên `document.documentElement` — component không được chạm root, Shadow DOM ở 1h1 cần thế.
- CSS custom properties trên `[data-theme='light']` và `[data-theme='dark']` — `--md-bg`, `--md-fg`, `--md-fg-muted`, `--md-border`, `--md-link`, `--md-code-bg`, `--md-code-fg`, `--md-selection`, cộng bộ `--md-hljs-*` (keyword, string, comment, number, function, tag, attr). Đây là nguồn duy nhất của màu; không component nào hardcode màu.
- `mode` là controlled prop, không state nội bộ — lớp trên bơm giá trị vào, `ui` chỉ đọc và gọi `onModeChange`.
- `mode: 'system'` khi `window.matchMedia` không tồn tại → `resolved: 'light'`.
- `useTheme` gọi ngoài provider throw `Error('useTheme must be used within ThemeProvider')`.
