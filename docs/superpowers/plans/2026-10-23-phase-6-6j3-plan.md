INTERFACES  export interface CheckpointTracker { flush(label: 'save' | 'auto' | 'import', actor: string): HistoryEntry | null; dispose(): void }
            export function createCheckpointTracker(doc: Y.Doc, opts?: { quietMs?: number; onAuto?: (e: HistoryEntry) => void; actor?: string }): CheckpointTracker
            export function registerActor(doc: Y.Doc, name: string): void   // meta.actors = { ...actors, [String(doc.clientID)]: name }
            Tracker: doc.on('afterTransaction', tr) — if tr.changed has the source Y.Text (getSource(doc)):
              add every client whose clock in tr.afterState exceeds tr.beforeState, plus every client in
              tr.deleteSet.clients; (re)start the quiet timer. flush: if the set is empty → null; else
              appendHistory-equivalent push of { id: crypto.randomUUID(), actor, ts: Date.now(), label,
              clientIds: sorted, snapshot: Y.encodeSnapshot(Y.snapshot(doc)) }, clear the set and the
              timer, return the entry. Quiet timer (default 30000 ms) → e = flush('auto', opts.actor ?? 'local');
              e && opts.onAuto?.(e). dispose removes the listener and clears the timer.
            Pushing to history happens in its own transaction with origin 'md:checkpoint' and must not
            re-trigger the tracker (history is not source).
INVARIANTS  - packages/core is pure TS: yjs only; no react, chrome.*, document; provider-agnostic.
            - Snapshots need gc:false docs; document that createCheckpointTracker expects one (no throw).
            - Schema keys unchanged (history entries gain the already-declared optional `snapshot`).
TEST        pnpm --filter core test src/doc/checkpoint.test.ts
            two replicas (gc:false) edit and sync → flush lists both clientIDs; flush with no change → null;
            fake timers: edit, advance 30000 → one 'auto' entry and onAuto called once; snapshot from an
            entry → Y.createDocFromSnapshot(doc, Y.decodeSnapshot(entry.snapshot)) source text equals the
            text at flush time even after later edits; registerActor writes the name under String(clientID).
            Then `pnpm --filter core test`; report.
