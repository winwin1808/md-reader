### [x] 18d2.2 — `POST /api/feedback` và `GET /api/admin/feedback`
FILES       apps/api/src/api.ts · apps/api/src/api.test.ts · apps/api/src/index.ts
INTERFACES  `ApiDeps` thêm `feedback?: FeedbackStore`.
            `POST /api/feedback` (đặt trước khối `/api/admin/`):
            1. `text = await req.text()`; `utf8Len(text) > MAX_FEEDBACK_BODY` → `json({ error: 'too large' }, 413)`.
            2. `JSON.parse` lỗi → `json({ error: 'invalid body' }, 400)`.
            3. Body là object và `website` là chuỗi khác rỗng (sau trim) → `new Response(null, { status: 204 })`, không gọi store, không `check`/`record`.
            4. `parseFeedback(body)` null → 400 `invalid body`.
            5. `!deps.feedback` → `json({ error: 'not available' }, 501)`.
            6. Subject chỉ IP: `{ installHash: null, ipHash: await hashToken(ipSubject(req.headers.get('CF-Connecting-IP') ?? '')) }` (import `hashToken` từ `./tokens.js`, `ipSubject` từ `./limits.js`); KHÔNG gọi `subjectFrom`, KHÔNG đọc `x-mdr-install`.
            7. `deps.limits`: `check('feedback', subj)` có verdict → `limited(v)` (429 + `retry-after`).
            8. `await deps.feedback.add(input)`; `deps.limits?.record('feedback', subj, { roomId: '-' })`; trả 204.
            `GET /api/admin/feedback` (trong khối `/api/admin/` sẵn có, cùng luật: không có `adminSecret` → 404; `adminAuthorized` sai → 401): `limit` = số nguyên từ query, mặc định 50, kẹp 1..200; `before` = số nguyên dương từ query, khác → bỏ qua; `!deps.feedback` → 501; trả `json({ items: await deps.feedback.list({ limit, before? }) })`.
            `index.ts`: deps của `handleApi` thêm `feedback: new D1FeedbackStore(env.DB)`.
            Tiêu thụ từ `./feedback.js`: `parseFeedback`, `MAX_FEEDBACK_BODY`, `FeedbackStore`, `D1FeedbackStore`, `MemoryFeedbackStore` (test).
INVARIANTS  Không thu telemetry: route không đọc `x-mdr-install`, không lưu IP (IP chỉ băm để đếm hạn mức trong `usage_daily`, như các route khác).
            Giới hạn ≤ 5/ngày/IP, ≤ 500/ngày toàn cục qua `LimitStore` sẵn có; vượt → 429.
            Bẫy bot (`website`) trả 204 như thành công để bot không dò được.
            Đọc góp ý chỉ qua admin có `ADMIN_SECRET`.
            Entry Worker `index.ts` chỉ export hàm/class.
