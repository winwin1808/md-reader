INTERFACES  Tiêu thụ: `type BridgePinState = 'unknown' | 'none' | 'self' | 'other'` từ `@md-reader/core/bridge`; `StoreLike` sẵn có trong file (`get(k): Promise<Record<string, unknown>>`, `set(v): Promise<void>`).
            Sinh ra (thêm vào `bridge-storage.ts`, không đổi export sẵn có):
            ```ts
            export const BRIDGE_ASKED_KEY = 'mdr.bridgeAsked'      // dùng với chrome.storage.local
            export const BRIDGE_SEEN_KEY = 'mdr.bridgeSeen'        // dùng với chrome.storage.session
            export const BRIDGE_CONNECT_MSG = 'mdr-bridge-connect'
            export const ASKED_MAX = 20
            export const SEEN_TTL_MS = 11 * 60_000

            export type AskedMap = Record<string, { at: number; rejected?: boolean }>
            export interface SeenServer { keyHash: string; client: string; port: number; pinned: BridgePinState; rejected: boolean; at: number }

            export function pairPolicy(i: { pinned: BridgePinState; asked: boolean; manual: boolean; recentlyRevoked: boolean }): 'ask' | 'silent'
            export function parseAsked(v: unknown): AskedMap
            export async function readAsked(store: StoreLike): Promise<AskedMap>
            export async function markAsked(store: StoreLike, keyHash: string, now: number, rejected?: boolean): Promise<void>
            export function parseSeen(v: unknown): SeenServer[]
            export async function readSeen(store: StoreLike): Promise<SeenServer[]>
            export async function upsertSeen(store: StoreLike, s: SeenServer): Promise<void>
            export async function removeSeen(store: StoreLike, keyHash: string): Promise<void>
            export async function pruneSeen(store: StoreLike, now: number): Promise<void>
            export interface ConnectMsg { type: typeof BRIDGE_CONNECT_MSG; keyHash: string }
            export function parseConnectMsg(v: unknown): ConnectMsg | null
            ```
            `pairPolicy`, đúng thứ tự này: `pinned === 'other'` → `'silent'`; `manual` → `'ask'`; `recentlyRevoked` → `'silent'`; `asked` → `'silent'`; còn lại → `'ask'`.
            `parseAsked`: không phải object → `{}`; bỏ mục có khoá không khớp `/^[0-9a-f]{64}$/` hoặc `at` không phải số hữu hạn; `rejected` chỉ giữ khi `=== true`.
            `markAsked`: đọc, ghi `{ at: now, rejected }` với `rejected = tham số ?? giá trị cũ của mục đó`; nếu kết quả không `true` thì không ghi thuộc tính `rejected`; cắt còn `ASKED_MAX` mục có `at` lớn nhất; ghi lại dưới `BRIDGE_ASKED_KEY`.
            `parseSeen`: không phải mảng → `[]`; bỏ mục sai kiểu (`keyHash` 64-hex, `client` string, `port` số nguyên, `pinned` thuộc 4 giá trị, `rejected` boolean, `at` số hữu hạn).
            `upsertSeen`: thay mục cùng `keyHash` hoặc thêm cuối. `removeSeen`: lọc theo `keyHash`. `pruneSeen`: bỏ mục `at < now - SEEN_TTL_MS`; chỉ ghi khi có thay đổi.
            `parseConnectMsg`: `type === BRIDGE_CONNECT_MSG` và `keyHash` khớp `/^[0-9a-f]{64}$/`, ngược lại `null`.
INVARIANTS  File này không gọi `chrome.*` trực tiếp — mọi truy cập kho đi qua tham số `StoreLike` (worker truyền `chrome.storage.local` / `chrome.storage.session` vào).
            Dữ liệu đọc từ kho là không tin cậy: mọi hàm đọc phải đi qua `parseAsked`/`parseSeen`, không bao giờ ném lỗi vì dữ liệu rác.
            Máy chủ đã ghim khoá khác (`pinned === 'other'`) không bao giờ được hỏi, kể cả khi người dùng bấm kết nối tay.
            Không đổi `BRIDGE_STORAGE_KEY`, `parseBridgeSettings`, `addApproved`, `removeApproved`, `parsePairDecision`, `loadOrCreateExtKey`.
