INVARIANTS
- Packages boundary: `packages/ui` is pure React & CSS (NO `chrome.*`), pure presentation.
- In `packages/ui/src/components/MindmapModal.tsx`:
  - When `isOpen === false`, returns null.
  - Portal / full-screen overlay: renders fixed full-screen overlay (`.mindmap-modal-overlay`) with backdrop blur.
  - Tree layout algorithm:
    - Recursively computes hierarchical positions `(x, y)` for all nodes.
    - Level separation horizontally `dx ~ 180px`, vertical node separation `dy ~ 42px`.
    - Computes bounding box for centering and fit-to-screen.
  - Bézier curves:
    - Draws smooth cubic Bézier curves connecting parent right anchor to child left anchor:
      `M ${parentRightX} ${parentY} C ${midX} ${parentY}, ${midX} ${childY}, ${childLeftX} ${childY}`.
    - Strokes styled with branch color (inherited from top-level branch).
  - Branch colors:
    - Top-level children of root cycle through vibrant distinct branch colors (`#2563eb`, `#10b981`, `#8b5cf6`, `#f59e0b`, `#ec4899`, `#06b6d4`, `#f97316`).
    - Descendants inherit their ancestor branch's color. Root has neutral theme accent or border color.
  - Interactive SVG canvas:
    - Mouse drag on canvas pans the view `(translateX, translateY)`.
    - Mouse wheel zooms in/out `(scale)` clamped between 0.2 and 3.0.
    - Double click or click "Fit to Screen" recalculates `(translateX, translateY, scale)` to fit SVG contents nicely in viewport.
  - Floating controls bar:
    - Zoom In button (`+` or `Zoom In`)
    - Zoom Out button (`-` or `Zoom Out`)
    - Fit to Screen button (`⛶` or `Fit`)
    - Close button (`✕`)
  - Clicking a node text: triggers `onNodeClick?.(node)`.
  - Keyboard: `Escape` calls `onClose()`.
- In `packages/ui/src/theme/mindmap.css`:
  - Fixed overlay `.mindmap-modal-overlay` with `z-index: 10000`, `inset: 0`, background `rgba(0, 0, 0, 0.75)` or theme-adaptive background with `backdrop-filter: blur(12px)`.
  - Header with document title and close button.
  - Floating controls panel at bottom-right or top-right.
  - SVG styling: nodes, branches, text labels, hover highlights.
  - Import `mindmap.css` into `packages/ui/src/viewer.css`.
- In `packages/ui/src/index.ts`:
  - Export `MindmapModal`, `MindmapModalProps`.
