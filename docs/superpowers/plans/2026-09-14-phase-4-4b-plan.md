INVARIANTS
- Packages boundary: `packages/ui` is pure React & CSS (NO `chrome.*`), pure presentation.
- In `packages/ui/src/components/WordCountBar.tsx`:
  - Parses word count (non-empty whitespace tokens), character count (`text.length`), and reading time (`Math.max(1, Math.ceil(words / 200))` min).
  - Format: `${words.toLocaleString()} từ · ${chars.toLocaleString()} ký tự · ~${readingTime} phút đọc`.
  - When `visible === false`, returns null.
  - If `autoHide === true`, listens to window `scroll` event. When `window.innerHeight + window.scrollY >= document.documentElement.scrollHeight - 120`, applies class `is-hidden` (or hides). Cleans up event listener on unmount.
- In `packages/ui/src/components/CelebrationConfetti.tsx`:
  - Renders a `<canvas className="celebration-confetti-canvas" ...>` fixed to viewport with `pointer-events: none; z-index: 99999;`.
  - On `active` transition from false to true, initializes ~60 confetti particles with varying colors, velocities, angles, and rotations.
  - Runs a lightweight `requestAnimationFrame` loop updating positions and drawing confetti rectangles/ovals.
  - Stops after `duration` (default: 3000ms), clears canvas, and triggers `onComplete?.()`.
