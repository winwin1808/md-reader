            `{ text, ts: Date.now() }` under the existing key ONLY (a) right before the alwaysOpenApp
            redirect and (b) when the user clicks the open-in-app control (pass a callback to

            alwaysOpenApp redirect (review 6h1 #1): app.html is not web-accessible, so the content script must
              NOT `location.replace`/`window.open` it — it sends the existing open-app message to the worker
              (which does tabs.update) after writing the cache entry. Use makeCacheEntry / readCacheEntry from
              ../shared/md-url (6h1.2) for every write/read.
            useDocSession: reading the cache uses readCacheEntry (`{ text, ts }` and a legacy string); after reading,
            remove the key only after the text was applied (or the decision kept local text) — not
            before awaiting sync, so a cancelled StrictMode run doesn't lose it (review 6e3 #4).

            - packages/ui has no chrome.*; chrome.* stays in apps/extension.
